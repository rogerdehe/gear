- Judgement calls to note: (1) a `note` does not write the result column of the original message ("a note changes nothing but the answer"); (2) `downgrade` is accepted but has no effect — the store has no way to change the urgency of a message (the captain's T-24 keeps `needs_ack` false for the same reason); (3) a message that is already Waiting may be waited on again: the wait fields are recorded, the state does not change, so no transition is needed.
