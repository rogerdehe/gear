## Goal

Implement the three plumbing functions in `crates/gear-cli/src/main.rs` that every slice-1 command uses:
- `env_from_process()` → `gear_app::Env`: `GEAR_CTX` parsed with `GearCtx::parse` (absent → `ctx: None`; malformed → the parse error), `HERDR_PANE_ID` → `pane_id`, `GEAR_ADMIN=1` → `admin` (any other value → false).
- `open_store()`: `GEAR_DB` set → `Store::open(path)`; unset → `ErrorCode::NoTarget` with a detail saying `GEAR_DB` is not set (the admin target file, design/14, comes with slice 3).
- `announce_request_id(given)`: the given id, or a new one `r-<unix-ms>-<pid>`; prints `request: <id>` to stderr in both cases; returns it.

Make each testable by delegating to a private helper that takes a variable lookup (`impl Fn(&str) -> Option<String>`) instead of reading the process environment directly.
