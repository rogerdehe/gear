## Goal

Implement `gear_app::draft::parse` (`crates/gear-app/src/draft.rs`): the strict plan-draft format of design/05 "Draft format" into the `Draft` types already declared there. Pure text parsing — no store, no semantic checks (deps existing, cycles, verdict vs attempt are plan apply's job, later). Every rejection is `ErrorCode::BadFormat` with a detail starting `line <n>: ` (1-based, the offending line).

Strictness rules (from design/05): only the known sections; queue block header `## T-<n>|NEW [now|must|should|could|wont]` then `lane=`, `milestone=`, `required` in any order; queue fields only `goal`, `accept`, `evidence-files` (comma list), `evidence-due` (minutes), `deps` (`-` or comma list), `state` (`ready` | `cancelled` only), `followup-of`, `reopen`; a repeated field in one block is an error. Staff verbs only `temp`, `park` (exactly one of `until=` / `until-task=`), `hold` (`reason=` required, value to end of line), `retire`. Verdict: `pass` requires `evidence=` and forbids `rework=`; `fail` requires `rework="<text>"` and forbids `evidence=`. Blank lines are ignored everywhere; free text is kept trimmed.
