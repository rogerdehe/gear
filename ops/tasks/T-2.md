## 实现要点

1. `classify_screen`：取 `tail` 的最后 `profile.tail_lines` 行；每行做**字面子串**匹配（不用正则）；对应四类 marker → `ScreenFlag`。
2. `validate_template`：模板里出现任一 marker（四类都查）→ `Err(包含该 marker 的说明)`。
3. `outcome_from_error`：
   - `HerdrError::Protocol { code }`：code 属于"确定未执行"集合 → `Refused`；集合：`agent_blocked`、`not_found`、`invalid_request`、`invalid_params`、`agent_not_found`、`pane_not_found`、`pane_not_available`。其他任何 code → `Uncertain`。
   - `Io`、`Deadline`、`Disconnected`、`Decode` → `Uncertain`。
4. `SocketHerdr::connect`：`HerdrClient::connect(path)` 后 `require_supported_protocol()`；失败 → `ObserveError(说明)`。
5. 读方法：
   - `agents()` → `session_snapshot()` 的 agents 列表；
   - `agent_get(pane)` → `agent_get`；pane 不存在或没有 agent 时返回 `Ok(None)`（用 Protocol 错误码区分"不存在"与其他错误；其他错误 → `ObserveError`）；
   - `read_tail(pane, lines)` → `pane_read`，source = `RecentUnwrapped`，`lines` 行，返回文本。
6. 写方法：成功 → `Outcome::Ok`；错误 → `outcome_from_error`。
   - `prompt`：`agent_prompt`，**不带 wait**；
   - `pane_run`：用 `pane_send_text` 发 `command` 再 `pane_send_keys(["enter"])`，或若 board-herdr 有更直接的方法就用它（查 client.rs）；两步中第二步失败 → `Uncertain`；
   - `agent_start`：`AgentStartParams { name, kind, pane_id, args, timeout_ms: Some(60_000) }`，返回值里取出 pane 对应的 `AgentInfo`（如需再调 `agent_get`）；
   - `send_keys`、`pane_close`、`notify`（`notification_show`）照对应方法；
   - `set_title`：Herdr 的 `pane.report_metadata`（title 字段，source 固定 `"gear"`）。board-herdr 没有封装就用 `client.call("pane.report_metadata", json!{...})`，字段名按 `herdr api schema --json` 核对。
7. 不需要为 `SocketHerdr` 写真实 Herdr 集成测试（会动真实会话）；能编译、逻辑清楚即可，舰长另行做实机探针。
