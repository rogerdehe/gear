```rust
fn run_home(store: &mut Store, env: &Env, herdr: &mut dyn HerdrRead, now: Ts, json: bool, out: &mut dyn std::io::Write) -> GearResult<()>
```

`identity::observe` → `home::build` → write the text (or, with `--json`, the `Home` text and view as JSON) to `out` → **only after the write succeeded** `home::record_view`.
