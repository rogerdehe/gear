## Goal

Wire `cmd_send` / `cmd_reply` in `crates/gear-cli/src/main.rs`. Captain decision on testing: the logic lives in private helpers that take everything injected, and the tests call them with `gear_herdr::fake::FakeHerdr` and an in-memory store — no live Herdr, no process environment:

```rust
fn run_send(store: &mut Store, env: &Env, herdr: &mut dyn HerdrRead, c: &SendCmd, body: String, now: Ts, json: bool) -> GearResult<String>
fn run_reply(store: &mut Store, env: &Env, herdr: &mut dyn HerdrRead, c: &ReplyCmd, now: Ts, json: bool) -> GearResult<String>
```

Each: `identity::observe(env, herdr)` → map the clap struct to `mail::SendArgs` / `ReplyArgs` → `mail::send` / `mail::reply` → return the printable result (plain text: one line per item; `--json`: the result serialized). `cmd_*` only glue: `env_from_process()`, `open_store()`, `SocketHerdr`, `announce_request_id`, body from the argument or stdin, print.

Mapping rules: `--kind` text → `MsgKind` (unknown → `BadFormat`); reply mode from `--resolve` (default) / `--wait <who> --until <t>` / `--note`; `<t>` is `+<n>m` or `+<n>h` relative to `now`, or unix seconds; anything else → `BadFormat`. Flags that slice 1 does not support (`--candidate`, `--preempted`, `--saved`, `--next-check`) → `BadFormat` naming the flag.
