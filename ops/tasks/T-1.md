## Implementation notes

1. `Store::open`: create parent dirs; `PRAGMA journal_mode=WAL`, `busy_timeout = BUSY_TIMEOUT_MS`, `foreign_keys=ON`; run `SCHEMA_SQL`; if `meta.schema_version` is missing write `SCHEMA_VERSION`; if present and greater than `SCHEMA_VERSION` → `ErrorCode::BadFormat`.
2. `Store::write`: `rusqlite::TransactionBehavior::Immediate`; closure `Ok` → commit, `Err` → rollback and return the error unchanged. SQLite busy/locked → `ErrorCode::Locked`. Other rusqlite errors map to `GearError` through one private conversion function (use `BadFormat` for corrupt data / type mismatch; never `NoTarget` here).
3. `Store::read`: `TransactionBehavior::Deferred`; end with rollback or commit (read-only).
4. `next_id`: upsert-increment in `id_seq`, return `"{kind}-{n}"`, starting at 1.
5. `run_request`: hash `args_key` with **FNV-1a 64-bit** (write it yourself, ~15 lines; store as hex). Existing row with same hash → `Replayed(stored)`; different hash → `RequestConflict`; no row → run the closure, on success insert into `requests` and return `Executed`. If the closure fails, write nothing (return the error; the outer transaction rolls back).
6. JSON fields (`payload`, `shown_msgs`, `shown_ops`) are serialized with `serde_json` to TEXT.
7. Booleans as 0/1; enums stored via `as_str()`, read via `parse()`.
8. `actionable_for`: `state='open'` or (`state='waiting'` and `wait_until` not null and `<= now`), ordered by `created, id` ascending.
9. `slot_ops` (the seat's single *delivery* slot, unrelated to worktrees): `kind IN ('deliver','doorbell')` and `state IN ('intended','executing','submitted','unknown')`.
10. `last_op`: same seat and kind, newest first by `created DESC`, then by numeric part of the `O-<n>` id (or rowid) descending.
11. `testing::seed_project` / `seed_active_seat`: fill values exactly as the doc comments in lib.rs say.
