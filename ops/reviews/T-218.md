## Findings
- F1 [P1, blocking] An execution-failed automatic retry remains suppressed indefinitely — `crates/gear-engine/src/lib.rs:548` (with marker consumption only at `crates/gear-engine/src/ops.rs:830`) — A normal agent restart can occur between the idle observation/planning of the retry and its execution. `execute_intended` writes the retry `Failed` with `agent-gone`, but only `confirm_pending_with` clears `pending`, and it visits Submitted/Unknown ops, never this Failed op. If the replacement agent is present by the next observation, the independent missing-agent flag cannot rescue it. The outstanding-failure sweep now returns false forever for `pending`, and lane_nudge refuses another redelivery. The task remains Delivered, with no captain item. This breaks the explicit failure clause and STABLE bar: one restart during automatic retry can leave work stuck silently. Reproduction and smallest fix follow.
