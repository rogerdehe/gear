- **[P0] A missing branch is not evidence of a completed push** — `crates/gear-engine/src/merge.rs:286`. The result is `Ok("T-5 was already merged: origin/heat/t5 is gone")` while origin/dev still contains only its original commit; the caller would record Confirmed. - **[P1] Failure handling retries the same candidate and duplicates captain items** — `crates/gear-engine/src/merge.rs:205` (also worktree failure at line 93). - **[P1] Remote cleanup errors are discarded before confirming success** — `crates/gear-engine/src/merge.rs:332`.
