F2 [P1, blocking] A quota pause is silently discarded while a declared wait is open — `crates/gear-store/src/lib.rs:2820`. Reproduce: open_pause(p, seat, wait, T-2, 100); open_pause(p, seat, quota, minimax, 110). Both return Ok, but pauses_of_project contains only the wait; close_pause(p, seat, quota, 200) returns NoTarget. A provider quota park can overlap a task's declared wait: these are independent conditions. This breaks §5.4's every-quota-park record, the done-sentence's quota continuation and voyage reporting, and STABLE's normal-use error bar. Fix: in open_pause, restrict the existing-open lookup to the supplied kind (`AND kind=?3`, bind kind), keeping idempotency per kind rather than per seat (about 3 lines plus a regression test). Test overlapping wait/quota with distinct timestamps, close each independently, and verify both durations survive.
F3 [P1, blocking] NewFriction and NewDecision require `created`, although §13.1 explicitly defines their inputs without id/seq/created — `crates/gear-store/src/lib.rs:456` and `:503`. An independent caller initializing the specified fields fails to compile with E0063 for both types. This breaks the task's exact interface contract and prevents the dependent friction/decision writers needed by the voyage-review done-sentence from compiling against it; it also breaks the STABLE integration bar. Fix: remove `created` from these two input types, supply the insertion timestamp inside insert_friction/insert_decision_if_new (for example SQLite unixepoch()), retain it on the returned row types, and update the existing test literals (roughly 15–25 lines). Add a compile/round-trip case using the specified inputs without created; verify the stored creation timestamps and decision replay behavior.
F4 [P2, logged] A same-second second pause is moved into the future and can end before it starts — `crates/gear-store/src/lib.rs:2830`. Probe: open wait at 100, close at 100, open quota at 100, close quota at 100 yields quota start_at=101/end_at=100. The loop invents time to avoid the primary-key collision; repeated collisions can shift up to 60 seconds. This corrupts duration arithmetic in this boundary case. Log as an edge outside the ordinary hours-long quota flow. Small fix: preserve the supplied timestamp and return an explicit collision error instead of silently changing it; prevent closing before start_at. If multiple same-second intervals must be supported losslessly, the captain must settle a schema-key adjustment rather than encoding artificial time.
