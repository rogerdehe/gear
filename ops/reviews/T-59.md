## Set aside

- **The captain handover case** (`finish_onboard` activates a `Captain`-role seat too, where design/03:89
  wants an incoming captain to stay `pending` until the handover ACK) — the writer declared it out of
  scope, the packet's doc comment says nothing about a role exception, T-63 binds the captain at init
  without these functions, and the MVP has no `gear admin captain replace` flow. Belongs to the task that
  implements the handover.
- **`finish_onboard` does not require the seat to be `Starting`** — it accepts any state the model allows
  to reach `Active` (e.g. `NeedsCheck → Active`, `Unknown → Active`), which is wider than its doc comment's
  "the seat goes Starting → Active" and wider than design/10:19 (`NEEDS_CHECK → ACTIVE` needs the user's
  `gear admin seat confirm`). Not reachable in the walking skeleton: the only caller,
  `runtime/t62-onboard-run`'s `onboard_seat`, calls it immediately after `begin_onboard`. Worth tightening
  before any engine path retries onboarding from `NeedsCheck`.
- **`begin_onboard` also accepts `Temp: Released → Starting`** (design/10:47 resume) although its doc
  comment's parenthetical only names `Queued` / `Missing` / `NeedsCheck`. The behaviour is the correct one
  for the resume flow; the doc comment is narrower. Not changed here — it is a captain-owned stub.
- **Quota reservation and `resources` recording** (design/10:29-30) — done around these calls by the
  engine, not part of the packet's two functions.
- **`onboard_intent`'s "retries/restarts reuse the same operation and generation"** (design/03:54) — the
  signature carries no operation id and the packet's doc comment says always `generation + 1`; needs a
  captain decision when op tracking exists.
- **Generation / void checks on ordinary writes** (design/03:25, `resolve_caller` / `require`) — a
  different task, not this one.
- **Two raw `get_binding` + `set_binding_status` round trips per old generation** — O(generations) queries
  per onboarding; fine at MVP volumes, and the store exposes no "bindings of a seat" query to do better.
