## Findings
F1 [P1, blocking] Pause totals are permanently overstated before their authoritative end is reconciled — `crates/gear-engine/src/waits.rs:91` (called at `crates/gear-engine/src/lib.rs:195`). The newly added first wait pass counts every still-open seat pause through `now`. A completed background merge is collected later in the tick (`merge.rs:247` records the worker's earlier completion time); quota pauses are closed still later by `overrun::reconcile_quota_pauses` at the seat's earlier state transition. Although those operations shorten the pause interval, both this loop and `overrun::process` preserve the larger stored `paused_s`. The excess is never removed, so active time is understated and overrun/friction thresholds are delayed. This breaks contract v4's round-clock requirement and the STABLE bar's requirement to fix normal-use stability/usability errors. Smallest fix: remove the duplicate pause-accounting loop from `waits::reconcile` (roughly lines 71–94 and the unused RoundKey import); keep wait/pause reconciliation there and let the existing `overrun::process`, already run after merge collection and quota-pause reconciliation, compute the union and update the round once. Add the two regression cases below to the engine tests (about 30–40 lines using the existing wait fixture).
