## Set aside

- design/09 step 7 lists "extra requirements for continue" (task not WAITING, not held, no unresolved blocker, not pending verification). `decide` does not check them, and cannot: `LaneView` (fixed on dev) carries no `TaskRow`/hold/blocker for the current attempt. The packet scopes `decide` to "exactly the order its doc comment lists", which omits them, so this is not a defect here — but it belongs in a question below.
- A `Delivered` attempt on an idle seat (cooldown elapsed, no pending op) returns None forever — no nudge, no assign. design/09 names only Started/Stopped for `continue`, and assigning a second task would violate "one task per seat", so `none` is the conservative choice; whether the engine should nudge a delivered-but-never-started agent is a design gap, not this task.
