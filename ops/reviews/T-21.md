## Findings
- [P1] `observe::expects_agent` reimplements `SeatState::expects_agent()` with a different, wrong set — `crates/gear-engine/src/observe.rs:122-123` — `gear_model::SeatState::expects_agent()` (`crates/gear-model/src/state.rs:168-171`, already `pub` and already imported here) returns `Active | Standby | Parked | Held | Retiring | Unavailable | Handover`. The private helper returns true for every state except `Queued | Released | Starting | Releasing`, so `Retired`, `Missing`, `NeedsCheck` and `Unknown` seats are wrongly judged "expects an agent". `reconcile` then emits `Missing`/`Present`/`Changed` for those seats instead of `NotExpected`, contradicting Task 1's "seats that expect no agent → NotExpected". Slice 2+ acts on Missing/Changed, so a retired / needs-check / unknown seat would be spuriously re-judged or re-staffed. Fix: delete the private helper and call `state.expects_agent()`.
