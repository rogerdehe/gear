## Findings

F1 [P1, blocking] An earlier round is read with the seat's later CLI profile — `crates/gear-engine/src/rounds.rs:142`. `count_round` prefers `cfg.profiles[seat.profile]` even when that profile's kind differs from the immutable `round.cli`, then applies that current profile's project patch. A normal cross-CLI restart or configured kind change before the delayed count can therefore select the wrong parser. Reproduced with a closed Codex round containing 300 input tokens: with seat profile `codex`, count_round returns Some(300); after changing only the seat profile to built-in `pi`, it returns Some(0) for the identical round/log. Pi accepts the readable Codex file as an empty log; tick persists zero and its `round.input.is_some()` guard prevents correction. This breaks done (3), accurate tokens per round, and STABLE's normal-use correctness requirement. Smallest fix: in `count_round`, use the current seat profile only when its resolved kind matches the round's CLI; otherwise resolve the profile and project override for `round.cli` (about 15–25 lines). Add an engine fixture that closes a Codex round, changes the seat to pi before end+60, then runs tick and asserts the historical round still stores 300 tokens. Preserve custom usage_log overrides when the selected profile matches the round's CLI.

F2 [P1, blocking] A model switch loses provider-qualified price lookup for bare model IDs — `crates/gear-usage/src/lib.rs:860`. The default round model supplies its provider only when the record model exactly matches its original model suffix. Codex turn_context records carry bare model IDs; after an in-round model change, records for the new model therefore cannot find an existing `[prices."provider/new-model"]` entry. Reproduced with round model `openai/m1`, turn_context models `m1` then `m2`, cumulative input totals 100 then 300, and prices `openai/m1`=1 and `openai/m2`=3 USD/M (other rates zero): round_usage returns input=300, cost=None, source=none; expected cost=0.0007, source=prices. This breaks the explicit §4.2 example 5 / §4.4 contract and done (3), per-round cost, under STABLE. Smallest fix: resolve bare record model IDs to their provider-qualified configured price keys even when the model changes; retain each record's actual model and keep ambiguous provider matches unknown (about 15–25 lines in the model/price resolution). Add the above Codex-shaped model-switch fixture; the existing switch fixture uses already-qualified pi model names and misses this case.
