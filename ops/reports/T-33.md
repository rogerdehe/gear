# T-33 — Change an agent's model in place, never by closing it

Scope: T-33 — the engine switches a live agent's model with the CLI's own picker (`/model`, the filter, Enter, the variant dialog, then the status bar must show the model): no exit keys, no restart, the conversation stays. Used by the quota fallback (T-15) instead of the exit/start restart, and it never types into a working agent; two failed tries flag the seat. Quota markers left on the screen by an earlier switch no longer count (M-266).
Branch: data/t33 (code @ pending, see the hand-in)
Files:
- crates/gear-engine/src/switch.rs — `switch_in_place`: reads the status bar first (already on the model → nothing sent), waits while the agent works, then sends the sequence (esc, `/model`, Enter, the picker filter, Enter, the variant when `Select variant` opens, Enter) and confirms on the status bar; a failed attempt is retried once (a durable counter in the store's meta), then `Failed`. `SwitchSteps::for_kind` holds the per-kind picker command (OpenCode/Codex/Claude `/model`); a kind without one is not switched in place.
- crates/gear-app/src/config.rs — `[models.switch."<model id>"]` with `picker` (the text typed into the picker, specific enough to pick the wanted entry — L-29), `bar` (what the status bar must show) and an optional `variant`.
- crates/gear-engine/src/quota.rs — the quota fallback calls the in-place switch when the model has labels (no exit keys, no `agent_start`); on success it records the model, resets the counter, delivers one `Continue T-<n>` and tells the captain in one line; two failures park the seat as needs-check. A model without labels keeps the old exit/restart path.
- crates/gear-engine/src/quota.rs (M-266) — a quota marker counts only when the agent has **stopped** (`obs.idle`): a stale limit line on a working agent never parks or switches it.
- Tests (engine, FakeHerdr): a wrong model → the key sequence with a status-bar check and no restart; already on the model → nothing sent; a working agent → nothing sent; a variant dialog → the variant typed; two failed tries → flagged; the quota fallback switches in place (no exit keys, no agent start) and delivers exactly one continue; a working lane with a stale limit line stays active.

Verification:
- `env -u GEAR_DB cargo build --workspace --all-targets` → clean, zero warnings and zero errors.
- `env -u GEAR_DB cargo test --workspace` → green (64 suites; 7 new tests).

## Real proof — the exact commands for the captain to watch one in-place switch

1. Give the models their picker/status-bar texts (only the person in front of the pane knows the exact labels; the filter must be specific, L-29) in the project config, then re-register:

```toml
# ops/gear.toml — the labels an in-place switch needs, keyed by the model id
[models.switch."deepseek/deepseek-flash"]
picker = "DeepSeek V4.1 Flash OpenCode Go"
bar    = "DeepSeek V4.1 Flash OpenCode Go"

[models.switch."minimax-cn/MiniMax-M3.1-Flash"]
picker = "MiniMax-M3.1-Flash"
bar    = "MiniMax-M3.1-Flash MiniMax"
```

```bash
GEAR_ADMIN=1 gear admin init ops/gear.toml
```

2. Watch the engine do it (it switches on the quota fallback, and logs one line):

```bash
tail -f ~/.local/state/gear/engine.log | grep -E 'switched|quota|switch'
```

3. Or watch the same steps by hand in a lane that has stopped (what the engine sends, SOP `agent:opencode`):

```bash
ops/bin/switch-model.sh <agent-name> "DeepSeek V4.1 Flash OpenCode Go" "DeepSeek V4.1 Flash OpenCode Go"
herdr agent read <agent-name> --source visible | grep 'Build auto'   # the bar shows the new model
```

The engine sends no exit keys and starts no agent: the pane keeps its session, and the next `gear send` shows the lane still on the same attempt.

Open questions:

- The per-kind picker command lives in the engine (`SwitchSteps::for_kind`, like `model.rs`'s per-kind start knowledge), not in `Profile`: adding fields to the public profile type for one CLI's TUI would widen it for every kind.
- A failed switch flags the seat as needs-check with the reason ("did not confirm twice"), not a park: a human checks the pane.
- M-266's rule is implemented as "count a marker only while the agent has stopped" (the packet's alternative). A line-based "newer than the last switch" test would need the tail digest in the observation; the stopped-agent rule already covers the reported incident (working lanes parked on old errors).
