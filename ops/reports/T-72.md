# T-72 — every GEAR worktree pushes only where the project registered (attempt 2)

Scope: T-72 rework — F1: the engine's merge check read only the first push URL
while git pushes to all of them, so a second, unregistered push URL received
the merge; F2: a quote in a path produced an invalid generated hook. F3 (a
pre-existing worktree-specific hook is not chained) stays logged, as the
captain settled.

Branch: base/t72 (code @ the hand-in commit; origin/dev merged before
verification, gate green on the merged result)

What changed in this rework:
- `crates/gear-engine/src/merge.rs` — `push_allowed` now reads
  `git remote get-url --push --all origin` and calls `gear_app::push::check`
  for **every** URL git would push to. One unregistered destination refuses the
  whole push (git cannot be asked to skip one), with the same path as before:
  op `Failed`, no worker, no retry, one urgent captain item naming the refused
  destination and the command.
- `crates/gear-engine/src/hooks.rs` — the chained repository hook's path is
  written as a proper single-quoted shell literal (`'` → `'\''`), so a
  repository (or a configured hooks dir) whose path holds an apostrophe still
  yields a valid hook.
- `crates/gear-engine/src/merge.rs` (tests) —
  `a_second_unregistered_push_url_stops_the_merge`: the fixture's origin pushes
  to the registered `../origin` and to an unregistered `../other-origin`;
  nothing lands on either, the op is `Failed`, exactly one urgent item names the
  refused destination, and a later tick does not retry. Red on the old code
  (the merge ran and the unregistered repository received `dev`), green with the
  fix.
- `crates/gear-cli/tests/it/push_hook_contract.rs` — `a_quote_in_the_path_still_makes_a_valid_hook`:
  a repository and worktree whose paths hold an apostrophe, a repository hook
  too, and `sh -n` on the generated hook: it parses.
- `ops/reports/T-72.md` — this brief.

The rest of attempt 1 stands: the per-worktree `core.hooksPath` install for
lane, reviewer and merge worktrees, the chained repository hook, the hook's
`gear push-check` first, and the live note that the project needs a re-init to
freeze its destinations.
