# T-251 — The Time & tokens view shows fresh tokens and cache reads apart, and says once when no prices are set

Scope: T-251 — `tokens_of` sums the fresh tokens only (input + output + cache
write); the cache reads get their own `TaskBoard::cache_read`, filled by
`cache_read_of`, and their own `cache` column in the fifth view; the total line
names both, and a view whose rows have no cost says `no prices set` once
instead of a `?` in every cost cell.

Branch: mast/t251 @ origin/dev (20cf6bd9) — the code and this brief.

Files:
- `crates/gear-board/src/lib.rs`
  - `tokens_of`: `total += round.input + round.output + round.cache_write` (the
    cache reads are no longer in the sum). The unknown rule is unchanged: a
    round with none of the four counted fields makes the sum `None`.
  - `cache_read_of` (new): `None` as soon as a round has `cache_read == None`,
    else the sum; `None` when the task has no rounds — the same shape as
    `tokens_of` and `cost_of`.
  - `TaskBoard.cache_read: Option<i64>`, filled in `project_with_agents` next to
    `tokens`.
  - `to_json`: the task object carries `"tokens"` and `"cache_read"` next to

- `crates/gear-board/src/frame.rs` — `view_tokens`:

## Out of scope

- `priced` is exactly the packet's rule: "`cost_usd` is None on every row". It
  therefore also fires when the project *has* `[prices]` but one of a task's
  rounds was never priced (`cost_of` then returns `None`), and the total says
  `no prices set` where it used to say `(known so far; 1 unknown)`. That is the
  packet's literal rule; telling "no prices configured" from "one round
  unpriced" needs the project config in `ProjectBoard`, which the packet does
  not ask for. `an_unpriced_round_hides_no_part_of_the_sum` names it.
- The cache reads are not in the unknown count when the view is priced (the
  packet names the count only for the unpriced case). A cache cell `?` does not
  therefore raise the footer count.
- `crates/gear-board/src/graph.rs` still shows the task panel's round tokens with
  cache reads included (`820k tokens` in `graph_contract`); the packet changes
  the Time & tokens view only.
- `crates/gear-app/src/time.rs` (`gearb time`) keeps its own token fields.
