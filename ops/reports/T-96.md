What changed in this rework (`skills/gear/references/captain.md`):

  example no longer demonstrates the exact kickoff mistake the task exists to
  remove. The `# Queue` line's explanation is corrected too: a lane works its
  own queue in order on its own branch and **takes its next task as soon as it
  hands the first in — the review runs in the background**, which is what
  `dispatch::lane_view` does (a Submitted attempt is a safe point). The old
  "after the first lands" clause was wrong and is gone.
- **F2** — the model-entry form is stated once, in the `[models]` block of the
  config example (`review = [{ model = …, cli = "codex", args = […] }, …]`);
  the model-chain bullet in §1 now says an entry may name its own CLI and start
  args and **points at that example**, instead of repeating the literal.
- The first two facts of attempt 1 stand: `[quota].lanes` is the lanes the
  project has (not those running at once, and the sheet's lane count agrees
  before the user sees it), and the model bullet keeps the "reviewer never runs
  the writer's model" rule.
