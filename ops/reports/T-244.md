# T-244 — a session file that was never written does not blank a round's tokens

Branch: mast/t244 (code @ 80d18798; origin/dev 01e5784c, already the base, no
newer commit on dev)

## What changed

`crates/gear-usage/src/lib.rs`, `round_usage`:

- the per-session `let u = usage(...)?` and `let records = usage_records(...)?`
  became `let Some(..) = ... else { continue }`: a session whose log cannot be
  read is skipped, it does not decide the round;
- `readable` counts the sessions that were read, and the function returns
  `None` only when that count is zero (no sessions in the list, every file
  gone, or the same missing path twice);
- the totals, the record-level check (`if check != u { return None }`), the
  price lookup and the `cost_source` computation of the readable sessions are
  untouched;
- the doc comment says why: pi can open a session and replace it at once, so
  a file that was never written says nothing about the round.

So T-226's row shows the tokens of the session that does hold them instead of
`?`.

## Tests

`crates/gear-usage/tests/it/pi_jsonl_contract.rs` (three, on pi's fixtures):

- `a_session_file_that_was_never_written_does_not_blank_the_round`: one path
  that does not exist + one with two records → the round is the readable
  session's usage (tokens, cost, `cost_source == "agent"`), with the missing
  path first and last;
- `a_round_with_no_readable_session_is_unknown`: `[]`, two missing files, and
  the same missing path twice → `None`;
- `two_readable_sessions_are_summed`: the sum of two readable sessions, as
  before.

`make check CRATE=gear-usage`: 38 passed, 0 skipped. `cargo build -p
gear-usage --all-targets`: no warnings.

## Out of scope

- `crates/gear-engine/src/rounds.rs` groups the round's sessions by CLI and
  still turns a `None` from `round_usage` into `unknown()`. With this change
  that only happens when no session of a CLI group was readable, which is the
  intended meaning; no change made there.
- A window that holds no record of a readable session stays zero, not
  unknown (unchanged behaviour).
