# T-118 — A rework packet leads with this round's rework

Scope: T-118 — `gear --show T-n` on a rework round opens with the captain's rework text under `## Rework (attempt n, from the review of attempt n-1)` and keeps the older reports under `## Earlier reviews (history)`; `gear send --kind result` refuses a candidate that already failed.

Branch: deck/t118 @ origin/dev (928d912) — the code and this brief.

Files:
- `crates/gear-app/src/plan.rs` — `render_task_packet` computes the rework round (the highest attempt a review or a captain failed on) and the attempt that works on it now, and puts `## Rework (attempt n, from the review of attempt n-1)` with the task's rework note right after the header, before `## Goal`. The review records then render under `## Earlier reviews (history)` instead of `## Review`. A finished task (done/failed/cancelled) is not in a rework round: it keeps the plain `## Review`. - `crates/gear-app/src/tasks.rs` — `submit_result` refuses a candidate that equals a **rejected** attempt's candidate of the same task, naming the attempt: `T-7: candidate <sha> already failed on attempt 1: rework it and hand in a different candidate`. `BadFormat`, nothing written.
- `crates/gear-app/tests/it/packet_contract.rs` — the rework packet leads with the rework (before `## Goal`), carries only the blocking finding as the rework text, keeps the old report under `## Earlier reviews (history)` and names attempt 2 in the hand-in command; a first-round packet has no rework section; a finished task keeps the plain review history.
- `crates/gear-app/tests/it/result_contract.rs` — the failed candidate is refused with the attempt named and nothing written; a new candidate goes through.
- `crates/gear-engine/src/review.rs` — `a_rereview_resumes_the_jobs_session` handed the same candidate in on attempt 2; it now hands a new one (`def5678`), which is what T-118 requires. The test is about the reviewer's session, not the candidate.

## How it reads

```
# T-7 — Fix the login crash
Lane: heat · Contract: v1 · State: ready
Estimate: 30 minutes

## Rework (attempt 2, from the review of attempt 1)
F1: the rework is missing

## Goal
…

## Acceptance
…

## Evidence
…

## Report
gear send --kind progress "…"
gear send --kind result --task T-7 --attempt 2 --contract 1 --candidate <commit> "Report: <path>"

## Earlier reviews (history)
attempt 1 · fail · p:r-1
F1: the rework is missing
F2: the wording of a comment
```

The rework text is the task's `rework_note` — the captain's words after a fail verdict, or the blocking findings the reviewer named after a review fail (T-23) — so it is the same text either way, and it is what the lane must fix this round. The attempt number is the lane's open attempt for the task; without one it is the failed round + 1.
