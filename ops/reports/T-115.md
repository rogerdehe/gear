## What the marker does — and what it does not yet do

The marker makes the reviewer **seen as on quota**: the seat's screen carries `ScreenFlag::Quota`, so `review::nudge_stopped_reviewers` stops nudging it (a nudge cannot fix a limit), and the seat is no longer mistaken for an idle reviewer waiting for work.

The **move** is not wired yet, and that is a fact the captain should have: `[models].on_quota.review` is parsed and validated (`gear_app::config`), but the engine never applies it — `quota::apply_quota_policy` walks lanes only (`if seat.role != SeatRole::Lane { continue; }`, `crates/gear-engine/src/quota.rs:71`), and the cross-CLI restart it uses (`crates/gear-engine/src/restart.rs`) is written for lane seats (`SeatRole::Lane` state transitions). So a Codex reviewer whose weekly limit is spent still sits idle with its packet undelivered; it does not yet move to `opencode-go/deepseek-v4-pro`. M3.1's done clause (2) needs that path (the shape T-114 builds for a pi lane: leave the agent, start the next chain entry, deliver the task again).
