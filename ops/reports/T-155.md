## What changed

**`crates/gear-board/src/idle.rs`** (new module of `gear-board`):

```rust
pub enum IdleReason { Quota { until: Ts }, Parked { until: Option<Ts> }, Held { reason: String },
    Waiting { on: String }, DepWait { task: String, on: String }, Undelivered { task: String }, NoWork }
pub fn idle_reason(tx: &Tx, project: &str, lane: &str, now: Ts) -> GearResult<Option<IdleReason>>;
pub fn describe(reason: &IdleReason, tx: &Tx, project: &str) -> String;
```

The reasons are looked for in the order of §8.2, and the first fact that
fits wins:

| reason | the fact of the store | shown |
|---|---|---|
| `Quota { until }` | the seat is parked on quota | `quota until 15:12` |
| `Parked { until }` | the seat is parked | `parked until …` |
| `Held { reason }` | the seat is held | `held: …` |
| `Waiting { on }` | a task of the lane has `wait_on` (§5.3) | `waiting for T-m (lane, stage)` |
| `DepWait { task, on }` | the next task of the lane waits for a dependency that is not done | `next T-x waits for T-y (lane, stage)` |
| `Undelivered { task }` | the next task of the lane is ready and no attempt of it was made | `next T-x is ready but not delivered` |
| `NoWork` | nothing is left in the lane's queue | `nothing left planned` |

- **A lane that works has no reason** (`None`): it has an attempt in flight
  (Delivered, Started, Stopped or Unknown).
- The **declared wait** comes before the working check: §5.3 leaves the
  attempt of the task Started while the lane waits, so the wait is the reason
  the user needs.
- The **queue** of a lane is its tasks in the order of the plan (a task that
  is not in the plan yet — a draft — is not in it). The *next* task is the
  first one that is not finished.
- The **quota park** is the seat's reason (`quota: <model>; resume at
  <time>`) or the seat's open quota pause of the store (§5.4); its deadline
  is the pause's end, the engine's own `engine.resume.<seat>`, or the time in
  the seat's reason. A quota park whose deadline has passed is not the
  reason any more (§9.2): the engine continues the lane then, and the seat is
  only parked until it does.
- The **park** of the plan (`until=<RFC 3339>`) is read into a time; a park
  that names a task (`until-task=T-n`) has no time, so the text is the
  design's `parked until …`.
- The **clock** is the user's own (`libc::localtime_r`), so `quota until
  15:12` is the time the user sees on the wall.

**`crates/gear-board/tests/it/idle_contract.rs`** — one store fixture per
reason: the reason and its text. A lane with a Started attempt has none.
