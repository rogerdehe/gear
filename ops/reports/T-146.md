# T-146 — review rounds through session preparation

Scope: Review worktrees use direct Git, dirty changes are stashed and reported, and review delivery waits for session preparation. Reviewers are selected using the earlier review seat first, then compatible standby or released seats; the job is bound in the delivery transaction. The writer's sent_at is preserved.

Files: `crates/gear-engine/src/review.rs` — Git worktree preparation, branch-holder protection, seat selection and delivery gating. `crates/gear-engine/src/session.rs` — persist review action and session atomically and correct V1 for an absent reviewer whose old binding still names its session. `crates/gear-engine/src/lib.rs` — inject the Git executor. `crates/gear-engine/tests/it/` — migrate review-related integration fixtures to the direct Git protocol.

Verification: `cargo test -p gear-engine --lib` → 191 passed. Real Git fixture tests exercise checkout, dirty stashes, notices, and a live versus dead branch holder. Integration tests use a fake Herdr and injected Git executor. `scripts/test.sh` → 1116 passed, 0 skipped; suite 51 s. Three unchanged merge tests and one CLI fixture exceeded 10 s.
