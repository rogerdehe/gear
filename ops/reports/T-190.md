# T-190 — a plan park ends

Scope: a lane the plan parked (`- park <lane> until=…` / `until-task=T-n`)
stayed Parked after its time had passed: no staff line could move it, and the
captain went hold, then release. Two parts: the release of a parked lane, and
the end of a park whose time has come.

## What changed

**`crates/gear-app/src/plan.rs`**

- `release_lane` accepts a **Parked** lane exactly as a Held one: the agent
  is in the binding's pane → **Active**, else **Queued** (the engine onboards
  it again). The refusal for a lane in any other state keeps its wording.
- `end_parked_lanes(tx, project, agents, now)` (new, public): a lane Parked by
  the plan whose `state_reason` is `until=<RFC3339>` at or before now, or
  `until-task=T-n` with T-n done, goes **Active** (its agent is still in the
  pane) or **Queued** (the agent is gone), with the reason `park ended`. A
  lane parked on **quota** (the engine's `resume:<seat>` meta) is left to the
  quota path. A park whose time has not come stays.

  The plan's apply calls it before its own staff lines: a park the captain
  writes now is not ended by the same apply.

**`crates/gear-engine/src/lib.rs`** — the tick calls the same function every
tick (one line), and the tick report names the lanes whose park ended
(`park_ended`).

`gear plan check` does not exist yet; when it does, it calls the same
function.

## Tests

`crates/gear-app/tests/it/plan_staff_contract.rs`:

- `a_parked_lane_is_released` — `- release heat` on a parked lane: the agent
  is in its pane, so the lane goes Active;
- `an_expired_park_ends_on_the_apply` — the park's time is an hour before the
  apply: the lane works again, with the reason `park ended`;
- `an_unexpired_park_stays` — the park lasts;
- `an_until_task_park_ends_when_the_task_is_done` — the park ends when the
  task it waits for is done;
- `a_quota_park_is_untouched` — the engine's quota park (the `resume:<seat>`
  meta) stays with the quota path.

`crates/gear-engine/tests/it/park_end_contract.rs` (new):

- `the_tick_ends_a_park_whose_time_has_come` — the tick ends the park, the
  lane is Active and the tick report names it;
- `the_tick_leaves_a_park_whose_time_has_not_come`;
- `the_tick_leaves_a_quota_park_to_the_quota_path`.

## Open questions

A park whose end cannot be judged (the session's agents were not read) stays:
nobody may say whether the lane's agent is still there. The plan's apply and
the engine's tick both read the session, so this only happens when the read
itself failed.

`Parked → Queued` is not one of the seat transitions the model allows, so
the lane is let go first (`Parked → Held → Queued`), the same way a released
lane is.

## Out of scope

The tail (`- tail: <lanes> until=…`), which ends by itself already (B6).
