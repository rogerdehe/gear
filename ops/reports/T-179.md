# T-179: accept pull-request merge mode

Removed the validation refusal for `merge = "pr"`. Project-level and child-repository GitHub configurations can now select PR landing; existing validation of repository identities and labels remains in place.

Tests exercise both configuration scopes and check that the parsed, validated repository resolves to PR merge mode.

`scripts/test.sh` passed 1,287 tests (one leaky; build 21 seconds, suite 158 seconds). The CLI initialization test also verifies that PR mode is persisted.
