# T-140 — `- release <reviewer>` releases a Standby reviewer seat

Scope: T-140 — design §3.6 (third bullet): the `# Staff` line `- release
<reviewer>` lets the captain let an idle reviewer go. A reviewer seat in
`Standby` — its agent alive, its pane open, no job — goes to `Releasing` and
the engine closes the pane as for any release; a reviewer that is reviewing is
refused with the task it is reviewing (`<name> is reviewing T-n`); a reviewer
in any other state is refused with the reason. The lanes behave as before
(T-133).

verification)
