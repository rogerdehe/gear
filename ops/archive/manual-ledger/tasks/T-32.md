## Goal

Wire `cmd_run` in `crates/gear-cli/src/main.rs` (design/08 "Startup", steps 1, 3, 4; step 2's config display and the host/session check come later):
1. Single-instance lock on `<dir of GEAR_DB>/engine.lock` with std `File::try_lock()` (stable since Rust 1.89; no new crates). Not acquired → `ErrorCode::Forbidden` "engine already running" and exit; the lock is held for the life of the loop.
2. `ops::recover_on_start(store, now)`; print one line per recovered op.
3. Loop: `gear_engine::tick(store, herdr, cfg, now)` every `cfg.tick_s` seconds; a tick error is printed and the loop continues; print a one-line summary only when the `TickReport` is non-empty.

Testability, as T-29: a private helper with everything injected and a bounded number of ticks —

```rust

```

`cmd_run` is glue (`open_store`, `SocketHerdr`, `EngineCfg::default()`, real clock and sleep, `ticks = None`). Tests do not sleep: `run_engine` sleeps only between ticks and only when `ticks` is `None`.

### Progress notes
- 1. `take_engine_lock(dir)`: creates the directory, opens `engine.lock` and takes `std::fs::File::try_lock()`; a held lock is `Forbidden` with "engine already running" in the detail, any other lock error is reported as `BadFormat`. The handle is the lock — dropping it releases it, which `lock_released_on_drop` pins (the second acquisition inside the block fails, the one after the drop succeeds). `cmd_run` keeps the handle alive for the whole loop.
- 2. `run_engine` recovers first (one clock call) and then ticks `ticks` times (or forever, sleeping `cfg.tick_s` between ticks only when `ticks` is `None`); each tick prints one summary line only when its `TickReport` differs from the default, and a tick error is printed while the loop continues. `run_engine_with` takes the tick call injected so `tick_error_does_not_stop_the_loop` can drive the error path (T-4's `tick` errors only on store failures, which a test cannot provoke).
- `recovers_then_ticks_n_times` is **not** ignored: T-4 is merged, so the real `tick` runs. An op left Executing becomes Unknown before the first tick, and the clock is called once for the recovery plus once per tick (3 calls for `ticks = Some(2)`).
- `cmd_run` is glue: `GEAR_DB`'s directory for the lock, `open_store`, `open_herdr`, `EngineCfg::default()`, the real clock and no tick bound.
