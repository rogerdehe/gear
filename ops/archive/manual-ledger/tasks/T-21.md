- 1+2. `observe::reconcile`: one `SeatObs` per seat of the project. A seat that expects no agent (Queued, Released, Starting, Releasing — the states the `Presence::NotExpected` doc names) is judged no further. The screen is read only for an idle/done agent and only when the profile is known (one tail read, `classify_screen`, Busy ⇒ not idle); a working agent, an unknown profile or a failed tail read all fail closed (not idle).
