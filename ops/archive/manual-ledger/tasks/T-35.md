### Progress notes
- 1+2. `decide` follows the doc comment's order: no observation, a seat that is not Active/Standby/Retiring, a pending delivery, a non-idle agent, a RateLimit/Quota/Auth screen flag, and the cooldown each return `None` with a reason. Then: Started/Stopped → `Continue` (or `Escalate` once `nudges_since_progress >= nudge_budget`), Submitted → `Assign` only when `safe_for_next`, no attempt → `Assign` the first ready task. Retiring seats and temp workers never `Assign` (a `Continue` is still allowed), and a `Delivered`/`Unknown` attempt counts as in flight so a second task is never put on the seat. Terminal attempt states (which the `LaneView` contract excludes) fall back to the free-seat path.
