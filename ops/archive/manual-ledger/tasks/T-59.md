- `begin_onboard`: the seat must exist (`NoTarget`); it starts from `Queued` (freshly registered) or from a state the model allows to reach `Starting` (`Missing`/`NeedsCheck` for a restart); every earlier binding of the seat that is not Void becomes Void (generations 1..=the seat's generation); the generation becomes `generation + 1`; the seat moves to `Starting`; a Pending binding (`pane_id`, `kind`, session = the project's Herdr session, `session_ref` empty) is inserted for the new generation, which is returned.
- `finish_onboard`: the seat must exist; a generation that is not the seat's current one is `StaleGeneration` (checked before the binding, so a late call from an old session is stale and not a bad transition); a binding that is not `Pending` is `BadTransition`; the seat must be able to reach `Active` (Starting → Active); the binding becomes `Active` and carries Herdr's `session_ref` when it reported one; the seat moves to `Active`.
