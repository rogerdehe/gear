## Goal

`gear --show T-<n>` prints the task packet: identity as for the home page (a registered seat of the project), then `gear_app::plan::render_task_packet(tx, project, task)` on a read transaction; plain text only (`--json` → the text as a JSON string). Other `--show` targets (`queue`, `draft`, …) stay `BadFormat` naming the target; `--diff`/`--all` stay rejected. Same pattern as T-30: a private `run_show` with everything injected, tested with `FakeHerdr` and an in-memory store; `cmd_home` dispatches to it when `--show` names a task.
