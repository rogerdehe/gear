# T-98 — two faults from the live acceptance

Scope: T-98 — (1) the GitHub COMPLETION marker said the lane was the reviewer
(`reviewer=sandbox:calc`) and always claimed `ci=pending`; (2) the `running/`
fixture had no origin, so the adoption run needed one made by hand.

Branch: base/t98 (code @ the hand-in commit; origin/dev merged before
verification, gate green on the merged result)

What changed:
- `crates/gear-forge/src/marker.rs` — the COMPLETION marker is now two honest
  lines, with BMAD-Team's field names:
  - `hand_in(agent, rounds)` → `<!-- ORCHESTRATE:COMPLETION agent=<lane seat>
    rounds=<n> -->`, the **writer's** completion;
  - `completion(reviewer, rounds, ci)` → `<!-- ORCHESTRATE:COMPLETION
    reviewer=<reviewer seat> rounds=<n> [ci=<state>] -->`, the **reviewer's**,
    where `ci` is written only when it is known — never guessed as "pending".
- `crates/gear-forge/src/sync.rs` — the hand-in comment carries the lane's
  `agent=` completion; the verdict comment carries the reviewer seat's
  `reviewer=` completion (no `ci`); the landing comment carries the same
  reviewer and round with `ci=pass`, because that merge just ran the gate and
  is the one place the state is known.
- `scripts/fixtures/make.sh` — `running/` gets its own local bare origin
  (`origins/running.git`, on `main`), added as an absolute path and pushed, so
  a GEAR project registered on the fixture has a registered destination for the
  push allow-list (T-72). `FIXTURE.md` says so, and why.
- `crates/gear-forge/tests/it/marker_contract.rs` — the writer's marker names
  the lane (never a reviewer), the reviewer's names the reviewer, and an
  unknown `ci` is omitted rather than invented.
- `crates/gear-forge/tests/it/sync_contract.rs` — the hand-in comment asserts
  `agent=p:heat rounds=1`, the verdict `reviewer=p:review-1 rounds=1`, and the
  landing `reviewer=p:review-1 rounds=1 ci=pass`.
- `crates/gear-cli/tests/it/fixtures_contract.rs` — `running/`'s origin is a
  local path ending in `origins/running.git`, and its `main` is on that bare
  repository.
- `ops/reports/T-98.md` — this brief.
