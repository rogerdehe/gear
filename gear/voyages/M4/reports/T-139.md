# T-139 — messages to a reviewer carry its task, the hand-in reply, `gear reply --reopen`

Scope: T-139 — design §3.8 (a message to a reviewer seat carries its task:
the reviewer's own messages take the task its seat is bound to, an
instruction the captain addresses to it without `--task` takes its
`task_id`, an idle reviewer is refused), §10.7 row B03-04/10 (the answer a
hand-in gets) and §10.7 row B03-07 (`gear reply` resolves by default, and
`--reopen` reopens an item resolved by mistake).

Branch: mast/t139 (code @ the hand-in commit; origin/dev merged before final
verification)

Files:
- `crates/gear-app/src/mail.rs` — §3.8: a reviewer seat is bound to a task for life, so the messages it writes carry that task (`send`); the captain's instruction to a reviewer seat without `--task` takes the seat's `task_id`, and a reviewer with no job is refused with "`<reviewer>` has no review job; nothing would show". The answer to a reviewer's question copies the task and the attempt of the message it answers (already the case) — the new test proves the whole path now: the question is about T-n, so the answer is too, and it shows on the reviewer's home page. §10.7 row B03-07: the new reply mode `Reopen` opens a resolved item again (and answers nobody); `handlable` states which state a mode may touch.
- `crates/gear-cli/src/main.rs` — §10.7 row B03-04/10: `gear send --kind result` answers the hand-in with "Handed in. End your turn: the next task comes by itself; do not push to `<lane>/t<n>` again." (the branch is the task's own). §10.7 row B03-07: `gear reply --reopen`, and the help of `gear reply` says that the default resolves.
- `crates/gear-app/tests/it/reviewer_mail_contract.rs` — the contract tests: a reviewer's question carries its task; the answer to it shows on the reviewer's home page; an instruction without `--task` to a reviewer in a job carries it; the same instruction to an idle reviewer is refused; a resolved item is reopened (and a reopen of an open item is refused).
- `crates/gear-app/tests/it/main.rs` — registers the new test module.
- `crates/gear-cli/src/main.rs` (tests) — the hand-in answers with the new text; `gear reply --reopen` reopens a resolved item; the help of `gear reply` states the default and names `--reopen`.
- `skills/gear/references/captain.md` — the captain's daily loop names `--reopen` next to the reply.
- `ops/reports/T-139.md` — this hand-in.

If the captain wants the message form, it needs a keel task to change that contract.
