# T-189 — the verdict quote rule exactly

Scope: the closing quote of a quoted value in a `# Verdicts` line (T-141,
round 2, F1): the last quote on the line, without the field-boundary
heuristic.

## What changed

**`crates/gear-app/src/draft.rs`** — `find_closing_quote` returned the first
quote that ends the value, guessing from what followed it: the end of the
tail or the start of the next `key=value` field. The guess read the literal
`estimate=25` **inside** a quoted text as the start of a field and cut the
value short, so a verdict that quotes a field of its own was refused with
"the quoted value must be the last field".

The closing quote is now the **last quote on the line** (the captain's
rule): the prose between the quotes may hold quotes of its own. The
field-boundary heuristic and its helper (`starts_a_field`) are gone.

Unchanged: a line without a closing quote is `BAD_FORMAT` ("a verdict line's
quoted value has no closing quote"), and a non-empty suffix after the closing
quote is still the existing last-field error that names the order.
