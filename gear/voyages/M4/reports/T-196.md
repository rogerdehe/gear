# T-196: role rules at agent start

Lane and reviewer rules are embedded from their respective skill reference files, written atomically beside the database under `rules/` only when their content changes, and appended with the current voyage's done and bar lines. Profile instruction arguments are inserted after unattended arguments for onboarding, in-place restarts, reviewer starts and session-runner resumes. Captains receive no rules arguments; OpenCode's empty instruction template adds none. Busy-start retries refresh the file and any inline arguments.

Fake-Herdr tests cover pi lane starts and resumes, codex reviewer arguments and rule text, OpenCode's unchanged arguments, the captain exemption, current-voyage selection and unchanged-file behavior. Existing start tests now use temporary database paths and assert the additional arguments. `scripts/test.sh` passed: 1,277 tests, zero failures (41 s build, 83 s suite). The first test run exposed fixture assertions that expected the old arguments; those were updated before the passing run.
