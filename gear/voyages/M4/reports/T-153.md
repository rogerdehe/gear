# T-153: dispatch through the session rule

Lane dispatch creates an attempt before preparing its session and retains unsent attempts across ticks. Only a Ready preparation produces the task delivery; the successful Herdr submission records `sent_at`. Follow-ups whose earlier session could not be used include the requested report line. A refused prompt leaves `sent_at` unset.

A missing or restarted agent with an open round runs S1 through the session runner without creating another round. A completed resume pins its target for that round, so the transient hand-restart session cannot cause a second resume. An unconfirmed delivery may be retried once after S1 restores the same session, and remains guarded against repeated sends to the same running agent. Onboard records a generation-specific fresh marker in the same transaction that activates the seat; the first round consumes it, while related work still resumes its prior session.

The fake-Herdr tests cover preparation waiting, assignment and `sent_at`, refusal, L7 follow-up text, fresh onboarding, related-session resume, and S1 recovery. Existing blocked-delivery, retry, merge, and quota tests retain their checks with session-aware timing and fixtures.
