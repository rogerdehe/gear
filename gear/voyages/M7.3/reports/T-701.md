# T-701 — Record the model of every attempt

## What changed (`crates/gear-app/src/tasks.rs`)
- `pub fn attempt_model_key(project, task, n) -> String` → `attempt.model:<project>:<task>:<n>`.
- `start_attempt`: after the attempt row and its delivery time, writes that key with the value of
  `engine.model.<seat>` when that meta is non-empty; a seat with no model meta writes nothing.
- `record_own` (the captain's done line): writes the same key with the captain seat's `engine.model.<seat>`,
  or `<binding kind> (captain)` when that meta is absent (the binding of the seat's current generation; no
  binding → nothing written, an edge case outside normal use).

## Tests
- `tasks_contract`: a started attempt of a seat whose meta names a model carries it under the key; a seat
  with no model meta writes nothing.
- `captain_alone_contract`: a captain done line writes `claude (captain)` with no model meta, and the model
  meta's value when one is set.

## Check
`make check CRATE=gear-app` — 803 passed; `cargo fmt --all --check` clean.

## Out of scope
- A captain seat with no binding (only possible when `captain_of` is empty and the caller names a seat with
  no binding row) writes no model key; the packet names only the binding-kind fallback.
