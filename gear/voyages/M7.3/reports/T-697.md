# T-697 — The plan and the coverage report accept a squash, and an integrated-by pass with only voyage files missing

## What changed
- `crates/gear-app/src/plan.rs`:
  - `on_integration` (the plan's merged check) now uses `crate::base::landed_in`, so a candidate landed by a
    squash is merged through the `Gear-Candidate`/`Gear-Source` trailer; a git error is still `BadFormat`.
  - `require_integrated_by`: a candidate that is not landed is accepted when `git diff --name-only
    <reference> <candidate>` is non-empty and every path is under the project's voyage folder
    (`Repo.voyage_dir` with `{project}` filled, `{milestone}` matching any one folder); otherwise the
    refusal keeps today's text. Helpers `changed_between` and `under_voyage` added.
- `crates/gear-cli/src/main.rs`: `GitOnIntegration::contains` (the coverage report's commit check) uses
  `gear_app::base::landed_in`, keeping its fail-closed `false` on an unreadable answer.

## Tests
- `plan::integration_check_tests::a_squashed_candidate_is_on_the_integration_branch`: a squash commit naming
  the candidate by `Gear-Candidate` makes it merged; an unresolvable sha is not.
- `integrated_by_contract`: a squashed candidate counts as merged; a candidate differing only in
  `gear/voyages/M1/reports/T-1.md` is applied; one differing in `src/heat/x.rs` is refused with today's text.
- `gear-cli`: `the_coverage_report_accepts_a_squashed_candidate` — the squashed candidate is not listed.

## Check
`make check CRATE=gear-app` — 800 passed; `make check CRATE=gear-cli` — 215 passed; `cargo fmt --all --check`
clean.

## Out of scope
- The voyage-only acceptance requires a non-empty diff: a candidate with the same tree as the integration
  branch but no ancestry stays refused, as T-205's existing test requires ("differs only in voyage files"
  means it differs). Logged as the one judgement the packet left open.
- Paths with spaces are quoted by `git diff --name-only` and would not match the voyage prefix (edge case).
