# T-694 — a feature lands by replaying its commits

## What changed

- `crates/gear-engine/src/merge.rs` `prepare_merge`: for a feature's
  integration task (`op.payload["keep_branch"] == true`) in squash mode, the
  merge loop is replaced by a replay: `git rev-list --reverse --first-parent
  --no-merges <base_ref>..<task_tip>` names the feature's own commits, each is
  cherry-picked in order (`--allow-empty --keep-redundant-commits`), and the
  last commit's message is amended to append `Gear-Source: <task_tip>` and
  `Gear-Candidate: <sha>`. The feature's commits keep their own messages and
  trailers, and the squash block is skipped on a successful replay.
- A replay that conflicts runs `git cherry-pick --abort`, `git reset --hard
  <base_ref>`, and falls back to the task squash path with the body line
  `- replay conflicted; squashed`; the feature's resolved tree is what lands.
- The gate still runs once, after `prepare_merge`, on the replayed or squashed
  result.
- Merged `origin/dev` (T-693 landed there) into `hull/t694`; the merge was
  clean.

## Tests (acceptance)

- `merge::tests::a_feature_replays_its_commits_onto_the_integration_branch`:
  a feature branch with two squashed member commits and a merge of dev lands
  as those two commits on dev, in order, no merge commit, the last one with
  `Gear-Source`/`Gear-Candidate`; the gate ran once.
- `merge::tests::a_feature_whose_replay_conflicts_lands_as_one_squashed_commit`:
  a conflicting replay lands one squashed commit with
  `- replay conflicted; squashed`, the resolved tree, and the gate once.
- `make check CRATE=gear-engine TESTS='test(merge)'` — 173 passed, 0 failed.
- `make check CRATE=gear-engine` — 1231 passed, 0 failed, 23 skipped.

## Check

The two commands above are the project's capped check for the crate.

## Out of scope

- A feature branch whose replay range is empty answers `Merged` (nothing new
  to land); outside the named normal use.
- A cherry-pick that fails for a reason other than a conflict (a dirty
  worktree) takes the same abort/reset/squash fallback.
- The `merge_method = "merge"` path is unchanged: a feature still lands as a
  merge commit there.
