# T-702 — Measure each model's speed

## What changed
- `crates/gear-app/src/time.rs`: `pub fn dev_of(times: &AttemptTimes)` — the dev time (start → hand-in) as
  the one computation; `round()` now calls it, so `gear report time` and the speed module share it.
- `crates/gear-app/src/speed.rs` (new, `pub mod speed;` in `lib.rs`): `ModelSpeed` and `measured(tx, now)` —
  every project's attempts from the last 90 days that were handed in, work time from `time::dev_of`, estimate
  `estimate_min` for attempt 1 / `rework_estimate_min` for later (no estimate → work time only), model from
  `attempt.model:` meta else the seat's `engine.model.<seat>` else skipped; captain-alone done tasks measured
  merge → previous captain-done merge of the same voyage (or the voyage's departure for the first); sorted by
  samples, most first. `calibrated(speeds, model, estimate_min)` = `estimate_min × median_ratio` rounded,
  only at ≥ 5 samples with a ratio.

## Tests (`speed.rs`)
- three models with known attempts: samples, medians and ratios; an attempt without an estimate counts for
  the work time only; a captain-alone voyage's two done tasks measured 10 min from departure and 10 min from
  merge to merge; `calibrated` None at 4 samples, 15 at 5 with ratio 1.5.

## Check
`make check CRATE=gear-app` — 804 passed; `cargo fmt --all --check` clean.

## Out of scope
- T-701's `crate::tasks::attempt_model_key` is not on `dev` yet, so `speed.rs` carries a private copy of the
  key format (`attempt.model:<project>:<task>:<n>`); point it at T-701's function once that lands.
- `calibrated` reads "at least 5 samples with a ratio" as `samples >= 5` and a positive median ratio: the
  struct the packet fixes has no separate ratio-sample count, so a model with 5 samples but fewer ratios is
  calibrated from the ratios it has.
- A captain's own done task with no milestone is skipped (no voyage to measure from).
