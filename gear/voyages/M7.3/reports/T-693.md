# T-693 — rework attempt 2 (F1)

## What changed

F1: a merge op without a goal no longer falls back to the unfilled merge
template (`merge(T-5): {source}`). The squash subject is now built from the
task id alone.

- `crates/gear-engine/src/merge.rs` `prepare_merge`: the empty-goal fallback
  passes an empty goal to `squash_message` instead of `commit`.
- `crates/gear-model/src/commit.rs` `squash_message`: an empty goal writes the
  task id alone (`T-n`) as the subject, with no `": "` and no placeholder; a
  non-empty goal is unchanged.
- `crates/gear-engine/src/merge.rs` tests: the train test now accepts the task
  id alone as a subject and asserts no `{` in either subject.

## Tests (acceptance)

- `merge::tests::a_squash_without_a_goal_lands_the_task_id_alone`: a merge op
  whose payload has no `"goal"` lands subject `T-5` and no `{`.
- `merge::tests::a_squash_merge_lands_one_commit_with_the_lane_subjects_and_trailers`
  and `merge::tests::a_squash_train_lands_one_commit_per_task_in_order` still
  pass.
