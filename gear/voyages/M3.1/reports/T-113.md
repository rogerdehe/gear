## The live facts (pi 1.4.0 on this machine, Herdr 0.9.1)

Every text below was taken from pi's own output, not from its source:

| Fact | Where it came from |
|---|---|
| `--model <provider>/<id>`, `--thinking <level>`, `--approve`, `--session <path\|id>` | `pi --help` |
| skills live in `<agent-dir>/skills/`, agent dir `~/.pi/agent` | pi 1.4.0 `docs/configuration.md`, `docs/skills.md` |
| `/quit` quits pi | pi 1.4.0 `docs/slash-commands.md`; live: the agent is gone and the shell prompt is back |
| `escape interrupt · ctrl+c/ctrl+d clear/exit` | the TUI's own startup line |
| busy ` Working` | the TUI while a turn runs: `── ⠋ Working ────` (also `── ⠧ Working ────`) |
| quota `insufficient_quota` | `pi -p` against a local endpoint that answers 429 with OpenAI's quota body: `429: {"message":"You exceeded your current quota, please check your plan and billing details.","type":"insufficient_quota","code":"insufficient_quota"}` |
| rate limit `rate_limit_error` | the same, with a rate-limit body: `429: {"message":"Rate limit reached for mock-model","type":"rate_limit_error","code":"rate_limit_exceeded"}` |
| auth `No API key found for anthropic.` | `pi -p --model anthropic/claude-sonnet-4-5` with no key; the TUI shows ` Error: No API key found for anthropic.` |
| back-off `Retrying (3/3) in 7s...` | the TUI while pi retries: `── ⠙ Retrying (3/3) in 7s... (escape to cancel) ────` |
| guardrails `Command auto-denied:` | the TUI after pi asked for `sudo -n systemctl status`: `Command auto-denied: No privileged commands in an unattended lane.` |
| guardrails `is blocked (outside working directory)` | the TUI after pi was told to write `~/probe.txt`: `Access to ~/gear-guardrails-probe.txt is blocked (outside working directory).` (the file was not created) |
| the session is a file; `--session <path>` resumes it | Herdr reports `agent_session.value` = `…/sessions/…/2026-10-26T04-33-21-698Z_01a1767c-….jsonl`; restarting with that path reopened the transcript |
