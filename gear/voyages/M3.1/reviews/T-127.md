## Findings

F4 [P2, logged; carried forward] FIFO test handshakes have no failure bound — `crates/gear-engine/src/merge.rs:3135` — opening/reading `running` and writing `release` can block forever if a worker fails before reaching its gate or exits between handshakes. `WAIT` bounds worker progress waits, not these FIFO helpers. This remains the earlier error-path edge and is explicitly optional in the rework, so it does not block the DELIVERABLE bar. A later change can bound the handshake through a channel result with a timeout, without adding polling sleeps.

F5 [P2, blocking] An engine test still sleeps on the wall clock — `crates/gear-engine/src/onboard.rs:1212` and `crates/gear-engine/src/opencode.rs:177` — `an_empty_model_list_is_waited_for` sets `model_list_wait_s = 5` and `model_list_poll_ms = 10`, queues an empty model list followed by a loaded list, then calls `onboard_queued`. The first response becomes `Lookup::NotLoaded` and `start_args` executes `thread::sleep(Duration::from_millis(10))` before consuming the second response. Moving the switch settle to Herdr does not cover this path. This fails the explicit mechanical “No test may sleep on the wall clock” requirement of the DELIVERABLE test-time fix; the report's opening no-sleep claim is still false. Smallest fix: set this test's existing `model_list_poll_ms` configuration to 0 and guard the sleep in `opencode::start_args` with `if model_list_poll_ms > 0`, keeping the positive production defaults and every existing assertion (about 4–6 lines across these two files). The fake's queued second response supplies progress without a clock wait. Correct the report as needed, rerun this filtered test, and run the required gate once to verify the timings stay within the amended acceptance. No new sleep, allowlist entry, or weakened assertion is needed.
