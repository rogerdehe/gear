# T-656 — the engine prunes old plan versions of every project once a day, captain running or not

Candidate: 8763e894 (branch hull/t656)

## What changed (crates/gear-engine/src/lib.rs only)

- `const PLAN_PRUNE_EVERY_S: Ts = 24 * 3600;` and
  `const PLAN_PRUNE_KEY: &str = "engine.plans_pruned";`.
- `pub fn prune_plans(store, now) -> GearResult<Option<usize>>`: reads the key,
  returns `Ok(None)` while `0 <= now - last < 24 h`; otherwise prunes in one
  `store.write` (`tx.prune_plan_versions()` then the key set to `now`) and
  returns the count. An absent key prunes at once, then every 24 h.
- `TickReport` gained `pub plans: Vec<String>` with the packet's doc comment.
- `tick` runs the prune as its first step, before "reconcile rebinds": a count
  over zero is reported as `<n> old plan version(s) deleted`, a failure as
  `plan prune failed: <code>: <detail>` (the tick goes on), and the step is
  timed with `note_slow(..., "plan prune", ...)`.

## Tests (`mod plan_prune_tests`)

- `prune_runs_at_start_and_then_once_a_day`: `Ok(Some(0))` at T0 with the key
  set, `Ok(None)` at T0+3600, `Ok(Some(0))` at T0+24h.
- `the_tick_reports_nothing_when_nothing_is_pruned`: an empty in-memory store
  with `FakeHerdr::new()` and `EngineCfg::default()` leaves `report.plans` empty
  and sets the meta key.
