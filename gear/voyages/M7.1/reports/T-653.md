# T-653 — an inline ring does not repeat the captain's goal line that an item body already starts with

Candidate: 29db0896 (branch hull/t653)

## What changed (crates/gear-engine/src/doorbell.rs only)

- Added private `goal_prefix(goal: &str) -> &str`: the goal up to and including
  its first `:` (the whole goal when it has none).
- `inline_text`'s goal loop now skips a goal when any entry's `item.body`
  starts with `goal_prefix(goal)`; otherwise it appends the goal as before.
- Nothing else changed: the one-line paths (`decide`, the single-seat `with_goal`
  call, the joined one-line loop) show no bodies, so the goal line stays there.

## Tests (mod tests)

- `an_inline_ring_does_not_repeat_a_goal_its_item_starts_with`: the item body
  starts with the same `Your goal, voyage M1:` prefix (its course differs); the
  text carries that prefix once and ends with the full reply line.
- `an_inline_ring_keeps_a_goal_of_another_voyage`: the body names M0, the goal
  M1; the goal line is appended.
- `a_goal_line_follows_the_inline_text` passes unchanged.
