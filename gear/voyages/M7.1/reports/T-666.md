# T-666 — prune every project's old plan versions on request

## What changed
- `crates/gear-store/src/lib.rs`: added `Tx::prune_plan_versions(&self) -> GearResult<usize>` next to
  `Tx::insert_plan` (which keeps its own T-646 delete unchanged). One statement:
  `DELETE FROM plans WHERE version <= (SELECT MAX(p2.version) FROM plans p2 WHERE p2.project = plans.project) - ?1`
  with `params![PLAN_VERSIONS_KEPT]`, `.map_err(map_sqlite)?`, returning the deleted row count from
  `execute`. It covers every project id present in `plans`, whether or not it is registered in
  `projects`. No VACUUM: SQLite reuses the freed pages.
- `crates/gear-store/tests/it/plan_versions_contract.rs`: new test `every_project_is_pruned_on_request`
  — file store, raw INSERT of 30 versions of "q" and 5 of "r", reopen, prune returns 10,
  `oldest_plan_version("q")` = Some(11), `plan_version("q")` = 30, `get_plan("q", 10)` None,
  `get_plan("q", 11)` Some, `oldest_plan_version("r")` = Some(1), second call returns 0.

## Check
`make check CRATE=gear-store TESTS='test(plan_versions)'` — 2 tests run, 2 passed (the existing
T-646 test and the new one). No other crate touched.

## Out of scope
- The engine does not yet call `prune_plan_versions` once a day; only the store API and its test are
  in this task.
