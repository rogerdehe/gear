# T-654 — a guardrails item rings only when the agent has stopped on the refusal, once per spell

Candidate: e178457f (branch hull/t654)

## What changed (crates/gear-engine/src/guardrails.rs only)

- Added `use gear_herdr::AgentStatus;`.
- Per seat, `stopped = matches!(obs.status, Some(AgentStatus::Idle | AgentStatus::Done | AgentStatus::Blocked))`.
- `refused` now additionally requires `stopped`.
- The recover branch is now `if obs.screen.is_some() && stopped { recover(...)?; }`.
- Module and `check` doc comments updated: the refusal is judged only on the
  screen of an agent that stopped; a working agent goes on after a refusal, and
  its screen neither opens nor closes the item.
- `observe.rs` untouched.

## Tests (crates/gear-engine/tests/it/guardrails_contract.rs)

- `a_working_agent_refused_does_not_ring`: Working + REFUSED → no ring, no item.
- `a_refusal_seen_while_working_then_stopped_rings_once`: Working+REFUSED at 0
  (nothing), Idle+REFUSED at 1 (rings), Working+CLEAN at 2 (item still Open,
  nothing rung), Working+REFUSED at 3 (nothing), Idle+REFUSED at 4 (nothing,
  still one item).
- `a_working_clean_screen_does_not_resolve_the_item`: ring at 0, Working+CLEAN
  at 1 keeps it Open, Idle+CLEAN at 2 resolves it.
- The five existing tests pass unchanged.
