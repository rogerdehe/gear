# T-683 — `gear issue file` / `gear issue show`: the captain files a bug through the engine

## What changed (`crates/gear-cli/src/main.rs`, unchanged from attempt 1)
- `Cmd::Issue { op: IssueOp }` with the doc line `Captain: file an issue on the project's forge (the engine
  files it).`; `IssueOp::File { title, body, labels }` and `IssueOp::Show { id }`.
- Dispatch in `run` next to the `Cmd::Plan` arms; `Cmd::Issue` is in the no-engine list.
- `run_issue_file`: the caller check and GitHub-mode check as `run_import_issues`, with `gear issue file`
  named in the messages; then one `store.write` reading `forge.issue_requests.<project>` (absent → `[]`,
  unparseable → BadFormat `the issue requests of <project> do not parse`), `id` = highest + 1, pushing
  `{"id","title","body","labels","number":null}` and writing it back. Returns `(id, repo)`.
- `cmd_issue_file` prints the named line, or `{"id":…,"repo":…}` with `--json`.
- `run_issue_show` / `cmd_issue_show`: captain or any registered seat of the project, read-only; prints
  `issue request <id>: filed as #<number>` or `issue request <id>: waiting for the engine`; an unknown id is
  NoTarget `no issue request <id> in project <project>`. The CLI never runs `gh`.

## Attempt 2 (rework): the acceptance test module
- New `crates/gear-cli/tests/it/issue_file_contract.rs`, built like `import_issues_contract.rs`
  (`CARGO_BIN_EXE_gear` with `GEAR_DB`, `GEAR_CTX=p:captain:1`, `HOME`, no Herdr), with the three tests the
  packet names:
  - `a_captain_files_an_issue_request`: the command succeeds, stdout holds `issue request 1 recorded`, the
    store's `forge.issue_requests.p` holds one request with id 1, the label and `number` null; a second call
    gives id 2.
  - `show_reads_the_number_once_filed`: with `"number":42` set, `gear issue show 1` prints
    `issue request 1: filed as #42`; `gear issue show 9` fails with `no issue request 9`.
  - `a_project_without_github_refuses`: without `[github]` the command fails with `not in GitHub mode` and
    writes no key.
- `mod issue_file_contract;` added to `crates/gear-cli/tests/it/main.rs`.
