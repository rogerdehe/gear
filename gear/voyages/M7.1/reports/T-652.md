# T-652 — F-341: a feature member's light stage check is not starved by seat stamps of finished features, and the carrier's review names members that got none

Candidate: 257b5c96 (branch hull/t652)

## What changed (crates/gear-engine/src/review.rs only)

1. Added private `seat_held_by_live_feature(store, project, seat)`:
   - no `feature_seat` stamp → false;
   - stamp names a feature with no carrier → true;
   - carrier task row missing → false; carrier terminal → false; otherwise true.
   The free-seat guard in `start_stage_checks` now reads
   `Some(seat) if !seat_held_by_live_feature(store, project, &seat.id)? => Some(seat)`,
   so a seat stamped by a finished feature is free for a live feature's first
   light check; the existing `set_feature_seat` overwrites the stale stamp.
2. The terminal-carrier skip for members (already in place) is untouched.
3. `feature_review_section` now carries an `unchecked` flag per member: the last
   attempt is `Accepted` and its `stage_check` marker (parsed JSON) does not have
   `state == "done"` (absent marker = unchecked). When any member is unchecked,
   the section appends
   `Members without a light check: T-a, T-b: review their changes in full.`
   in member order. It only informs; nothing waits on it.
