# T-668 — the engine's friction item names `gear friction close`, a resolve is refused

## What changed
- `crates/gear-app/src/friction.rs`: added `close_hint(tx, project, message)`. `None` unless the message is
  the engine's friction item (`thread == "friction"`, `sender == "engine"`, state Open or Waiting). Else it
  takes `tx.open_frictions(project)?`, picks the oldest by `(created, F-<n> as i64, 0 when it does not
  parse)`, returns `None` when none is open (the engine closes the item itself on its next tick), else
  `gear friction close <id> -m "lesson|fixed|not worth it (...)"`.
- `crates/gear-app/src/home.rs` `next_command`: the captain branch now checks `close_hint` after the station
  arm and before the verdict hint, returning `next: <command>`.
- `crates/gear-app/src/captain.rs` `needs_of`: after the station check, `close_hint` returns the command.
- `crates/gear-app/src/mail.rs` `reply`: right after the station refusal, a `Resolve` on such an item is
  refused with `message <id> closes itself when its friction reports are closed: next: <command>`; note and
  wait stay allowed.

## Tests (`crates/gear-app/tests/it/app_reply.rs`)
Helper `friction_item` inserts the engine's `friction` item and two reports (T-1, T-2).
- `a_friction_item_is_not_closed_by_a_resolve`: BadFormat, detail names `gear friction close F-1 -m
  "lesson|fixed|not worth it (...)"`, the item stays Open, a Note is accepted.
- `a_friction_item_names_its_oldest_report`: the captain's page names F-1; after closing F-1 it names F-2.
- `a_friction_item_without_open_reports_resolves`: both reports closed → the Resolve is accepted.
