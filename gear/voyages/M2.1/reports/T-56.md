Scope: T-56 — the skill teaches the captain to write a `deps:` only for work that cannot start without the other task's result, and to read the snapshot after every plan apply so no lane stands idle with nothing startable (ops/lessons.md 7a).

Branch: docs/t56 (code @ 6375ef7 plus the same-lane clause @ the hand-in commit; origin/dev 050eb93 merged before final verification)

Files:
- `skills/gear/references/decompose.md` — rule 6: `deps:` only on what a task cannot start without the other task's result — never on a neighbour's review, never because two tasks touch nearby files. An interface the two tasks share and that is already written down (function names, a config shape, an API) is no such result: write it into both goals, let the tasks run in parallel and let the later one rebase when the first lands. - `skills/gear/references/captain.md` — daily loop, step 3: after every `gear plan apply`, read the snapshot; a lane with no current task and nothing startable gets a task before you end your turn.
