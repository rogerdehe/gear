# T-612 — report

A lane busy with no open attempt while its next task waits is freed
(Prometheus T-778: a lane looped inside one turn retrying `gear send --task
T-778 --attempt 1` for a task not yet delivered, so it never went idle and the
urgent delivery waited; one Esc fixed it).

## What changed

- `crates/gear-engine/src/lane_nudge.rs`: `free_busy_lanes(store, herdr,
  project, observed, now)` runs from the lane-nudge step each tick. For a lane
  seat that is Active/Standby/Retiring, observed Working, with no open attempt
  (`dispatch::lane_view(...).attempt` is None), a Ready task for it, and a
  Deliver op intended (any slot op of kind Deliver), it keeps the first tick
  the condition holds. After 3 minutes it sends one Esc (`send_keys` "esc")
  into the seat's pane; 3 minutes later, if it is still working with no
  attempt, it opens one Info item to the captain on `busy-lane:<seat>`. The
  marks are cleared when the lane is idle, gets an attempt, loses its ready
  task, or its delivery is no longer intended. Never for a lane with an open
  attempt.
- `nudge_stopped_lanes` now takes the `HerdrAct` and calls `free_busy_lanes`;
  the Esc is reported in `lane_nudged`, the captain item in `flagged`.
- `crates/gear-engine/src/lib.rs`: the tick passes `herdr` to the nudge step.
- `crates/gear-engine/tests/it/lane_nudge_contract.rs`: the two direct calls
  pass the fake Herdr.

## Tests

`make check CRATE=gear-engine TESTS='test(lane_nudge::)'` — 8 tests, 8 passed.
New tests in `lane_nudge.rs` `mod tests` with the fake Herdr:

- `a_busy_lane_with_no_attempt_is_freed_with_one_esc`: a working lane with no
  attempt and a ready task gets one Esc after 3 minutes and one Info item to
  the captain after 6; no more items.
- `a_busy_lane_with_an_open_attempt_gets_nothing`: a lane with an open attempt
  gets no Esc and no item.
- `an_idle_lane_or_a_lane_with_no_ready_task_is_not_busy`: an idle lane and a
  working lane with no ready task get nothing.

`make gate` — 2604 tests, 2604 passed (36 s, under the 80 s limit).

## Out of scope

- The Esc is sent once per busy episode; if the lane is still busy after the
  captain item, no further Esc is sent (the captain owns it then).
- A lane whose delivery op is a Doorbell only (no Deliver) is not treated as
  "delivery intended".
