# M4.1 lessons

What M4.1 taught, recorded as it happened. A lesson holds for this voyage; only what the release review distils into the shipped skill (`skills/gear/`) carries over. Numbers are the ones lessons had in the old shared file, so earlier references still find them.

41. **A contract names only what exists, and follows each named seam to its end.** M4.1's T-227 contract named a push check and a store query that did not exist, and told the lane to add its seats to `report.flagged` without looking at what that list triggers (a second, generic stall alert). The MiniMax lane stopped to deliberate at each gap (two captain interrupts, contract v1 to v4, one rework); T-226, whose contract named only existing functions, was done in 10 minutes. Before sending a contract: grep every function, field and list it names, and read what each list it feeds into does.
