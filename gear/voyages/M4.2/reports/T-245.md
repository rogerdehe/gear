# T-245 — a direction check that stops is nudged like a review

Branch: hull/t245 (code @ dc2f1f39; merge of origin/dev in db73f10c)

## What changed

`crates/gear-engine/src/review.rs`, `nudge_stopped_reviewers`:

- the early `if direction_seat(...) { return Ok(None) }` is gone. A direction
  seat is now nudged on its own job:
  - the job in meta `direction_key(project, task, attempt.n)` must still say
    `"running"` (a `starting` job has no packet in flight yet, a finished one
    has nothing to nudge);
  - no result of this seat and generation is in
    (`direction_results_of_attempt(...)` with `sender == seat.id &&
    sender_gen == seat.generation`);
  - its attempt is `Started`, so the review test (`Submitted` and no verdict)
    runs only for the review case (`else if`).
- the cooldown, the slot-op check, `review_nudges_used` and
  `REVIEW_NUDGE_BUDGET` are used unchanged for both kinds.
- the nudge text is the direction one for a direction seat ("You are idle and
  your direction check on {task} is not in. … hand in with the
  `gear send --kind result --direction` command …") followed by the seat's
  packet (`packet_text`); the review text is untouched.
- `nudge_flag_current` applies the same direction rule: an exhausted direction
  seat is flagged exactly while its job runs and its result is not in, as a
  review seat is flagged while the attempt is `Submitted` and the verdict is
  not in.

## Tests

`crates/gear-engine/tests/it/reviewer_nudge_contract.rs`, new world
`direction_world` (attempt `Started`, job meta `running`) observed through the
Herdr fake (`observe::reconcile`):

- `an_idle_direction_seat_whose_job_runs_is_nudged`: nothing inside the
  cooldown; past it one Deliver op whose text starts with "You are idle and
  your direction check", carries the packet again and has `nudge == 1`;
- `a_direction_seat_whose_result_is_in_is_left_alone`: a direction result of
  the seat/generation in → no op;
- `a_working_direction_seat_is_left_alone`: an agent `Working` → no op;
- the existing review nudge tests are unchanged and pass.

`make check CRATE=gear-engine` after the origin/dev merge: 611 passed, 0
skipped. `cargo build --workspace --all-targets`: no warnings.

## Out of scope

- `review_progress` (used for the nudge budget) reads Progress messages only;
  a direction seat that answers an overrun question resets its budget the same
  way a review seat does — not changed, not asked for.
- The nudge budget and the stall flag are still shared per seat+generation, so
  a warm seat that ran both a direction check and a review of the same task
  and attempt counts its nudges across both. The flag test path
  (`nudge_flag_current`) is exercised only through the existing tick tests; no
  new test was added for the direction flag, as the acceptance named the
  three nudge cases.
