# T-482 — report

A reviewer's Herdr agent now carries its seat's name, `<project>-review-<k>`
(`p-review-1`), and keeps it across the tasks it reviews; the task under
review shows in its title (`Review T-<n>`), as the user decided at M1
(gear/voyages/M1/plan.md:25), not in the agent name.

## What changed

`crates/gear-engine/src/names.rs`:

- `desired(seat)` is `agent_name(project, seat.name)` for every seat — the
  captain, a lane and a temp reviewer alike; `review_agent_name` is gone.
- `restore` iterates the seats once: every seat's name is its own, so no pass
  has to give a task name back before another seat asks for it (the T-270
  two-pass partition is gone with the task-based names).
- The module comment and the `desired` doc state the seat-based rule.

Call sites: `review.rs` names the reviewer's agent after the seat
(`agent_name(config, &seat.name)`) and records that label; `session_runner.rs`
starts every seat, temp reviewers included, with `names::desired(seat)`.

`skills/gear/references/conventions.md`: the Reviewer agent row is
`<project>-review-<k>` (its seat's name; the task under review shows in its
title, `Review T-<n>`) — `acme-review-1`.

`docs/design/04-herdr.md`: the one sentence describing `names::desired` now
names the seat-based rule.

## Tests

- `crates/gear-engine/tests/it/agent_names_contract.rs`: the reviewer fixture
  is named `p-review-1`; `a_correctly_named_reviewer_gets_no_rename` and
  `a_cleared_reviewer_is_restored_to_its_seat_name_before_delivery` assert the
  seat name and the rename to it; `each_reviewer_keeps_its_seat_name_across_tasks`
  (was the T-270 name-freed test) asserts a finished reviewer and a seat
  starting a new review each get their own seat name, with nothing taken.
- `crates/gear-engine/src/review.rs`: the warm-seat test now sees
  `AgentStart` named `p-review-1` for both jobs — the name is kept across
  tasks; the recorded start label and the start test use `p-review-1`.
- `ops.rs`, `reviewer_nudge_contract.rs`, `dead_temp_slot_contract.rs`:
  fixtures follow their seat names (`p-r-1`, `p-review-1`).
