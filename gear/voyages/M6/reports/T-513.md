# T-513 — report (attempt 1)

A model-switch handover names the branch of the task the lane holds, not
whatever branch its worktree happens to be on.

## The change

`crates/gear-engine/src/handover.rs`:

- `Facts` gains `head`: the branch Git reports for the worktree
  (`rev-parse --abbrev-ref HEAD`), kept as the worktree fact it is.
- `collect`: for a **lane** seat, `branch` is now
  `dispatch::task_branch(&conventions.task_branch, project, &seat.name, &task)`
  — the attempt's own task branch, with the project's
  `[conventions].task_branch` template. A reviewer's `branch` stays the branch
  the engine checked out for it (its worktree is cut on its review branch), and
  a seat with no attempt still gets no handover at all.
- `fact_lines`: when the worktree's head and the task's branch differ, one line
  follows the `Branch:` line —
  `- The worktree is on <head>; this task's branch is <branch>: switch to it before you go on.`
  The line goes into both the document's part 1 and the incoming packet's
  facts, so the new model reads it before it starts.
- The last commit, the upstream and unpushed commits, the changed and untracked
  files and the stash remain the worktree's own facts, whichever branch it is
  on.

`crates/gear-engine/src/restart.rs`: the existing handover test asserted the
old behaviour (`Branch: work`, the fixture branch the worktree sat on). It now
asserts `Branch: heat/t1` and the switch line naming `work`, which is the
F-284 case in miniature.

## Tests

New `crates/gear-engine/tests/it/handover_branch_contract.rs` on a real Git
repository:

- a lane switched while its worktree is on `hull/t1` and its attempt is T-2
  names `hull/t2` and carries the switch line;
- a lane whose worktree is already on `hull/t2` names it and carries no switch
  line;
- a reviewer whose worktree is on `review/t2` names `review/t2` and no switch
  line (unchanged);
- only the branch comes from the attempt: the last commit and the changed file
  stay the worktree's (`Last commit: … hull/t1`,
  `Uncommitted changes: README.md`);
- a seat with no attempt still gets no handover.

## Noted

- A worktree that is in detached HEAD (`head` = `HEAD`) also differs from the
  task branch, so the switch line appears and names `HEAD`; that is the honest
  fact and the line still tells the agent where to go.
- The branch is computed even when the worktree cannot be read, so a lane whose
  worktree facts fail still gets its task branch by name.
