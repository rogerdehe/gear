# T-481 — report

A lane now keeps its conversation from one task to the next, as the user
decided: a first attempt continues the session the seat already runs, and a
new conversation is started only when the captain marks the task unrelated
(`fresh: <why>`), when the CLI that made that conversation changed, or when the
seat holds no conversation yet. A round that had to start new because of the
CLI change is marked a new-session recovery, and its packet points the lane at
the session its earlier work ran in.

## What changed

- `crates/gear-engine/src/session.rs` — `lane_action` (L7): for attempt 1
  without a usable `followup-of` session, the action is `keep` when the seat's
  last round ran on the CLI the seat runs on now and the seat holds a session;
  `new` when the task carries `fresh:`, when the CLI of the seat's last round
  differs from the current one, or when the seat holds no session. L1 (no live
  agent → `fresh`), L2-L6 (rework, follow-up) are unchanged. `prepare_lane`
  compacts a kept conversation when the context is large (§3.5) and the seat
  ran a previous round. When the chosen action is `new`/`fresh` and the earlier
  work's CLI differs from the current one, the round stores
  `engine.session_recovery.<project>.<task>.<n>` with that CLI and session.
- `crates/gear-store/src/lib.rs` — the key helpers, one place each:
  `last_round_of_seat`, `task_fresh` / `set_task_fresh` / `clear_task_fresh`,
  `set_session_recovery` / `session_recovery`. No migration: the schema stays
  v7 (the `fresh:` mark and the recovery mark are meta keys, as the captain
  decided in M-6658).
- `crates/gear-app/src/draft.rs`, `crates/gear-app/src/plan.rs` — a queue block
  may carry `fresh: <why>` (empty is refused); apply stores it for a NEW task
  and for an existing one, a block without it keeps the mark; `gear plan show`
  prints it. A done or cancelled task loses the mark. `render_task_packet`
  prints the one line `Earlier work on this task ran in <cli> session
  <session_ref>; read it for reference if your CLI can.` for a marked round.
- `crates/gear-app/src/home.rs` — the seat's page shows `round: new-session
  recovery` under the task line of a marked round.
- `crates/gear-board/src/lib.rs` — `TaskBoard.recovery`; the lane line names
  the current task as `… · new-session recovery`.
- `crates/gear-engine/src/dispatch.rs` — the `This task follows T-F; read its
  report` pointer is also added for a `keep`: a follow-up whose session cannot
  be used now keeps the lane's own conversation, and the design's §3.3 sentence
  covers every case where the follow-up's session is not the one the round runs
  in.
- `skills/gear/references/captain.md` — one sentence: tasks on a lane continue
  its conversation, `fresh: <why>` marks unrelated work.
