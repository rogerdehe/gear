# T-474 — report

Branch hygiene and coverage. A cancelled task's branch is deleted; a merged
task's branch is deleted even when its tip moved past the merged candidate, its
extra commits named to the captain; `gear report coverage` lists the accepted
attempts whose candidate is not on the integration branch; direction branches
have a project template and are deleted when their job closes; and a task moved
between lanes leaves no branch behind once it is done.

## What changed

**Direction branches** (`crates/gear-model/src/branch.rs`,
`crates/gear-app/src/config.rs`, `crates/gear-engine/src/review.rs`):

- `[conventions].direction_branch`, a template like the review branch's, default
  `{project}/direction/{task}` (the old hard-coded name was `direction/t<n>`).
  `expand` fills `{task}` (the task id in lower case) as well as `{n}`; the
  template is validated (a per-task placeholder, a usable branch name, and not
  the task or review branch).
- The direction job records its branch when it starts; when the job closes
  (a result, or the attempt ended without one), the branch is deleted — the
  reviewer's worktree is detached and the branch deleted locally, and the
  branch is deleted on the remote. An older job without a recorded branch falls
  back to the branch its checkout recorded, so a stale `direction/t-328` is
  cleaned too.

**Merged tasks** (`crates/gear-engine/src/merge.rs`):

- A merged task's own branch whose tip moved past the approved candidate is
  deleted like the others; its commits after the candidate are named in the
  merge result ("closed on origin (their commits after the approved candidate
  were not merged): …"). When the delete itself fails, the branch stays and is
  listed as left with its commits. A branch whose extra commits write only
  reports is closed silently, as before (T-402).

**The branch sweep** (`crates/gear-engine/src/merge.rs`):

- It covers every lane that held a task (the task's current lane and every
  attempt's seat), so a task moved to another lane no longer leaves its old
  lane's branch behind (the other project's T-199: `api/t199`).
- A done task's branches are deleted when they are on the integration branch
  (fetched once per repo for the sweep) and named to the captain with the
  commits the integration branch does not have otherwise; one item, once per
  branch per `branch_max_age_min`. Cancelled tasks are deleted as before.

**Coverage** (`crates/gear-app/src/coverage.rs`, `crates/gear-cli/src/main.rs`):

- `gear report coverage`: the captain's report of accepted attempts whose
  candidate is not on the integration branch, with the task, attempt, candidate,
  repo and lane. The app builds it from the store; the git question is handed in
  by the CLI, which fetches the integration branch once per repo and answers each
  candidate with `merge-base --is-ancestor`. A candidate the check cannot read is
  reported as off, so a silent yes does not hide a lost merge.

## Friction

Past the 40-minute budget: the packet's acceptance runs three full crate
suites, which took about 7 minutes together on this machine, and the
direction-branch delete crosses the store/git boundary (the git calls run
after the store transaction, which needed restructuring). No permission was

## Out of scope

- A stale review branch left on a done task is left to the merge's close (T-483)
  and, if it survives, the old-age naming; the sweep deletes review branches of
  done tasks too (they are on the integration branch after the merge), so in
  practice they go with the task branch.
- The direction branch's remote delete is best effort: a failed delete is not
  retried, and the branch stays until a later job or the old-age rule.
- The branch sweep runs every 10 minutes, so a cancelled task's branch lives up
  to that long.
- Coverage checks accepted attempts only; the backlog's "failing cases that no
  task names" half is not in this packet.
- An offline machine's coverage check lists every candidate as off (the fetch
  falls back to the remote-tracking ref); the captain sees the warning rather
  than a false all-clear.
