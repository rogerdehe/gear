## Set aside
- `reviewer_free_for_a_hand_in` counts `SeatState::Unknown` as quota-occupying (review.rs:3759), which `occupies_quota` does not. Conservative — it can only delay a stall ring, never fire a false one — so it is not flagged.
- A `[temps]` block with `quota.temps = 0` makes `reviewer_free_for_a_hand_in` always false (0 occupying seats is not `< 0`), so the stall never rings where T-376 would have rung after 20 min. This is a pathological config (a temps block that forbids reviewers) and outside normal use; the no-`[temps]` case is handled by the separate `tell_captain_of_hand_ins_without_reviewers` path, which is unchanged.
- The stall message body still says "handed in N min ago" (total age, not free-since age); that is accurate and matches the test, so not flagged.
