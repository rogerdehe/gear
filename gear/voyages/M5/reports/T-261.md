# T-261 — report

`gear admin init` and `gear admin init --check` now name the lanes and
reviewers the config starts, with their models. Change is confined to
`crates/gear-cli/src/main.rs::cmd_admin_init` (plus its contract tests).

## What it does

- After the `config ok: project …` headline of `--check`, and after a
  successful `init` (after the `project …` / `seat …` lines), one line per
  lane:

  ```
    lane <name>: <kind> <model> · owns <owns joined by ", ">
  ```

  where the model is the lane's first `models` entry, else the first
  `[models] lanes` entry, else `-`.

- Then the reviewers line: `  reviewers: <quota.temps> × <temps.kind> <model>`
  with the first `[models] review` entry's model (else `-`), or
  `  reviewers: none` when the config has no `[temps]`.

- `--json`: the object (`--check`) gains `"lane_list": [{"name","kind","model"}]`
  and `"review_model"`. The `init --json` object gains the same two fields,
  merged into the serialized `InitResult` from within `cmd_admin_init` — no
  change in `gear_app`.

Model ids are printed as the config names them (`ModelEntry::model()`); a
lane's own chain wins over the role chain, as the engine runs it.

## Tests (`crates/gear-cli/tests/it/admin_init_contract.rs`)

- `check_names_every_lane_and_the_reviewers_with_their_models` — a two-lane
  config with a lane chain, a review chain and one lane overriding its model:
  the full stdout is asserted line by line, models and `owns` included.
- `check_json_carries_the_lane_list_and_review_model`.
- `check_says_none_without_temps_and_dashes_without_models` — no `[temps]`
  prints `reviewers: none`; no model chain leaves every model `-`; the JSON
  carries the same.
- `init_names_the_lanes_and_reviewers_after_registering` — a successful
  `init` prints the same lines as `--check`.
- The three existing exact-stdout assertions on `--check` now compare the
  headline line (a new `headline` helper) instead of the whole stdout, since
  the seat lines follow it.

## Acceptance

`make check CRATE=gear-cli` — 135 tests run, 135 passed (19 in
`admin_init_contract`, the previous 15 included). `make gate` is the merge
gate's job.

## Notes

- `cargo fmt -p gear-cli` is not a no-op on this branch: it reformats large
  parts of `main.rs` and the other `tests/it/*.rs` files (the tree is not
  rustfmt-clean). I reverted that and kept the diff to the two files, so the
  new code is formatted by hand in the surrounding style.

## Out of scope (noticed, not acted on)

- `make check`/`cargo fmt` churn above: a repository-wide `cargo fmt` would
  rewrite about a thousand lines of `main.rs`; if the project wants rustfmt
  enforced, that is its own task.
- `init --json` previously printed `serde_json::to_string(&r)`; it now goes
  through `to_value`, which orders keys alphabetically instead of by struct
  field order. No test or caller depends on the order.
