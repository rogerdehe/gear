## What changed

**`gear/voyages/M5/board/prototype.py`** (export mode only):

- `import json`.
- `fn golden_fixture(path)` — writes `<dir>/fixture.json` with
  `json.dump({"now": NOW, "review_merge_m": REVIEW_MERGE, "quota": [...], "voyages": VOYS, "when": WHEN},
  f, ensure_ascii=False, indent=1, sort_keys=True)`. `quota` is the literal list of `view_now`'s quota loop, in the
  same order — `tokenrhythm 5h 41 "22:00"`, `codex week 63 "Oct 30"` — as dicts, so it reads back as
  `provider`/`window`/`used`/`resets`. Tuples in `VOYS`/`WHEN` become JSON lists, `None` becomes `null`.
- `fn golden(outdir)` — after the eight frames, calls `golden_fixture(os.path.join(outdir, "fixture.json"))`.
- `FakeWin.chgat(y, x, n, a)` already assigned `a` onto each of the n cells (it never ORed); its docstring and the
  `FakeWin` class docstring now say so in words: it replaces the old attribute (colour pair and bold included).

**`gear/voyages/M5/board/golden/fixture.json`** — new, 25th file in the directory (the 24 frame files regenerate
byte-identical; see below).

**`gear/voyages/M5/board/README.md`**, "Golden frames" section, two lines added:

- `FakeWin.chgat(y, x, n, attr)` sets the attribute of each of the n cells to `attr`: as in curses it **replaces** the
  old attribute (colour pair and bold included), it does not OR into it, so the row `hl` lights is reverse video with
  no colour and no bold — exactly change 13, "one colour".
- `fixture.json` is the fake data the frames were drawn from (VOYS, WHEN, NOW, REVIEW_MERGE and view_now's quota
