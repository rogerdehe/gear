# T-340 — report

The real board can be read back as the three golden planes (T-276's format), and
a frame depends only on the store and the `now` it was built at: the header's
clock no longer reads the wall clock, and the canvas writes like the prototype's
`put` — never into the last column.

## What changed

**`crates/gear-board/src/frame.rs`**

- `Canvas` gains `pub fn char_at(&self, x, y) -> char` (a space outside the
  canvas), `pub fn width(&self) -> usize`, `pub fn height(&self) -> usize` and
  `pub fn light_row(&mut self, y: usize)` — every cell of row `y` from column 1
  to column `width - 2` (both included) gets
  `Style { fg: None, bold: false, reverse: true }`, the characters stay (the
  prototype's `hl`, `chgat(y, 1, wd - 2)`). A row off the canvas is ignored.
- `Canvas::put_styled` and `Canvas::put_line` stop at column `width - 1`: they
  write at most `width - x - 1` characters, so nothing is written at
  `x >= width - 1` (the prototype's `put`, `addnstr(y, x, s, wd - x - 1)`).
- `fn header` draws `crate::idle::clock(board.now)` at column `width - 8`, where
the prototype puts its clock (`wd - 8`, T-340 contract v2); `fn clock_now` is
gone. With the clock five characters wide it ends at `width - 4`, so the new
clipping never eats a digit and row 0 still ends with the time (three spaces
follow it, as in the golden frames).

**`crates/gear-board/src/lib.rs`**

- `pub mod golden;`
- `Board` gains `pub now: Ts` ("the time the board was built at"), set by
  `build_with_agents` from its `now` argument. `build` goes through it, so
  every board carries the `now` it was built at.

**`crates/gear-board/src/golden.rs`** (new)

- `pub struct Planes { text, colour, reverse }` — one `String` per canvas row,
  one character per cell.
- `pub fn planes(canvas: &Canvas) -> Planes`: text = `char_at`; colour = `.`
  none, `o`/`w`/`b`/`d`/`a`/`m`/`u` for Ok/Warn/Bad/Dim/Acc/Mag/Blu,
  uppercase when bold, `*` when bold with no colour; reverse = `R` or `.`.
  This is exactly the format of `gear/voyages/M5/board/golden/*.col|*.rev`.

**`crates/gear-app/tests/it/voyage_contract.rs`** — the one `Board { … }`
literal outside the crate carries `now` (the field is required; the test does
not otherwise change).

## Tests

**`crates/gear-board/src/golden.rs`** (unit, as the packet asks):

- `the_planes_read_a_frame_cell_by_cell` — 20×8 canvas, `"ab"` Ok bold at
  (1,0), `"c"` bold no colour at (3,0), row 1 lit: row 0 text `" abc"` + 16
  spaces, colour `".OO*"` + 16 `.`, reverse 20 `.`; row 1 text 20 spaces,
  colour 20 `.`, reverse `"."` + 18 `R` + `"."`.
- `put_styled_never_writes_the_last_column` — `put_styled(17, 2, "xyz", …)`
  writes `x` at 17, `y` at 18, leaves 19 a space; a text starting at 19 writes
  nothing and leaves the style plain.
- `light_row_lights_the_columns_the_prototype_lights` — columns 1 and 18 lit,
  0 and 19 not, characters unchanged, `light_row(8)` on an 8-row canvas is a
  no-op.
- `a_cell_outside_the_canvas_is_a_space` — `char_at`/`width`/`height`.

**`crates/gear-board/tests/it/golden_contract.rs`** (new; registered in
`tests/it/main.rs`):

- `two_builds_with_the_same_now_draw_the_same_frame` — one project, one ready
  task; two `gear_board::build` calls with the same `now`, which is 90 s behind
  the wall clock (a build that still read the clock would put another minute on
  row 0): `board.now` is that `now`, `frame::canvas(…).text()` is equal, and
  row 0 ends with `idle::clock(now)`.

Existing tests needed no change: no test in the crate expected text in the last
column of a wide canvas, and none pinned the clock's column.

## Question sent, and the answer (contract v2)

`gear send --kind question` M-4639 asked two points where the v1 acceptance
contradicts itself; the captain answered (M-4640) and contract v2 carries both:

1. **The clock and the new clipping.** (2) clips `put_styled` at `width - 1`,
   so a clock right-aligned at `width - 5` lost its last digit, while the board
   acceptance wants row 0 to hold `idle::clock(now)`. v2 settles it: the clock
   sits at column `width - 8`, as the prototype does — the golden frames are the
   standard.
2. **The golden text literal.** v1's acceptance said row 0 text is `" ab c"` +
   15 spaces, but with `"ab"` at (1,0), `"c"` at (3,0) and its own colour plane
   `".OO*"` + 16 dots, the `c` is at column 3. v2 carries the positions: the
   text is `" abc"` + 16 spaces, which is what the code and the test produce.

This attempt worked to v2 and is handed in under `--contract 2`.
