# T-291 — report

A lane is told, with its new task's packet, when its home worktree still holds
uncommitted edits (M4 F-90: mast carried stray edits in five engine files from
T-220 into T-222 and the captain stashed them by hand).

## What changed

`crates/gear-engine/src/dispatch.rs` only.

**The record (prepare_dispatch).** `fn note_dirty_home` runs for an
`Action::Assign` before the attempt exists: when the task has no attempt yet
(`tx.attempts_of_task`), it reads `engine.worktree_path.<seat>` and runs
`cfg.review_git.run(&path, &["status", "--porcelain"])` **outside any
transaction**. A non-empty result is stored in meta
`engine.dirty_home.<seat>` as `{"task": <task>, "paths": [the first five],
"count": <n>}`; a clean worktree, a missing path or a failed read store `""`.
Nothing blocks the delivery.

- `fn dirty_home_json` builds that value; `fn porcelain_path` reads a path out
  of one `git status --porcelain` line (two status letters and a space, the new
  path of a rename last).
- `fn dirty_home_key(seat)` is the meta key.

**The sentence (intend_dispatch).** For `Action::Assign` with `attempt.n == 1`,
when `engine.dirty_home.<seat>` names this task, the text gets, right after the
first sentence that names the branch (the `Branch: <branch>.` line of
`first_attempt_text`):

> Your worktree has uncommitted changes from earlier work ({count} paths:
> {paths joined by ", "}). Before you switch: commit them as a WIP commit on
> the branch they belong to and push it; never `git stash` (the stash is
> shared by every worktree of the repository) and never carry them into
> {branch}.

and the meta is cleared. A rework (`attempt.n ≥ 2`) never carries it.
`fn dirty_home_notice` builds that sentence, `fn branch_sentence_end` finds the
sentence, `fn insert_after_branch_sentence` puts it in place with one space on
each side.

## Tests

`dispatch::tests` (one temp git repo for the module, made once in `fn home()`
and serialized with `fn clean_home()`):

- `a_dirty_home_worktree_is_named_in_the_first_packet` — a modified
  `src/a.rs`: the first packet of T-1 carries `Your worktree has uncommitted
  changes from earlier work (1 paths: src/a.rs)` and `never `git stash``, right
  after `Branch: heat/t1.`, with the start command still after it; the meta is
  `""` afterwards.
- `a_clean_home_worktree_gives_the_usual_text` — the text equals
  `first_attempt_text("T-1", 1, "heat/t1", "origin", "trunk", …)` exactly.
- `a_rework_never_carries_the_dirty_home_line` — attempt 2 with a record for
  T-1 still in meta: no line, no `git stash`.
- `a_failed_read_says_nothing` — a path git cannot read stores `""` and the
  packet is the usual text.

`make check CRATE=gear-engine`: 674 tests passed.

## Out of scope

- The read happens on every assign whose task has no attempt yet; once
  `start_attempt` has made attempt 1, later assigns of that task are reworks
  and are not read (nor does a rework use a stale record: the notice is only
  read for `attempt.n == 1`).
- The repo is not rustfmt-clean (3589 diffs before this task); this change
  follows the file's existing style rather than reformatting it.
