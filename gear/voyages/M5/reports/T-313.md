One word for a voyage: a plan may say `# Voyage` (M4.2 #15). `# Milestone` and
`milestone=` keep working.

## What changed

**`crates/gear-app/src/draft.rs` — `fn parse`**

- The section arm is one match arm for both spellings: `"Milestone" | "Voyage"`.
  Everything inside is shared, so both spellings run the same id check, the same
  duplicate check (`seen_milestones`, keyed by id) and push the same
  `(title line, body)` pair into `draft.milestones`.
- The missing-id error now reads
  ``a voyage header needs an id, e.g. `# Voyage M2: …` `` for either spelling.
- Doc comments that named the section (`Draft::milestones`, `milestone_parts`,
  `parse`, `collect_body`) mention the `Voyage` spelling too.

**`crates/gear-app/src/plan.rs` — `fn voyage_line`**

- The undescribed-voyage line reads
  ``Voyage <id> <title> · not described yet (no `# Voyage <id>` block)``.
