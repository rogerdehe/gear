# T-276 — the prototype exports golden frames (export mode only)

`python3 gear/voyages/M5/board/prototype.py --golden <dir>` draws the eight frames (four views, folded and
unfolded) into a fake window instead of a terminal and writes 24 files; the committed copy is
`gear/voyages/M5/board/golden/`. The prototype's drawing is untouched: the diff against `origin/dev` adds lines
and replaces one — `curses.wrapper(main)` is now inside `if __name__ == "__main__":`, the export mode being the
other branch.

## gear/voyages/M5/board/prototype.py — additive, after `main`

`GOLDEN_H, GOLDEN_W = 48, 160`, `MARK`, `LETTER`, `VIEW_NAME`, `VIEWS` (the view numbers `main` uses),
`FakeCurses`, `FakeWin`, `cell_width`, `golden_footer`, `golden_frame`, `golden_letter`, `golden_save`,
`golden`.

- `FakeCurses` carries the only two names the drawing reads off the curses module as attributes — `A_BOLD` and
  `A_REVERSE` — plus `error`; both come from `MARK`, so an attribute is a set of marker bits and the export can
  name it again. `MARK` is `b=1, ok=2, warn=4, bad=8, dim=16, acc=32, mag=64, blu=128, rev=256`: distinct bits, so
  the drawing's `C["warn"] | C["b"]`, `curses.A_REVERSE | C["b"]` keep working.
- `golden()` rebinds the module's `curses` to `FakeCurses()` and fills `C` with the markers, so nothing opens a
  screen; no other name of the module is patched.
- `FakeWin` keeps cells: `getmaxyx` → `(48, 160)`, `erase`, `addnstr(y, x, s, n, a)` (`n` counts characters as in
  curses), `chgat(y, x, n, a)` (a run of cells' attribute, characters kept, as curses replaces an attribute),
  `refresh`, `keypad`.
- **Cells, not codepoints** (the direction check on attempt 1): `cell_width` gives 2 for East Asian wide or
  fullwidth characters (in these frames ⛵ ⚓ ⏳), 0 for combining and format characters, 1 otherwise. A wide
  character is one glyph in two cells: the first holds it, the second is its continuation (`tail[y][x]`, a space
  with the same attribute); overwriting one half blanks the other half, as curses does. A character that does not
  fit in the line's remaining cells is not drawn — the prototype already keeps every write inside its row
  (`put` passes `wd - x - 1`), so this is the frozen drawing's own clip rather than curses' wrap.
- `golden_frame(view, detail)` draws exactly what `main` draws in its loop: `DETAIL[0] = detail`, `erase`,
  `header(w, view)`, the view with `sel = 0`, the footer at `h - 1`, `refresh`. The footer string is read from
  `main.__code__.co_consts` (the constant starting `←→ / Tab / 1-4`), so the golden cannot drift from it; if that
  constant ever goes, the export stops with a message instead of writing a frame without a footer.
- `golden(outdir)` picks the first voyage (`pick(0)`) and writes `now`, `tasks`, `cost`, `log`, each `folded`
  (`DETAIL[0] = False`) then `open` (`True`): eight frames, three files each.

## gear/voyages/M5/board/golden/ — 24 files

`<view>-<folded|open>.{txt,col,rev}`, 48 lines of 160 cells each: the characters (a blank cell as a space; the
continuation cell of a wide character is a space too), the colour letter (`.` none, `*` bold with no colour, `o` ok,
`w` warn, `b` bad, `d` dim, `a` acc, `m` mag, `u` blu, uppercase when bold) and `R`/`.` for reverse.

## Notes, no other change made

- Bold without a colour: contract v1's `.col` had no letter for it, so the header titles and the picked tab (bold,
  no colour) would have read `.` and a golden comparison could not have seen their bold. Asked the captain
  (M-4438); contract v2 adds `*` for exactly that, which `golden_letter` now writes and the 24 files carry.
- The first version counted codepoints as cells; the direction check on the first commit caught it, and `FakeWin`
  now counts terminal cells (wide ⛵ ⚓ ⏳ take two, with a continuation cell), which moved the voyage labels on the
  header's two lines and the ⏳ lines by one cell each.
- Frames are of `VOYS[0]`, so the golden files carry this fake data; they need regenerating when `VOYS[0]`'s fake
  data changes (that is a drawing change in the sense of the packet: the board's test data must match).
