# T-417 — report

The no-push clock no longer counts the time a lane was held (2026-10-29: the
user stopped the voyage for about two hours; on release `quiet::tick` measured
from the branch's last push, so every released lane was asked at once why it
had not pushed, and the captain was alarmed ten minutes later).

## What changed

`crates/gear-engine/src/quiet.rs` only. In `fn tick`, a lane seat for which
`fn eligible` says no (`Held`, `Parked`, `Retiring`-no, a seat in backoff, a
waiting seat, no `Started` attempt) now stops the clock while it is out:

```rust
let Some(attempt) = eligible(tx, &seat)? else {
    if seat.role == SeatRole::Lane {
        tx.set_meta(&base_key(&seat.id), &now.to_string())?;
        tx.set_meta(&reply_key(&seat.id), "")?;
    }
    continue
};
```

`engine.quiet.base.<seat>` is rewritten to `now` on every tick the seat is
ineligible, so the first eligible tick sees `max(push, base)` = the last tick
before the release: the interval runs from the end of the hold. An open
`engine.quiet.reply.<seat>` is cleared, so a question the lane owed when it was
held is dropped instead of alarming the captain mid-hold. Only `Lane` seats are
touched; captain/temp seats neither push nor are asked.

No other key, message or interval changed: an eligible lane is asked exactly
as before (`now - max(push, base) > push_interval_min`).

## Out of scope

- A hold that begins and ends between two ticks: the clock runs from the last
  tick of the hold, i.e. up to one loop interval earlier than the release.
  The packet asks for the end of the hold; the tick is the only clock the
  engine has, and the error is one loop, far under the 20 min interval.
- `engine.quiet.think.<seat>` and `engine.quiet.loop.<seat>` are untouched:
  both already require a `Started` attempt through `eligible`/`loop_attempt`,
  so a held lane is not asked those either.
- `fn tick` now writes two metadata rows per ineligible lane seat per engine
  loop. It is one small upsert on the store the tick already has open; no new
  transaction was added.
