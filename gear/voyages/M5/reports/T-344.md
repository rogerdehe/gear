# T-344 — report

The fixture loader (`golden_fixture::load`) now seeds everything else the
prototype draws: the reviewer and its rounds, the decisions of every voyage,
the friction reports, the quota readings and the goal checks. The prototype's
`fixture.json` stays the one copy of the data.

## What changed

**`crates/gear-board/tests/it/golden_fixture.rs`** only.

- Fixture structs grow the fields the packet names: `quota`
  (`provider`, `window`, `used`, `resets`), and per voyage `DECISIONS`
  (`at`, `kind`, `what`, `why`, `star`) and `DONE` (`met`, `text`) plus
  `FRICTION` (`task`, `lane`, `status`, `body`). Task `marks` (the last tuple
  field) is now read instead of ignored.
- **(1) The reviewer** — `testing::seed_temp_seat(tx, "gear", "review-3",
  "T-262", "w1:p9", "codex", now)` after the voyages, so `gear:review-3` holds
  T-262 and is Active.
- **(2) The review rounds** — for every task with `tokens_k > 0`, a round
  `(task, a, "review")` on seat `gear:review-3`, generation 1, `codex`, no
  model, where `a` is the last attempt that has a HandedIn time (read back with
  `attempt_times_of_task`), else 1. Tokens `input = (tokens_k −
  floor(tokens_k·0.75))·1000`, output/cache_read/cache_write `Some(0)`, cost
  `cost·0.25`, source `agent`. T-262's round starts at `now − 12·60` and is left
  open; every other one starts at that attempt's HandedIn time (else `d(s)`) and
  is closed at the same time.
- **(3) The decisions** — per voyage, in order, `i` from 0:
  `insert_decision_if_new` with key `golden-{milestone}-{i}`, `at` =
  `"2026-10-28 {at}"`, `source` `plan`, `alt`/`changes`/`line`/`plan_version`
  None, `why` None when the fixture's why is `""`. A task of stage `moved` adds
  one line to its voyage's log: kind `move`, what `"{id} moved to {marks}"`,
  key `golden-move-{id}`, `at` `"2026-10-28 " + idle::clock(now)` (`"14:32"`),
  `source` `gear`, `why` None, not starred.
- **(4) The frictions** — per voyage, `insert_friction` with attempt 1, role
  `dev`, seat `gear:<lane>`, `required: false`; a status `read` is closed right
  after with `close_friction(project, id, "read", now)`.
- **(5) The quota** — per entry, `quota.reading.<provider>` = JSON
  `{provider, windows: [{name, used_percent, resets_at}], read_at: now}`. A
  `HH:MM` reset is the first minute after `now` whose `idle::clock` shows it
  (bounded walk of two days, so a wrong fixture fails loudly); an `Oct 30` style
  date is `now + 2·86_400`. `used_percent` is kept as the JSON number the
  fixture writes, so `63` stays `63`.
- **(6) The goal check** — per voyage, `goal-check:gear:{milestone}` = the JSON
  array of `{"met", "text"}` from `DONE`, in order.
- Tests carrying the packet's acceptance (7 in the module, 4 new):
  - `the_reviewer_holds_t262_and_its_round_is_open` — `gear:review-3` holds
    T-262; its review round is on that seat, `codex`, attempt 1, started
    `now − 12·60`, `end_at` None, input 183 000, cost 0.0775.
  - `every_voyage_has_the_fixtures_decisions` — `decisions_of("gear","M5")` has
    3 rows, two starred, the first `2026-10-28 11:05` kind `scope` source
    `plan`; M4.2 has a `move` row saying `T-182 moved to M5` from `gear`.
  - `the_fixtures_frictions_keep_their_state` — two frictions; the M5 one
    (T-260, `gear:hull`) is open, the M4.2 one (T-248) is closed with outcome
    `read`.
  - `the_quota_and_the_goal_check_are_in_the_meta` — `quota.reading.codex` has
    window `week`, `used_percent` 63, `resets_at` `now + 2·86_400`, `read_at`
    `now`; `tokenrhythm`'s reset is after `now` and clocks `22:00`;
    `goal-check:gear:M5` has three entries and the second is met.
- The module doc now says the file is T-343's and T-344's.
