# T-259 — the engine releases a NeedsCheck reviewer with no task and no agent

Seen in M4.2 (review-10, M-4186): a reviewer whose session resume timed out
parked in `SeatState::NeedsCheck` with its pane gone and no task; the item asked
the captain to check an agent that no longer existed, and the plan's `- release`
refuses that state, so the captain released it in the store by hand.

`release_dead_temps` (crates/gear-engine/src/release.rs) now also takes a Temp
seat in `SeatState::NeedsCheck` whose `task_id` is `None`, with the same
`runs_a_reviewer` test as a parked (`Unknown`) seat. `release_dead` checks the
transition from the seat's own state instead of the fixed `Unknown`.

`crates/gear-model/src/state.rs`: the Temp transition table allows
`(NeedsCheck, Released)`.

A NeedsCheck temp that holds a task, or whose pane holds an agent (or a pane
that cannot be read — an observation failure is not an absence, design/08),
stays `NeedsCheck` as before.

## Tests

- `a_needs_check_temp_may_be_released` (gear-model state tests): Temp
  NeedsCheck → Released is allowed; a lane's NeedsCheck → Released is not.
- `a_needs_check_reviewer_without_a_task_and_an_agent_is_released`
  (crates/gear-engine/src/release.rs, fixtures of
  `a_parked_reviewer_without_an_agent_is_released_and_a_live_one_is_not`):
  NeedsCheck with no task and an empty shell in its pane → `Released`, binding
  `Void`, pane closed; the same seat with a task → stays `NeedsCheck`; the same
  seat with no task whose pane holds an agent → stays `NeedsCheck`.

Validation: `make check CRATE=gear-model` — 14 tests, all passed;
`make check CRATE=gear-engine` — 626 tests, all passed.
