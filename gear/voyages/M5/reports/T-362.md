## Rework (attempt 2): F1 of the review of attempt 1

`fn voyage_departure` read `project.voyages.first().elapsed_min` and rebuilt the
departure as `now − elapsed·60`. `project.voyages` is the project's voyages
newest first, so a board built for a landed M1 measured its rows from M2's
departure (60 minutes) instead of M1's own (120): the review saw
`starts +0h-50m` where the fixture's M1 task (departed NOW − 7200, started
NOW − 6600) has `starts +0h10m`. With no active voyage it fell back to `now`,
also wrong for a landed voyage.

It now reads the shown voyage's own timestamp,
`project.shown.as_ref().and_then(|voyage| voyage.departure)`, and falls back to
`now` only when the voyage has no departure at all. That is the exact ts, so no
minute is lost to the truncated `elapsed_min`.

T-350's two-voyage fixture (both fail on the old code with the review's
`starts +0h-50m` and `starts +-1h-50m`):

- `the_tasks_view_measures_a_landed_voyage_from_its_own_departure`: the board

## The lane order: a question, and M-5872's answer

`project.lanes` is in seat order, i.e. seat-id order (`hull, keel, mast`),
while the prototype's `LANES` is the voyage's plan order (`hull, mast, keel`),
so the two put `mast` and `keel` in each other's columns. With
`project.lanes` order the golden rows differ in every lane cell of the
drawing, which the declared `u`/`m` lane-colour swap cannot cover. I asked
(M-5869) and the captain answered (M-5872): order the Tasks view's lanes by
their first task in plan order, then any remaining lane of `project.lanes`,
marked in the code; the same order for T-359's Now rows when it comes. That
is `fn task_lanes`, and it makes the board's lane columns the prototype's
(`hull` Acc, `mast` Mag against the prototype's blue — the one allowed
colour difference — `keel` Warn).

A direction check on the first commit (M-5881) asked instead for
`project.lanes` order. I asked again (M-5883) because that contradicts
M-5872 and makes rows 13-46 unmatchable; nothing in the code changed for it.

the fixture's `prototype data` cells and the lane-colour swap. It passes.
When T-356 lands and the board's view starts where the prototype's does, the
frame comparison covers those rows and the two entries go.
