# T-334 — report

The board's model now knows the voyage's stations: which are reached, which is
now, which is next, and how far each is (backlog "Stages of a long voyage on
the board"). Nothing is drawn yet — S4 draws it.

## What changed

**`crates/gear-board/src/stations.rs`** (new; `pub mod stations;` in `lib.rs`)

- `pub enum StationState { Reached, Now, Next, Later }`.
- `pub struct StationProgress { id, needs, state, tasks, merged, left_min }`.
- `pub fn progress(tx, project, milestone) -> GearResult<Vec<StationProgress>>`:
  the voyage's scope is its tasks that are not `Draft`, `Cancelled` or `Failed`
  (the rule of `crates/gear-app/src/station.rs`); `fn is_merged` is true when
  `tx.attempt_times_of_task` has a `merged` time for any attempt — a verdict
  marks a task Done before its merge lands; each scope task whose station is
  the station's id counts in `tasks`, its merge in `merged`, and the
  `crate::voyage::estimate_of` of each unmerged task in `left_min` (an unknown
  estimate adds 0). A station with at least one task and every one of them
  merged is `Reached`; the first one that is not is `Now`, the next one is
  `Next`, everything further `Later`.
- `pub fn course(tx, project, milestone) -> GearResult<String>`: the `Now`
  station as `station <id> (<reached> of <n> reached): <needs> · <left> tasks
  left in <id> · <voyage left> tasks left in the voyage`; `all <n> stations
  reached · <voyage left> tasks left in the voyage` when every one is reached;
  `<voyage left> tasks left in the voyage` when the voyage has no stations.
  Voyage left is the scope tasks that are not merged (`fn left_in_voyage`).
- `pub fn goal_text(tx, project, milestone) -> GearResult<Option<String>>`: None
  when the voyage is missing or its `done` is empty; else `Your goal, voyage
  <M>: done: <done> · bar: <bar> · <course>. Judge every decision against it.`

**`crates/gear-board/src/lib.rs`** — `pub mod stations;`; `ProjectBoard` gains
`pub stations: Vec<stations::StationProgress>`, filled in its one constructor
(`project_with_agents`) with `stations::progress` of the measured voyage
(`workload`), and empty without one. No rendering change: the frame still draws
what it drew.

## The stations store task was not there

The packet builds on `tx.voyage_stations` / `tx.task_station` ("from the
stations store task"), but T-329 (hull) was still `ready` and `origin/dev` has
neither function nor `VoyageStation`. I sent `gear send --kind question`
(r-1793217988411, M-4616) with three options and went on with option 2, which
the captain confirmed (M-4619): `stations.rs` has two private helpers,
`fn stations_of` (the meta `voyage-stations:<project>:<milestone>`, one
`<id>: <needs>` line per station, split at the first `": "`) and
`fn station_of` (the meta `task-station:<project>:<task>`, empty means none) —
exactly T-329's key and line format, so switching them to the store functions
is two lines and no test changes. The public signatures are the packet's.
The captain's message says T-329 removes the helper once both are merged.

## Tests

**`crates/gear-board/tests/it/stations_contract.rs`** (new, registered in
`main.rs`), one store fixture: voyage M5 (`done: users install it`, `bar: an
error in normal use blocks the task`) with S1, S2 and S3, five tasks. The
fixture writes the stations and the task stations with `tx.set_meta` in T-329's
format (there is no store API yet).

- `the_stations_are_reached_now_and_next` — S1 (two tasks, both merged) is
  `Reached`, S2 (one merged, one Running with estimate 30) is `Now` with
  `left_min` 30, S3 (one Ready) is `Next`; the board's `stations` equals the
  computed list (the measured voyage's stations).
- `a_done_task_without_a_merge_time_is_not_merged` — S3's task set `Done` with
  no merged attempt: `merged` 0, its state stays `Next`, and the voyage still
  has 2 tasks left.
- `the_course_names_the_station_that_is_now_and_what_is_left` — `station S2 (1
  of 3 reached): the board shows the stations · 1 tasks left in S2 · 2 tasks
  left in the voyage`.
- `a_voyage_with_every_station_reached_has_nothing_left` — `all 3 stations
  reached · 0 tasks left in the voyage`.
- `a_voyage_without_stations_says_what_is_left` — `2 tasks left in the
  voyage`, `progress` empty, the board's `stations` empty.
- `the_goal_text_carries_the_done_the_bar_and_the_course` — the whole text,
  starting `Your goal, voyage M5: done: users install it · bar: …`.
- `a_voyage_without_its_done_has_no_goal_text` — None for a voyage with no
  `done:`, and None for a voyage that is not there.
