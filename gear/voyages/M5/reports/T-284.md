# T-284 — report

A reviewer that stopped mid-review on the screen

    ■ Selected model is at capacity. Please try a different model.

can still be held back from the nudge for good. The store of review-7 shows
the T-242 packet O-3263 and nudges O-3266 (+93 s) and O-3268 (+198 s), so the
nudge does reach a `Submitted` packet, and the at-capacity text matches no
codex quota or auth marker (the codex profile in
`crates/gear-herdr/src/profile.rs`), so the screen flags do not stop it.
The guard that did stop it is `fn nudge_stopped_reviewers` counting as
blocking every op of `slot_ops(&seat.id)` that is not `Submitted` and older
than the cooldown: an `Unknown` reviewer delivery (an uncertain send, or an
`Executing` op recovered on engine start) never settles — `ops.rs` settles a
reviewer delivery only by its verdict — so the reviewer was never nudged
again; and an op of an older generation (an agent that is gone) blocked too.

## What changed — `crates/gear-engine/src/review.rs` only

`fn nudge_stopped_reviewers`, the one `blocking` expression:

```rust
let blocking = tx.slot_ops(&seat.id)?.into_iter().any(|op| {
    op.generation == seat.generation
        && !(matches!(
            op.state,
            gear_model::OpState::Submitted | gear_model::OpState::Unknown
        ) && now - op.created >= cooldown_s)
});
```

An op now blocks only when it belongs to the seat's current generation, and
it is not (`Submitted` or `Unknown`) and older than the cooldown. `Intended`
and `Executing` ops still block at any age, so two deliveries are never in
flight; a young `Submitted`/`Unknown` op still blocks, so the cooldown is
honoured. Nothing else in the function or file changed.
