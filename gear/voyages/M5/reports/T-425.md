## Rework (F2 of the attempt 2 review)

`crates/gear-engine/src/review.rs`, `fn prepare_review_tree`: the ignored
`git merge --abort` and the now-ignored `git reset --hard` run **before** the
fallible `stash_review_tree` call. In the reviewer's state — a half-done merge
where a cleanly merged file was edited again — `merge --abort` fails
(`Entry 'b' not uptodate`), and with the old order the stash failed
(`could not write index`) and its `?` returned before the reset, so the
recoverable warm worktree failed on every tick and its seat was retired. Now
the reset always runs first and clears the tree; the stash then sees it clean
(and still preserves untracked evidence, which `reset --hard` does not remove).
The rest of the preparation is unchanged.
