# Goal
GEAR goes into a project and a team that already run, fits how they work, and then runs the whole voyage by itself: nobody patches the store, branches or panes by hand, every agent in every role is watched over, GEAR writes only where the project allows, and a team on GitHub sees and joins the work there.

# Milestone M3: Fit in, and run without hands
done: (1) on our own fixture projects (a parent repo with cloned child repos; a project with its own CI and docs) a voyage runs from kickoff to landing with no hand fix — no store edit, no branch repointing, no pane closing, no engine restart by the captain; (2) a push to any destination the project did not register is refused and rings the captain, in a test and live; (3) a Codex provider back-off is shown as back-off, never as a stall, and no start-up dialog (folder trust, update) leaves a seat blocked; (4) on a GitHub sandbox repo, issues become tasks, a lane's task opens a draft claim PR with an ORCHESTRATE marker, hand-in and verdict appear on the PR, the merge closes the issue; (5) `gear --skill adopt` exists as a skeleton and the project standard it produces travels in every task and review packet
bar: DELIVERABLE (user's choice): an error in normal use is fixed; edge cases are logged, not reworked; rework rounds are capped
eta: 6h

## T-71 [now] lane=steady milestone=M3 required
