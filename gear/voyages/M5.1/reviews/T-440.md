## Set aside

- `declared` is derived as `until − 120 min` instead of a separate stored timestamp; valid because `declare_wait` always writes `until = now + 120 min` in the same transaction.
- A missing meta key on an external wait would make `declared = 0` and `answered` read messages since epoch, but that state cannot arise from `declare_wait` (it always writes the key), so it is outside normal use.
