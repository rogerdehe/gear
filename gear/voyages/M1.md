# Goal
GEAR develops itself: the parallel develop–review–merge loop runs inside the engine, the plan board opens on a Herdr hotkey, and kickoff/quota policy come from the project config (PRD v0.9 §0, §8a, §10, §15, §16). Done when the gear project runs on GEAR with no ops/ stopgap scripts (ops/STOPGAPS.md empty).

# Milestone M1: Self-hosting loop, delivered as v0.1.0
done: a hand-in is reviewed and merged or sent back without the captain's hands, reviewers on warm seats, and a new user without Rust installs GEAR from the v0.1.0 GitHub release and runs a captain + lanes + reviewers project with Claude Code, Codex, OpenCode or Grok
bar: FASTEST TO THE GOAL (user's choice): fix only what breaks the chain or loses data; every other detail found on the way is cut — logged, never reworked; no new tasks
eta: 31h
