# T-645 — report

[F-4 3/7] The store records a voyage's labeled issues.

## What changed

- `crates/gear-store/src/schema.sql`: `voyage_issues` (project, number,
  milestone, title, body_hash, labeled, first_seen, last_seen; key
  (project, number)).
- `crates/gear-store/src/migrate.rs`: schema v11 with `step_10_to_11` creating
  the table (the schema batch, as the other table steps do).
- `crates/gear-store/src/lib.rs`: `VoyageIssueRow`, `Tx::upsert_voyage_issue`
  (insert or update in place, keeping `first_seen`) and
  `Tx::voyage_issues(project, milestone)` ordered by number.
- `crates/gear-board/src/issues.rs`: `IssueState` and
  `issue_states(tx, project, milestone)` — Unlabeled when `labeled` is 0;
  otherwise Done (every carrying task Done and merged), Verifying (all Done,
  one unmerged), InProgress (a carrying task has an attempt), Planned (tasks,
  no attempt), Deferred (no task, intake item resolved), Pending otherwise.
  Cancelled tasks do not carry the issue.

## Tests

- `crates/gear-store/tests/it/voyage_issues_contract.rs`: upsert then read
  ordered by number; a second upsert updates title/hash/label/last_seen and
  keeps first_seen.
- `issues.rs mod tests`: one test per state, plus a cancelled task not
  carrying the issue.
- The store tests that pin the schema version now expect v11.

`make check CRATE=gear-store` — 99 tests, 99 passed.
`make check CRATE=gear-board` — 284 tests, 284 passed.

## Out of scope

- Nothing writes `voyage_issues` yet: the label scan and the board view are
  later F-4 tasks.
