# T-647 — report

A new binary restarts the engine by itself, with no merge cut.

## What changed

- `crates/gear-cli/src/main.rs`:
  - `EngineOutcome::{Exit, Restart}`; `run_engine_with` returns it.
  - A `RESTART` atomic and a SIGHUP handler next to the SIGTERM one, both
    installed by `install_stop_handler`.
  - `BinaryWatch::restart_due`: the binary changed since the start and has sat
    unchanged for 5 s (`RESTART_SETTLE`). `BINARY_CHANGED_GRACE` is now 30 min:
    the captain item is only for an engine still draining that long after the
    change.
  - The loop drains (`gear_engine::drain`) on a stop or a restart, logs
    `engine draining for restart` for the latter, keeps ticking, and returns
    `Restart`/`Exit` only once `gear_engine::merges_idle` says the merges are
    idle. The injected `idle` check lets a test drive that.
  - `cmd_run` on `Restart` logs `engine restart: exec <path>`, drops the store
    and the Herdr door, and execs `current_exe()` with the same arguments. The
    lock file is close-on-exec (std opens files that way), so the new process
    takes it again; a failed exec logs and exits 1.
  - `gear admin restart`: for every store `admin projects` knows, SIGHUP the
    engine holding its lock; a free lock prints `no engine` and its stale pid
    is never signalled.

## Tests

- `a_changed_binary_drains_the_engine_and_restarts_only_when_the_merges_are_idle`:
  drains, ticks until idle, returns `Restart`, logs the drain.
- `a_sigterm_drains_the_engine_and_keeps_ticking_until_the_merges_are_idle`:
  a stop with a running merge ticks until idle, then `Exit`.
- `admin_restart_sends_sighup_to_the_engine_holding_the_lock`: a held lock
  naming a child `sleep`'s pid is SIGHUP'd; a free lock is `no engine`.
- The existing engine-loop tests pass the injected idle check.

`make check CRATE=gear-cli TESTS='test(engine) | test(admin_restart)'` — 18
tests, 18 passed.

## Out of scope

- `cmd_run`'s exec path is not covered by a unit test (it replaces the test
  process); the loop's `Restart` outcome is.
