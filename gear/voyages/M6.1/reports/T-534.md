## Friction

The first `cargo build --release` failed in sccache, not in the code: the shared
sccache server was started with a temp directory inside another project's
build-slot scratch (`/Volumes/Data/.herdr-worktrees/goldmine/build-slot/target/tmp`)
that had since been removed, so every compile died with `os error 2`. Stopping
the server (`sccache --stop-server`) and rebuilding worked; the first release
build cost the failed attempt plus a rebuild (1m55s). Not a permission I lacked,
but a shared tool state I had to reset.
