# T-451 — report

While the fleet rests outside its working hours, `gear` and the board say so:
outside the stored config's `[schedule] hours`, the shared voyage line ends
`· off hours until HH:MM` instead of T-449's `· departs at HH:MM`. Inside the
hours, without `hours`, and without `[schedule]`, the line is unchanged.

## What changed

- `crates/gear-board/src/voyage.rs` — `VoyageReport` gains
  `off_hours_until: Option<Ts>`; `build_reports` fills it once per project from
  the stored `config_toml` (`[schedule] hours`), with the same rule as
  `gear_app::config::off_hours_until` (T-450): the next start while `now` is
  outside the window, `None` inside it, without the section and when the text
  does not parse. The local-time math (`hours_window`, `inside_hours`,
  `minutes_of_day`, `local_at`, `local_minute`) is mirrored next to the
  config reader, because gear-app already depends on gear-board and
  gear-board cannot call it. `VoyageReport::lines()` appends
  ` · off hours until HH:MM` (via `gear_board::idle::clock`) while that is
  `Some`; otherwise T-449's `departs at` applies as before. The line is the
  one `gear`'s captain home page and `gear report voyage` print and the one
  the board draws as its voyage header, so both surfaces show it without a
  second copy. No gear-cli code change.

## Tests

- `crates/gear-cli/src/main.rs` — `run_home` of a captain with a voyage that
  has not departed and one open task: `hours = "10:00-18:00"` at 19:00 local
  shows `off hours until 10:00`; inside the hours and without `[schedule]` the
  voyage line is unchanged; with both `hours` and a future `depart_at` the
  rest is said instead of the departure. The T-449 home tests keep working
  through the same helper, which now takes the `[schedule]` text.
- `crates/gear-board/tests/it/depart_contract.rs` — the board render: the same
  cases (outside the hours, inside them, without `[schedule]`, and
  `hours` + future `depart_at` preferring the rest). The T-449 board tests are
  unchanged.

## Friction

- The seat's generation in `GEAR_CTX` was 31 while the seat was at 32, so
  every `gear` call returned `STALE_GENERATION`; I ran `gear` with
  `GEAR_CTX=gear:mast:32` for the rest of the turn.

## Out of scope (noticed, not changed)

- Like the departure (T-449), the rest is project-level: every open voyage line
  would say it while the fleet rests; normal use has one open voyage.
- The line names the next start, not the end of the rest for a `depart_at`
  plus eta final rest (T-450): that rest has no next start, and `hours` alone
  is what this line reads.
- A `hours` text that does not parse is refused by the config check; the board
  fails closed (no rest line), like T-449 does for `depart_at`.
