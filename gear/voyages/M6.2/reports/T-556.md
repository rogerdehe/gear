# T-556 — report

The three new gate variables, documented in the skill, and the release notes for
v0.6.53.

## What changed

- `skills/gear/references/conventions.md`, the merge paragraph (the one that
  names `$GEAR_GATE_FAILED`, and through the `gate =` sample line
  `$GEAR_GATE_TEMPFAIL`): after the `$GEAR_GATE_FAILED` sentence, every gate run
  is now told what it judges — `$GEAR_GATE_PROJECT` (the project id),
  `$GEAR_GATE_ROUND` (the id of the run's first merge op, lowercase without the
  dash, e.g. `o6543`) and `$GEAR_GATE_TASKS` (the task ids of the merges the run
  judges, space-separated, in merge order, e.g. `T-637 T-646 T-662`) — with the
  one sentence of use the packet asks for: a gate that runs CI elsewhere names
  its CI branch `<project>/gate/<round>` and puts the tasks in the CI run's
  title, so every gate branch has an owner and every run says what it judged.
- `docs/releases/v0.6.53.md` (new), in the form of `docs/releases/v0.6.52.md`
  (`# GEAR v0.6.53`, `Added:`, `Fixed:`, `Why:`, `## Upgrading`):
  - **Added** — the three gate variables, with their values and example.
  - **Fixed** — a set-aside task returns as a resume, not a rework (T-553; T-548
    came back as a rework with an empty Rework section); a merge waiting for
    another task is not reported as lost (T-553; the `Unknown` op of a queued
    merge counts as landing in the branch sweep); a rework or a resume says
    `git switch <branch>` (T-554; the worktree was still on `hull/t548`);
    a pane holding several captain seats keeps the name of the seat bound first
    (captain hand-fix `0d1673ea`; the Prometheus captain flipped between
    `prometheus-captain` and `lawrence-captain`).
  - **Why** — the SelyraAI gate branches owned by no project, the two wrong
    signals found while T-548 waited, the unreachable captain name (2026-11-04).
  - **Upgrading** — from 0.6.52 as in `v0.6.52.md`: stop, install the plugin at
    `v0.6.53`, any `gear` call, restart the engine, reinstall the skill; nothing
    to set, the variables reach every gate run.
