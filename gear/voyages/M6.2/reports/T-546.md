# T-546 — report

A project with no unfinished task releases its standby reviewers at once.
Lawrence M1 landed with two standby reviewers up because
`reviewer_release_idle_min` was unset: the idle-time rule held them for good,
though no task was left that a reviewer could ever be handed.

## What changed

- `crates/gear-engine/src/release.rs`, `fn release_idle_standby`: right after
  `idle_standby` returns a non-empty list, it reads
  `tasks_live_of_project(project)`. When no task in it is in a state other
  than `Done` or `Cancelled`, every seat of that list is released with
  `release_one(store, herdr, project, &seat, None, now, "idle-standby")`,
  pushed to `report.released` / `report.failed` as the loop below does, and
  the function returns. The idle-time rule below is unchanged for a project
  that still has work; the doc comment records the new rule (T-546).
- Tests in `mod tests`: `CONFIG_WITHOUT_IDLE_TIME` and
  `world_without_idle_time(states)` build a project with no
  `reviewer_release_idle_min` and two Standby reviewers whose agents are up.
  - `no_unfinished_task_releases_every_standby_reviewer_at_once`: tasks `Done`
    and `Cancelled` — both panes are closed on the tick and both seats are
    `Released` on the next.
  - `one_ready_task_keeps_the_standby_reviewers`: tasks `Done` and `Ready` —
    both seats stay `Standby` and no pane is closed.
- `an_idle_reviewer_is_kept_by_default` used a `Done` task as its fixture, and
  that premise is now the release rule: its task is `Ready` (work left, no
  lane working), which is what the test means to show — with no idle time set
  a Standby reviewer stays up while the project still has work.

## Checks

`make check CRATE=gear-engine TESTS='test(release::)'` — 58 tests, 58 passed.
The merge gate runs `make gate`.

## Out of scope

`tasks_live_of_project` keeps the tasks of a voyage that is not finished, so a
project whose only open work sits in a landed voyage's tasks is read as no work
left; that is the store's definition (T-529) and this task does not change it.
