# T-549 — report

The release notes for v0.6.52 (the batch merge), written before the engine
tasks land.

## What changed

- `docs/releases/v0.6.52.md` (new), in the form of the releases before it
  (`# GEAR v0.6.52`, `Added:`, `Fixed:`, `Why:`, `## Upgrading`):
  - **Added — the batch merge** (`[conventions] merge_batch`, default 1): above
    1, up to N passed merges of a project are merged together onto the
    integration branch, gated once and land together; a red batch fails only
    the task whose changes match the paths the gate wrote to the file
    `$GEAR_GATE_FAILED` names, the others merge again; with no match the batch
    is halved and gated again; `merge_batch` above 1 with `merge_parallel` above
    1 is refused; the default 1 changes nothing.
  - **Added — the gate contract for `GEAR_GATE_FAILED`**: every gate run gets
    the variable, naming a file; a gate writes the repo-relative files or
    directories whose tests failed there, one per line; a gate that writes
    nothing is fine.
  - **Fixed — standby reviewers on a finished project**: a project with no
    unfinished task releases them at once, without
    `reviewer_release_idle_min`.
  - **Why**: the SelyraAI merge queue (22 passed tasks, about two hours) and
    Lawrence M1's two reviewers left up.
  - **Upgrading from 0.6.51**: `gear admin stop`, `herdr plugin install
    rogerdehe/gear --ref v0.6.52`, any `gear` call, engine restart — the
    binary changed; the skill changed, so `gear admin install-skill --agent
    <cli>` for each CLI; to use the batch merge, set `merge_batch` in the
    project's `[conventions]` and re-apply the config.

The wording of the setting is the doc comment T-545 gives `merge_batch` in
`crates/gear-app/src/config.rs` ("How many passed merges of the project are
merged together onto the integration branch and gated once … Default 1: each
merge is gated alone"), and the sample line and merge paragraph in
`skills/gear/references/conventions.md` (`merge_batch = 1`, the batch
sentences, `$GEAR_GATE_FAILED`). The engine details named are T-547's and
T-548's plan (`GEAR_GATE_FAILED` for every gate run; the paths name the
culprit; halving otherwise).
