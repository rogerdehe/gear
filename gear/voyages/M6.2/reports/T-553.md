# T-553 — report

Two wrong signals found while T-548 waited for T-547 (hull F-311).

## (1) A waiting merge counts as landing — `crates/gear-engine/src/merge.rs`

- The branch sweep's `landing` check (a done task whose branch still holds
  commits the integration branch does not have) now reads a merge op in
  `OpState::Unknown` as landing too, beside `Intended`, `Executing` and
  `Submitted`. `Report::Waiting` leaves an op that waits for another task's
  merge in `Unknown`, so such a merge was read as nothing at all: the captain
  was told "nothing will merge them" (2026-11-04, T-548 while its merge queued
  behind T-547).
- Test `a_done_task_whose_merge_waits_for_another_is_not_named_unlanded`:
  a scratch origin and work clone where `heat/t5` holds a commit dev does not
  have; a done `T-5`. Without a merge op the sweep names the branch ("nothing
  will merge them"); with a merge op of `T-5` in `Unknown` it names nothing.

## (2) A set-aside task comes back as a Resume — `crates/gear-engine/src/dispatch.rs`

- `fn resume_text(task, attempt, version, branch, remote, integration, packet)`
  is the delivery of a task whose previous attempt was set aside:
  `Resume <task> attempt <n> (contract v<version>): it was set aside for more
  urgent work, not failed: there is no Rework section. Continue from what you
  pushed on <branch> (in your worktree); merge <remote>/<integration> into it
  first. Run `gear` first (it records that you got this). Task packet:
  <packet>. Read it before starting; report with gear send. After your result,
  end your turn: the next task comes when you are idle.`
- `fn attempt_set_aside(tx, project, task, n)` is true when attempt `n - 1` is
  `Abandoned` (the state `state: hold` leaves). `intend_dispatch` sends the
  Resume text then; a previous attempt in any other state (a review's rejection)
  keeps `assign_text`, the Rework wording. The integration branch is read once
  and passed to both texts.
- Tests: `a_set_aside_attempt_comes_back_as_a_resume` (attempt 1 `Abandoned` →
  attempt 2 delivered with the Resume text, naming the branch and the
  integration branch to merge in, with no "review failed"),
  `a_rejected_attempt_still_comes_back_as_a_rework` (attempt 1 `Rejected` → the
  Rework text, no Resume), and `the_three_packet_writings` for the exact
  wording.
