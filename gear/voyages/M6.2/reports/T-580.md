# T-580 — a feature task starts from its base branch, and GEAR makes that branch

## What changed

`crates/gear-engine/src/dispatch.rs` only.

- **The packet starts from the task's own base**: where
  `intend_dispatch` took `integration_branch(tx, project, &seat.name)` (the
  value `first_attempt_text`/`resume_text` name as `origin/<integration>`), it
  now takes `start_base(tx, project, seat, task)`: the task's `base` when it is
  set and not empty, else the lane's integration branch exactly as before. A
  member of a feature (`base = p/feature/f-1`) is therefore told
  `git switch -c heat/t1 origin/p/feature/f-1`.
- **The base branch exists before that packet**: `prepare_dispatch` — the step
  before the delivery in the same tick — calls `ensure_base_branch`. When the
  task's base is not the lane's integration branch and
  `git ls-remote --heads <remote> <base>` in the task's repo (the task's own
  repo snapshot, `config.repo_of_task`) prints nothing, it runs
  `git fetch <remote> <integration>` and then
  `git push <remote> <remote>/<integration>:refs/heads/<base>`.
- **A failure waits and tells the captain once per base**:
  `tell_captain_base` opens one urgent `System` item on the thread
  `feature-branch:<base>` whose body names the task, the lane, the base and
  git's own stderr; while the failure lasts the item's body follows the latest
  error instead of a second item. `ensure_base_branch` then answers `false` and
  `prepare_dispatch` skips that seat: no attempt is opened and no packet goes;
  the next tick plans the same assignment again.

## Test

`crates/gear-engine/src/dispatch.rs` tests
(`make check CRATE=gear-engine TESTS='test(dispatch::)'`: **22/22 passed**):

- `a_feature_task_starts_from_its_base_branch` — a fixture remote (`base_fixture`:
  a bare `origin` holding `dev`, and the lane's clone of it) and `T-1` with base
  `p/feature/f-1`: the packet carries
  `git switch -c heat/t1 origin/p/feature/f-1`, and `origin` now holds
  `p/feature/f-1` at `dev`'s own commit — the branch was pushed before the
  delivery.
- `a_task_without_a_base_starts_from_the_integration_branch` — the same fixture
  with no base: the packet says `origin/dev` and `refs/heads` on the remote
  holds `dev` alone, so nothing was created.
- `a_base_branch_that_cannot_be_made_waits_for_the_next_tick` — a repo with no
  `origin`: `prepare_dispatch` returns no ready seat (the delivery is left for
  the next tick), no attempt is opened, and one item sits on
  `feature-branch:p/feature/f-1` naming the base and the failing `git ls-remote`.

## Decisions and deviations

- **In `prepare_dispatch`, not `intend_dispatch`**: the packet says "before that
  delivery"; `prepare_dispatch` is that step (the engine runs it right before
  `intend_dispatch`, it already reads the worktree, and it can skip one seat
  while leaving the rest of the tick whole). Doing git inside
  `intend_dispatch`'s store write was the alternative and was not taken; a skip
  there would also have to undo an attempt already opened.
- **The guard is `base != the lane's integration branch`, as the packet words
  it**, so a plain task (whose `base` snapshot equals its lane's integration
  branch) runs exactly as before and costs no git.
- **`start_base` also feeds `resume_text`**, not only the first-attempt text:
  one value, one meaning for the branch the packet names, and a resumed attempt
  of a feature task reads the same base.

## Out of scope, logged

- A task whose repo snapshot names a child repo while the lane's current repo is
  another: the source of the created branch is the *lane's* integration branch
  (the packet's wording) inside the *task's* repo. If that branch is not in that
  repo, the creation fails and the captain gets the item — no wrong branch is
  made.
- Nothing closes the `feature-branch:<base>` item when the branch later appears;
  it stays open until the captain reads it, as the other engine items do.
- The rest of the feature work (plan apply, hand-in base, the integration task,
  the merge override, the captain's skill) belongs to T-578..T-583.
