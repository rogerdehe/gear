# GEAR v0.4.0

Seats and sessions: one seat model for lanes and reviewers, a session rule that keeps or replaces an agent's context on purpose, and quota waits that end at the provider's real reset.

- **One seat model.** Lanes and reviewers are seats with the same lifecycle. A reviewer stays warm (Standby) after its verdict and takes the next review in a new session; idle reviewers are released when no lane is working, or at once with `- release <reviewer>` under `# Staff`.
- **The session rule.** Before each packet the engine decides the session: a rework resumes its attempt's session, a follow-up (`followup-of`) keeps or compacts it, an unrelated task starts a new one. Each step (new, compact, resume) runs one per tick and is retried from its stored state after a failure.
- **Quota waits to the real reset.** A provider stop (a marker or a provider error, such as MiniMax's 429 Token Plan limit) is read from the provider's own quota source (`[[quota.sources]]`). A spent window parks the lane until the reset plus one minute, with the round's clock paused, then continues it in the same session. Readings are kept every 5 minutes.
- **Token and context readers.** The new `gear-usage` crate reads token usage and the last context size from pi, Codex, Claude Code and OpenCode session files.
- **Deliveries that are confirmed, not guessed.** A delivery is confirmed by the lane's own check-in within `timing.delivery_grace_s`; a late check-in still confirms it and closes its stall item. A hand-in for an attempt still marked Delivered is accepted. Herdr's agent state decides busy and ready everywhere.
- **Never typing into the wrong thing.** Prompts go to the live agent by name; a refused name is renamed and retried; a pane with only a shell gets nothing typed into it.
- **Rounds.** Every dev, rework and review round is recorded with its session, ready for the time and token reports of v0.4.2.

This build also carries parts of v0.4.1 to v0.4.3 that are already merged; they are described when their release ships.

## Upgrading

From 0.3.x: stop the engine (`gear admin stop` in your own terminal), `herdr plugin install rogerdehe/gear --ref v0.4.0`, start the engine with any `gear` call. The store moves to schema 6 on start (new columns only, left empty for old rows). Add `[[quota.sources]]` to `gear/gear.toml` for the providers you use, then `gear admin init gear/gear.toml`.

## Known issue

A Codex lane or reviewer does not start on v0.4.0: the role rules went into the Codex command line, which Herdr refuses or cuts short. Fixed on `dev` (f2283033: the rules go in as a pointer to their file) and in v0.4.1. With Codex seats, stay on v0.3.4 until v0.4.1.
