# GEAR v0.6.64

Added:
- **A merge waits for its task's `deps:`:** a queued merge runs only once every dep of its task has landed (a cancelled dep, or one of another project, does not hold it). To keep an accepted task out of the merge line until the fix it needs is on the integration branch, add `deps: T-<fix>` to it and apply the plan.

Why: Prometheus, 2026-11-05. T-748 was refused in three merge rounds for a dev-side cause that T-762 fixes, and every round sent its batchmates back with it.

## Upgrading

From 0.6.63: `gear admin stop`, install v0.6.64, then any `gear` call, and restart the engine. The skill changed (course: a merge that waits for a fix): reinstall it for each agent CLI.
