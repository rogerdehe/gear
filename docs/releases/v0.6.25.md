# GEAR v0.6.25

Fixed:
- **An OpenCode or Grok lane gets its role:** a lane's rules (its config charter and the working rules every lane keeps) reach the agent as a start argument, and OpenCode and Grok take none, so their lanes never saw their charter: a lane chartered as the technical owner of its task was still running on nothing but the packet. A lane on such a CLI now gets its rules in every packet, under `## Your role`. A lane on a CLI that takes them at its start is not told them twice.

## Upgrading

From 0.6.24: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.25`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
