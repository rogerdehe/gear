# GEAR v0.6.20

A follow-up to v0.6.19 found in its first live use.

Changed:
- **A named pane wins:** `gear --session <s> --pane <p>` is taken as the caller's pane even when the process runs under another pane. A CLI that hands its commands to a shared background process (Codex) runs them under whichever pane started that process, so v0.6.19 refused every Codex captain but that one.

## Upgrading

From 0.6.19: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.20`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
