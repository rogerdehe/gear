# GEAR v0.7.16

A captain that has put a finished voyage to the user is left alone until the user answers.

## Fixed

- **A seen land order is not rung again.** When every task of a voyage is done, the captain gets the land order and writes the voyage report for the user, then waits for the user's word. The land order stayed an open item, and the captain's stale-item reminder rang it again every period, so a captain with nothing left to do was told to land over and over. A land order the captain has seen is now never reminded; it stays open in the captain's `gear` until the user answers.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.16`) and restart the engine. Nothing to configure.
