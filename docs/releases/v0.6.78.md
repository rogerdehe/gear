# GEAR v0.6.78

`merge = "push"` opens no pull request for a task.

Fixed:
- **A draft pull request was tried at every delivery in push mode:** the forge opened a claim pull request for each delivered task whatever the merge mode, before the lane had pushed a commit, and GitHub refused it on every tick (Carthage: 225 refused calls in minutes). With `merge = "push"` (the default) a task now has no pull request; its issue still closes when its last task lands. `merge = "pr"` is unchanged.

## Upgrading

From 0.6.77: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.78`, then any `gear` call, and restart the engine — the binary changed.
