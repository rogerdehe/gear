# GEAR v0.6.103

The board prints every task on one row, and a task a captain's hand-fix delivered is not counted as cut at landing.

Fixed:
- **The board's Tasks view broke its columns on a feature's integration task** (Lawrence M2: T-96, T-107, T-98, T-100, T-112, T-115 and T-99 carry "Integrate feature F-n:" then the members' goals on new lines, and the second line landed at the left edge). A task's title is one row in every view.
- **A landing counted a task the captain's hand-fix delivered as cut** (GEAR M6.3: T-625, shipped by hand in v0.6.90, put the cut at 4 of 19 and refused the landing). A cancelled task that a `hand-fix:` decision line names is delivered, not cut.

## Upgrading

From 0.6.102: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.103`, then any `gear` call, and restart the engine — the binary changed. Restart a running `gear board`.
