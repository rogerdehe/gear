# GEAR v0.7.32

A merge leaves one commit per gated change and no merge commits, and estimates follow the measured speed of the model that runs the task (voyage M7.3).

## Changed

- **Squash by default.** `[conventions].merge_method` is `squash` (the default) or `merge`. With squash, a task merge in push mode lands one commit on the integration tip: subject `T-n: <goal>`, the lane's commit subjects in the body, and the trailers `Gear-Task`, `Gear-Attempt`, `Gear-Candidate` and one `Gear-Source` per merged commit. The train and the batch land one commit per task. `merge_method = "merge"` keeps the merge commits. The records merge at a landing follows the same method. `[github] merge_method` stays the pull-request method.
- **A feature lands by replay.** A feature's integration task replays the feature's own commits onto the integration tip (the review commit folded into the last one), with no merge commit; a replay that conflicts lands as one squashed commit. Bisect finds a feature's members by their `Gear-Task` trailer.
- **Every "is it merged" check knows a squash.** The merge restart, the lost-merge scan, carried tasks, the coverage report, the plan's merged check, the leftover-branch sweep and the parallel-change check accept a commit on the branch whose trailer names the candidate. The reclaim deletes an owned integration branch whose content is on the release branch after a squash, and reads each repository's own integration branch.
- **Estimates by measured speed.** GEAR records the model of every attempt. `gear report speed` shows each model's measured work time and actual-over-estimate ratio over the last 90 days. `gear plan apply` names a task estimate more than twice or less than half what its lane's model has measured (5 samples or more), and at departure the eta against the measured forecast. The skill tells the captain to estimate in agent time on that model, never human hours.
- **Named new blocks.** `## NEW:<label>` lets another new block of the same draft say `deps: NEW:<label>`; the apply writes the ids in.

## Fixed

- The parallel-change check reads a branch's own commits, so a file another task already landed is not reported as shared.
- An `integrated-by` pass whose candidate differs from the integration branch only in voyage files is accepted.
- The records merge refuses a captain branch that changes files outside the voyage folder, and a missing seat branch names the captain branches the remote does have.
- A restart request has its own key and no longer overwrites a restart plan in progress.
- A Claude lane or reviewer whose plan limit is spent is seen as out of quota.
- The captain's home page says the voyage's done sentence once.
- A flaky reclaim test runs alone in its own state.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.32`); the engine restarts on it by itself. Merges squash from now on; set `[conventions] merge_method = "merge"` to keep merge commits.
