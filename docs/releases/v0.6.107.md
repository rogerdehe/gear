# GEAR v0.6.107

A session command is typed even when the lane's last output names a path that contains it.

Fixed:
- **A lane's packet never arrived after its last report named a path containing `/new`** (Lawrence M2: console stayed idle on T-133 for over 10 minutes; its T-128 report named `admin-web/src/views/studio/new/api.ts`). The check whether a typed text still sits in the input box looked for it anywhere in the last lines, so `/new` was taken as already typed, never sent, and the new-session step waited for ever. The text now counts as held only when it starts its line, after the prompt marker or the box border.

## Upgrading

From 0.6.106: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.107`, then any `gear` call, and restart the engine — the binary changed.
