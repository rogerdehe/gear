# GEAR v0.4.2

A voyage you can review: tokens and cost per round, the decisions worth a look, the friction the lanes reported, and a landing that starts with that review.

- **`gear report voyage [--json] [--all]`**: the done sentence clause by clause, the ★ decisions in full (and every decision with `--all`), the friction reports open and closed, the rework rounds, and time and tokens per lane and per round. Work time is apart from quota waits and declared waits; the fleet stop counts only the time every lane was paused together. Rounds still open are counted from their session files; usage that cannot be read shows as unknown, never as zero. The default voyage is the current one.
- **Tokens and cost per round.** Every dev, rework, review and direction round is counted from its session (pi, Codex, Claude Code, OpenCode). Cost comes from the agent where it reports one, else from `[prices]`; a partial sum is never shown as complete. `gear report time` prints each round.
- **Friction reports.** A hand-in over its time carries `--friction "…"`: what cost the time that the captain could fix. When the captain has nothing else to do, one item lists the open reports; `gear friction` shows them and `gear friction close F-n -m "<outcome>"` closes one.
- **The decision log.** `# Decisions` lines (`- <time> <kind>: … | why: … | else: …`, ★ for the ones worth a look) are stored as the voyage's record; verdicts, cancels, staff lines and config re-applies add their own entries.
- **Direction checks.** While a lane works, a reviewer may check a new push for direction only (design §14) and the lane hears at once if it is off course; a hand-in always takes the reviewer seat first.
- **The board's views 4 and 5**: Decisions and Time & tokens.
- **The landing** starts with the voyage report reviewed with the user.

## Upgrading

From 0.4.1: stop the engine (`gear admin stop` in your own terminal), `herdr plugin install rogerdehe/gear --ref v0.4.2`, start the engine with any `gear` call. No store change. Optional: `[prices."<provider/model>"]` with `input`, `output`, `cache_read`, `cache_write` (USD per 1M tokens) for agents that do not report cost.
