# GEAR v0.7.29

A captain take asks only the previous captain's own agent for its handover.

## Fixed

- **The handover ask never reaches another agent.** `gear captain take` asked whatever agent sat in the previous captain's pane to write the handover. A pane outlives its agent: one reused for another project's agent got this project's handover request (pharos, 2026-11-16). The take now asks only when the agent in that pane runs the agent session GEAR recorded on the previous captain's binding; otherwise nobody is asked, and the new captain's take item points it at the previous session to read and write part 2 itself.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.29`); the engine restarts on it by itself. Nothing to configure.
