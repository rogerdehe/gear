# GEAR v0.6.63

Fixed:
- **A running merge is not a stopped voyage:** while a merge is queued or running, the "voyage is stopped: no lane can start anything" item does not ring, and an open one closes. The tasks left are waiting for that merge.
- **A remerge of an unknown merge queues it once:** the unknown op is closed, and only the new op is queued. Before, both were left queued.

Why: Prometheus, 2026-11-05. Eight "voyage M4 is stopped" items rang while T-748's merge ran, and T-716 had two queued merges after its remerge.

## Upgrading

From 0.6.62: `gear admin stop`, install v0.6.63, then any `gear` call, and restart the engine. The skill did not change.
