# GEAR v0.6.12

M6.1, bug fixes that reach the users: a model switch that saves a machine-wide
default, a remerge that carries the captain's conflict fix, held tasks that
count, and a release that reaches every project on the machine.

Changed:
- **T-531 — an OpenCode seat switches its model only through its session API:** no pane text is sent; a binding with no session, a catalogue that is not loaded, or a failed `session.switchModel` waits bounded and then fails, and the captain is told.
- **T-532 — a remerge carries the captain's conflict fix on the review branch:** when the review branch contains the approved candidate (the captain merged the integration branch into it and resolved the conflict there), the remerge merges that commit alone, so the integration branch gets the candidate and the resolution.
- **T-533 — a model or effort changes only by a restart with start flags:** every agent SOP says so (OpenCode: the session API), because `/model` and `/effort` save the machine-wide default for every agent of that CLI.
- **T-535 — a delivery still in the lane's input box is never confirmed:** the tick reads the pane tail, the idle-to-busy turn does not confirm held text, and the Enter is retried up to three times, 30 s apart.
- **T-536 — a held task stays in its voyage's scope and counts:** `state: hold` (Draft) counts in the stations, the voyage totals, `gear report time` and the board, is listed as "held" in the queues and the deps tree, and is still never started.
- **T-537 — a verdict names its candidate by any sha prefix:** a fail or pass verdict with the full sha settles an attempt stored with a shorter prefix, and the reverse; six shared characters are still a different candidate.
- **T-538 — no two gear-cli tests share a scratch directory:** the two tests that used the tag `lane` now use `lane-init` and `lane-import`, so plain `cargo test` no longer races them.
- **T-539 — the departure sheet shows the charters:** a `Charters` line names each role's one-liner and the sheet says it comes from `gear.toml`; the captain's packet follows the lane's model — files, functions and steps for a fast lane, the goal, boundaries and acceptance for a strong one.
- **T-540 — a merge never reports a branch as left when it is already gone:** the close step asks the remote first; a branch that is gone counts as closed, and one that still exists stays "left on".
- **T-541 — the skill review's corrections:** the acceptance commands are run exactly as written (lane and review rules), the plan names the exact command character for character, a removal or rename maps every caller with `git grep`, and a user who already ordered the voyage in their own words has departed.

## Skill

The skill changed with T-533, T-539 and T-541: reinstall it for every agent CLI.

## Upgrading

From 0.6.11: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.12`, then `gear admin install-skill --agent <cli>` for each agent CLI (claude, codex, pi, opencode, grok), and restart the engine. The engine changed (the model switch, the delivery confirm, the remerge and the branch close) and the skill changed, so both matter. Nothing in an existing config has to change.
