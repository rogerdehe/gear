# GEAR v0.6.77

A station answered with `keep course` is not a landing.

Fixed:
- **The reclaim item took any station answer for a landing:** a voyage whose landing order was answered `keep course` (GEAR's own M6.2) was named as landed, and its leftovers were asked to be removed. Only `station <id>: land …` now counts.

## Upgrading

From 0.6.76: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.77`, then any `gear` call, and restart the engine — the binary changed.
