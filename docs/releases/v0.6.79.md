# GEAR v0.6.79

A voyage whose landing order was answered `keep course` can land later.

Fixed:
- **No second landing order:** the "ready to land" item opens once per voyage, so a voyage whose order was answered `keep course` and then given new tasks never got another, and `station <id>: land` on the old, resolved item did nothing. A new task in such a voyage now clears the old order's mark, and the next time every task is done a new order opens. A voyage that landed keeps its mark.

## Upgrading

From 0.6.78: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.79`, then any `gear` call, and restart the engine — the binary changed.
