# GEAR v0.7.6

A stacked task no longer rings as a parallel change.

## Fixed

- **The parallel-change check reads a stacked task's own files** (Lawrence M-2306 to M-2379). A task started from another task's work (its branch holds that task's branch head or accepted candidate) is no longer paired with that task. The files it inherits from that work are not counted as its changes, so it is not paired with a third task over them either. Two tasks cut side by side that change the same file still ring.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.6`). The skill did not change. A running engine restarts itself on the new binary.
