# v0.7.47

## Fixed

- A landed voyage's records are not asked for again after GEAR merged them.
  Once a landing merged the captain's records branch and deleted it, a later
  reclaim scan of the same landing took the deleted branch for a missing push.
  When the next voyage's captain branch was already on the remote, it rang the
  captain urgently to push records that were already on the integration branch.
  The landing now remembers that the records were merged: a branch that is gone
  after that is the deletion GEAR made. A new records commit on the branch after
  the landing is still merged, as before.
