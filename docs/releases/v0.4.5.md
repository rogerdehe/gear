# GEAR v0.4.5

One store and one engine per Herdr session. Until now every project on the machine used `~/.local/state/gear/gear.db`, and its one engine drives only the Herdr session it was started from, so a project registered from another session had its lanes started in the wrong session, away from its captain.

- Without `GEAR_DB`, `gear` uses the store registered for the caller's Herdr session; a named session that has none gets `~/.local/state/gear/<session>/gear.db`, the default session keeps `~/.local/state/gear/gear.db`.
- Projects in the same session share its store and engine, as before. `GEAR_DB` still overrides.

## Upgrading

From 0.4.4: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.4.5`, then any `gear` call. A session that already has a registered store keeps it. A project registered from another session into the shared store is registered again from its own session (`GEAR_ADMIN=1 gear admin init gear/gear.toml`), which creates its own store; its home worktrees are reused.
