# GEAR v0.6.110

A rework packet no longer names a handover document that is gone; a review message is short; a queued remerge closes the merge-failed item.

Fixed:
- **A rework packet named a handover document that did not exist** (Lawrence M2: F-85 on T-130, F-100 on T-147). When a lane's agent was switched while its worktree held another task's branch, the engine committed the handover document on that branch; the lane's switch to its own task branch then removed the file. The document now stays untracked when the worktree is not on the task's branch, so it survives the switch; a worktree on the task's branch still gets the commit.

- **A review message copied the whole review to the captain** (M7 T-641): it now carries the verdict, the title of each blocking finding, the review file's path when the reviewer handed one, and `gear --show T-n` for the full findings, which the verdict record still keeps.
- **A merge-failed item stayed open after its remerge was queued** (M7 T-642; Lawrence M-921): the `- remerge` line now resolves the task's merge-failed item as well as its merge-lost item, with `remerge queued (O-n)`.

Added:
- Herdr's `workspace.close` is available to the engine (M7 T-640); the reclaim uses it in a later release.

## Upgrading

From 0.6.109: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.110`, then any `gear` call, and restart the engine — the binary changed.
