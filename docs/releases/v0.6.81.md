# GEAR v0.6.81

A feature's integration task merges, and features run without false alarms.

Fixed:
- **A feature never reached the integration branch:** the integration task's merge waited for its own members to land on the integration branch alone, which they never do (they merged into the feature branch, its candidate). It now carries them, as designed.
- **False "parallel changes" between members of one feature:** the scan read every member against the integration branch, so each member listed the files of the members merged before it. A task is now read against its own base, and a member already in its feature branch is skipped.
- **A failed merge closed as "voyage finished":** a voyage with accepted work not yet merged is open, so its merge-failed and merge-lost items stay until the work lands.
- **Reviewer worktrees stashed test temp directories:** `target/` is ignored in every crate.

Changed:
- **Seat branches name their voyage:** the default `[conventions] seat_branch` is `{project}/{seat}/{voyage}` (e.g. `acme/captain/M2`); the old `{project}/{seat}/home` branches are renamed when the engine settles a seat. A project that sets its own template keeps it.

## Upgrading

From 0.6.80: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.81`, then any `gear` call, and restart the engine — the binary changed.
