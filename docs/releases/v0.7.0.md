# GEAR v0.7.0

M7 and M7.1: client fleets run smoothly, and the backlog is cleared. Messages reach an idle seat as text, a new binary takes over every engine by itself, a voyage takes GitHub issues by its own label, every surface agrees on when a voyage has landed, and housekeeping runs without a captain. v0.6.110 to v0.6.114 were M7's releases; this one marks the voyage and adds M7.1.

## From M7 (released as v0.6.110 to v0.6.114)

- **An idle seat gets its messages as text** in one prompt (header, body, how to reply); a busy seat keeps the one-line doorbell. A long ring is cut with a pointer to `gear`.
- **A replaced binary restarts the engine by itself**: no new merge starts, the running ones finish, and the new binary runs under the same lock. `gear admin restart` does the same at once.
- **Voyage-scoped GitHub issue intake**: a `<project>/<milestone>` label created at departure; a labeled issue becomes one captain item; a land is refused while a labeled issue is pending.
- **Smaller messages and store**: a review message carries the verdict, the blocking titles and the review's path; engine items list at most 10 lines per section; the store keeps the last 20 plan versions per project.
- **Merge and landing fixes**: a red feature carrier is kept when a member is added; a queued remerge closes the merge-failed item; a carrier that landed without the carried work is named; the reclaim closes the merge workspace and sweeps only the project's current voyage; a rework never names a handover document that is gone.
- **One rule for "finished"**: a voyage whose land order waits is not finished (the captain sees that order); a cancelled task is never a lane's next task.

## M7.1

Changed:
- **The board calls a voyage landed only after its land order is answered `land`** (T-670; Lawrence M2). The board, the captain's page and the reclaim read one rule.
- **The engine prunes every project's plans once a day** (T-656, T-666), whether its captain runs or not.
- **The landing reclaim deletes cancelled tasks' branches** (T-655), after recording each tip sha on the voyage's landing thread.
- **Processes left in GEAR worktrees reach the captain** as one item (T-657, T-658); nothing is killed.
- **An installed skill copy carries the version that wrote it** (T-681); the captain's page names every copy older than the binary.
- **Lane rules: never borrow another CLI's credentials** (T-682); a missing login is reported as blocked.

Added:
- **`- restart <lane>` under `# Staff`** (T-669, T-665): a managed restart on the lane's current model, through the at-once path.
- **`gear issue file`** (T-663, T-664, T-683): the captain files a forge issue through the engine, which files it once, retries a failure and records the number.
- **A rebind can name the project root** (`repo=.` or no `repo=`) (T-674).
- **`gear admin init` warns about a model whose context window neither the config nor its CLI gives** (T-672).

Fixed:
- **F-341: feature members got no light stage check** (T-652): reviewer seats kept the stamps of finished features, so a new feature's first check found no seat; stale stamps no longer count, and a carrier's review names members left without a check.
- **The captain's hints**: an inline ring carries the goal once (T-653); a land order's hint offers `land` (T-667); a friction item's hint names `gear friction close` and its resolve is refused (T-668).
- **Screen reading**: Codex's writer-lock screen reads as blocked (T-676); pi, Codex and OpenCode markers match only the CLI's own lines, not tool output (T-677 to T-679); a guardrail item rings only when the agent stopped (T-654).
- **Captain tools**: one rebind that cannot apply yet no longer blocks the others (T-673); a moved or cancelled task's notice interrupts the old lane (T-671); a hand-in outside the lane's files is flagged (T-675); a merge waiting on a carried task whose own merge failed names the way out (T-660); a later `switch_at_once` speeds up a pending switch (T-661).
- **Smaller fixes**: the idle view keeps the last task's work span (T-680); agy usage without counts reads unknown (T-662); the health cost test holds under load (T-659).

## Upgrading

From 0.6.111 or later: install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.0`) and reinstall the skill copies (`gear admin install-skill --agent <agent>` for each agent you use); a running engine restarts itself on the new binary once its merges finish. From an older version, stop and start the engine once by hand.
