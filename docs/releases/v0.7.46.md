## Fixed

- A landed feature no longer removes a lane's own worktree. After a feature's
  integration task merged, GEAR removed the feature's merge worktree by opening
  the worktree that has the feature branch checked out, and that was the
  integration task's lane worktree: the lane lost its worktree and its Herdr
  workspace (MissHerAI M2.1, 2026-11-18: media after T-73, room after T-71).
  A worktree any seat of the project records as its own is never removed
  there.
