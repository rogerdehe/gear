# v0.7.48

## Fixed

- A lane started in the tick its voyage departed is moved to the voyage's seat
  branch. The engine starts the lanes one after another in one tick, and each
  reads the voyage as it starts; when the departure's apply landed during that
  tick, the first lane got the seat branch named for the time between voyages
  (`<project>/<lane>/between-voyages`) while the lanes after it got the
  voyage's name (alfred M1, 2026-11-19). The seat-branch settle that already
  moved the previous default's name now also moves the lane's own
  between-voyages branch to the voyage's name, and tells the captain.
- A departure's apply no longer calls a lane that is still starting retired.
  The warning "T-n is on lane x, which is retired" is now only for a lane no
  seat works or is starting.
