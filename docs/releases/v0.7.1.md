# GEAR v0.7.1

A skill fix: the captain's guide named the wrong records branch.

## Fixed

- **The landing's records branch is the captain's seat branch.** The skill said `<project>/captain/home`; the landing merges the branch `[conventions].seat_branch` names with `{seat}` = `captain` and `{voyage}` = the landing voyage (`<project>/captain/<milestone>` by default). The skill also says that merge runs without the gate, so the branch holds records only.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.1`) and reinstall the skill copies (`gear admin install-skill --agent <agent>` for each agent you use). A running engine restarts itself on the new binary.
