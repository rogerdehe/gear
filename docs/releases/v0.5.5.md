# GEAR v0.5.5

The second batch of M5.1, the fixes another project's fleet reports: a review that a merge could not find because the verdict never checked where the branch had been pushed.

Changed:
- **T-438 — a reviewer pushes its review branch to the project's remote, and a verdict whose branch is not there is refused at once:** the review packet names the exact `git push <remote> HEAD:refs/heads/<branch>` command instead of a bare "push it", and a full review's verdict checks that `<remote>/<branch>` holds the reviewer's commit before anything is stored, so a reviewer that pushed to a second remote is told to push again instead of handing in a verdict the merge then cannot find.

Nothing outside the tasks above.

## Upgrading

From 0.5.4: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.5.5`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
