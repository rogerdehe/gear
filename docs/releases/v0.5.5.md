# GEAR v0.5.5

The second batch of M5.1, the fixes another project's fleet reports: a review that a merge could not find because the verdict never checked where the branch had been pushed, and a push watchdog that asked a lane waiting on something outside GEAR, again and again, why it had not pushed.

Changed:
- **T-438 — a reviewer pushes its review branch to the project's remote, and a verdict whose branch is not there is refused at once:** the review packet names the exact `git push <remote> HEAD:refs/heads/<branch>` command instead of a bare "push it", and a full review's verdict checks that `<remote>/<branch>` holds the reviewer's commit before anything is stored, so a reviewer that pushed to a second remote is told to push again instead of handing in a verdict the merge then cannot find.
- **T-440 — a lane declares a wait on something outside GEAR, and the push watchdog leaves it alone until the wait ends:** `gear send --kind blocked --task T-<n> --attempt <n> --on external "<what you wait for>"` stores the wait and tells the captain what the lane waits for, a later message on the task or 120 minutes ends it, and while it lasts the no-push question is not asked — so a read-only audit waiting on CI and the captain's fixes is no longer pestered every few minutes.

## Skill

Nothing outside the tasks above.

## Upgrading

From 0.5.4: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.5.5`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
