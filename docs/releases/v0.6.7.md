# GEAR v0.6.7

M6, station S5's speed work, continued: the gate has no wall-clock test, and the think watch reads a lane's work once a minute instead of every tick.

Changed:
- **T-520 — the gate has no wall-clock test:** two engine tests asserted an elapsed time and failed under the gate's parallel load, so both now check the fact instead. The idle merge step is proved cheap by what it does not do (an idle tick leaves the lost-scan time where it was, so it reads none of the done tasks), and the round selection on 10 000 messages and 300 ended rounds is proved cheap by its `EXPLAIN QUERY PLAN` — the rounds by their key, the answered threads by `thread_messages`, no scan of either table.
- **T-521 — the think watch reads a lane's work once a minute, not every tick:** the fingerprint of a lane's worktree (three git commands and a hash of their output) was taken for every lane on every tick, some 500–800 ms of the quiet step on a large repository. The last fingerprint and its time are now kept per seat, and the worktree is read again only when a minute has passed (or the attempt changed); a change seen up to a minute late moves the "no change for" clock by at most that much.

## Skill

Nothing outside the tasks above.

## Upgrading

From 0.6.6: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.7`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
