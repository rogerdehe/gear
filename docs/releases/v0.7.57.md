# v0.7.57

## Added

- `gear reply M-<n> --false-alarm -m "<why it is wrong>"` resolves an item
  GEAR raised (sent by `engine`) that was wrong, with the text marked
  `false alarm: `. GEAR's own fixes start from the marked items instead of
  from whoever happens to notice. An item from a seat is refused: only GEAR's
  own items can be its false alarms.

## Fixed

- The health watch no longer names the captain's own processes as leftovers.
  A command the captain ran in its own worktree (a local stack a ship starts
  in the background, its parent gone) was reported as left in a GEAR worktree
  that no live seat holds, on every ship. A process whose worktree is checked
  out on the captain's seat branch is now the captain's while the captain is
  live.
