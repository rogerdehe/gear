# GEAR v0.6.41

Fixed:
- **A merge queued before `carried-by` was set no longer runs on its own:** marking an accepted task `carried-by: T-m` stopped new merges of it, but a merge already in the queue still ran a standalone gate, or kept waiting in a cycle for work that was already in its carrier. Such a queued merge is now closed (Intended becomes Void, a restart's Unknown becomes Failed, with the reason "the work lands with T-m's merge"), and the task lands with its carrier as before.

## Upgrading

From 0.6.40: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.41`, then any `gear` call, and restart the engine. The skill did not change.
