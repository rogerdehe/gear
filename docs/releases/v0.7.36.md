# GEAR v0.7.36

A warm reviewer that resumes an earlier review starts it at once; a lane working one task while another waits is shown working.

## Fixed

- **A re-review waited minutes on a warm reviewer.** A standby reviewer picked for a re-review resumes that review's conversation: its agent quits and starts again. The review start handed a standby seat a review only while its agent was idle or done, so after the quit nothing drove the switch on; the seat sat until it was released as gone two minutes later and the review began again on a new agent (MissHerAI T-17 and T-22, 2026-11-17). The review start now goes on driving a standby seat whose session switch is in flight.
- **The queue showed a working lane as idle.** A lane whose task waits on something (`gear send --wait`) gets its next task meanwhile; the queue and the board said "idle: waiting for ..." while it worked that next task. A lane with a task in flight that declares no wait is working, and the queue names that task.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.36`); the engine restarts on it by itself. Nothing to configure.
