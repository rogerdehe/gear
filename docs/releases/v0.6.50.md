# GEAR v0.6.50

Fixed:
- **`gear captain handover --project <p>`:** the user's own terminal names the project whose captain moves. Two projects sharing one checkout made the working directory name the first of them. A seat may not name another project than its own.
- **The handover document is found on any branch:** the outgoing captain commits it on its home branch, so the new captain was told there was none (Lawrence) or pointed at an older one on the integration branch (Prometheus). Its item now names the branch, the commit and `git show <commit>:<path>` when the document is not in the checkout.
- **The outside-pane refusal of a handover names the way that works:** a CLI that runs its commands outside its pane (Codex) cannot prove it is the captain; the refusal names `gear --session <s> captain handover --project <p> --pane <new>` from a shell pane with no agent.

Why: the Prometheus and Lawrence captains handing over from Codex to Claude panes (2026-11-04).
