# GEAR v0.7.37

The branch sweep compares with the configured integration branch; a merge conflict's item says what settles it.

## Fixed

- **The branch sweep named branches as not on `dev` while they were on the integration branch.** The sweep took a repo's integration branch from the first task it found there, and an older task's recorded base (`dev`, from before the config named `selina/dev`) made it name T-19's merged branch as holding 17 commits "not on dev" (MissHerAI, 2026-11-17). It now judges every repo's branches against the integration branch the config names now.
- **A merge conflict's item offered only a remerge, which fails again.** The item of a merge that failed on a conflict now names the two ways to settle it: a fail verdict that sends the task back to its lane to merge the integration branch and resolve the conflict, or a merge by hand into the integration branch, after which `- remerge <task>` records it as merged.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.37`); the engine restarts on it by itself. Nothing to configure.
