# GEAR v0.6.19

A seat names itself; one project can be paused.

Changed:
- **Every seat runs `gear --session <session> --pane <pane>`:** GEAR used to recognize a caller by its process and environment. A CLI that runs its commands in one shared background process (Codex) carries the environment of whichever pane started that process, so two such captains could not both be recognized. Every text GEAR sends a seat (doorbells, task, rework and review packets, continue notices) now spells the seat's full command, and the skill says to run every `gear` command that way. A caller in no pane is never guessed from an inherited pane any more; a caller in a pane that names another pane is refused. The CLI-specific session matching of v0.6.17 and v0.6.18 is removed.
- **`gear admin pause <project>` / `gear admin resume <project>`:** the engine stops dispatching, ringing and merging for one project while the other projects of the same engine go on.

## Upgrading

From 0.6.18: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.19`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
