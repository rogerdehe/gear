# GEAR v0.6.48

Fixed:
- **Accepted work has two hours to land:** a carried task is waited for while its carrier is still being worked on (ready, running, verifying, or its merge in flight), but only for two hours after its acceptance. After that it is lost work, whatever carries it, and the urgent item rings. A lost item about a task whose carrier is active again is closed (Lawrence M708-M712).
- **A remerge of work already on the integration branch records the attempt merged:** the failed-merge item closed, but the attempt kept no merge time, so the tasks that depend on it never started (Prometheus T-609 → T-616).

## Upgrading

From 0.6.47: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.48`, then any `gear` call, and restart the engine. The skill did not change.
