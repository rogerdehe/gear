# v0.7.43

## Fixed

- The review-stall count and its told mark, and the verdict-wait mark, are
  kept per project. Their keys named only the task and attempt, so a hand-in
  read another project's count for the same task id and number: MissHerAI's
  T-58 attempt 2 rang "no reviewer has its packet" 0 min after its hand-in,
  on Lawrence's T-58 attempt 2 of two weeks before, while the engine was
  resuming the reviewer.
- After an apply, the rewritten plan file drops each `state: ready` line it
  carried out; `hold` and `cancelled` stay. A `state: ready` on a task that is
  already ready is accepted as a no-op, so a plan file written before this
  version applies again without hand edits.
