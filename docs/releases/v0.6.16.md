# GEAR v0.6.16

Two projects in one repository: what the first two fleets sharing one checkout exposed before their departure.

Changed:
- **Merges into one branch run one at a time across projects:** two projects whose lanes land on the same integration branch of the same repository no longer gate side by side. While one project's merge holds the branch, the other's stays queued and then merges on top of it, instead of gating on a base that is about to move and losing the push race.

Known: GEAR keeps the lanes of one project apart by `owns`, not the lanes of two projects that share a repository. Until it warns about that, the captains of such projects agree which project owns each directory for their voyages.

## Upgrading

From 0.6.15: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.16`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
