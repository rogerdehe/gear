# GEAR v0.6.53

Added:
- **Every gate run is told what it judges:** it gets `GEAR_GATE_PROJECT` (the project id), `GEAR_GATE_ROUND` (the id of the run's first merge op, lowercase without the dash, e.g. `o6543`) and `GEAR_GATE_TASKS` (the task ids of the merges the run judges, space-separated, in merge order, e.g. `T-637 T-646 T-662`), next to `GEAR_GATE_TEMPFAIL` and `GEAR_GATE_FAILED`. A gate that runs CI elsewhere names its CI branch `<project>/gate/<round>` and puts the tasks in the CI run's title, so every gate branch has an owner and every run says what it judged.

Fixed:
- **A set-aside task returns as a resume, not a rework:** a task the captain held (`state: hold`) and set loose again is delivered with the Resume text — it says the task was set aside, not failed, so there is no Rework section to look for. T-548 came back as a rework with an empty one.
- **A merge waiting for another task is not reported as lost:** a merge op that is `Unknown` because it is queued behind another task counts as landing in the branch sweep, like `Intended`, `Executing` and `Submitted`. The captain was told "nothing will merge them" for T-548 while its merge waited behind T-547.
- **A rework or a resume says how to get onto the task's branch:** both texts now say `Branch: <branch>. Before you change anything: git switch <branch> (your worktree may still be on the branch of the task you did last)`. A lane's worktree was still on `hull/t548` and the rework was committed there first (T-547).
- **A pane holding several captain seats keeps the name of the seat bound first:** the engine no longer flips its agent between the projects' captain names on every pass. After `gear captain take lawrence` the Prometheus captain was renamed `lawrence-captain` again and again, and every prompt by `prometheus-captain` failed.

Why: the user's SelyraAI gate branches (`ci/candidate/<sha>`) belonged to no project and no run said which tasks it judged; hull found the two wrong signals while T-548 waited for T-547; and the Prometheus captain could not be reached by name after taking the Lawrence seat (2026-11-04).

## Upgrading

From 0.6.52: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.53`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use. Nothing to set: the three gate variables are given to every gate run.
