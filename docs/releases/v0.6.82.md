# GEAR v0.6.82

Feature integration, stage 2: one reviewer per feature, light checks that block nothing, and one owner lane for the fixes.

Added:
- **A member is accepted at hand-in:** a task of a feature merges into the feature branch as soon as it is handed in (conflict check and `feature_check`), with no blocking review.
- **One reviewer per feature:** the feature's reviewer gives each member a light check of direction and plain breakage, keeps its conversation from member to member, and reviews the integration task in full. A light check sets no verdict; at 5 minutes it is reminded once that it is a stage check and may go on with a reason; it is never stopped.
- **The full review sees the light checks, and its fix goes to one lane:** the integration task's review lists every member with its light-check findings; a fail of the review or of the full gate is one rework of the owner lane (the lane holding most members), on the feature branch.

Fixed:
- **A feature's merge named a branch that does not exist:** the merge queued after a review, and a `remerge`, named `<lane>/t<n>` for an integration task; they now name the feature branch and keep it, so a remerge after the captain merged the integration branch into the feature branch takes that fix.
- **The merge gate is faster:** slow tests were trimmed or moved to `make full`.

## Upgrading

From 0.6.81: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.82`, then any `gear` call, and restart the engine — the binary changed.
