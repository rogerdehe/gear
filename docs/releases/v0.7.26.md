# GEAR v0.7.26

The landing's reclaim never deletes a shared integration branch.

## Fixed

- **A shared integration branch survives a landing.** The reclaim deleted a landed project's integration branch once its tip was on the release branch. A project whose integration branch is a shared one (`dev`, also used by other projects and the release flow) lost it at every reclaim scan (SelyraAI, 2026-11-12: the shared `dev` deleted twice after Prometheus M5 landed). The reclaim now deletes an integration branch only when it is in the project's own namespace (`<project>/dev`), and never the release or staging branch.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.26`); the engine restarts on it by itself. Any project whose `[conventions] integration` is not under `<project>/` should check that the branch still exists on its remote.
