# GEAR v0.6.92

A feature's reviewer comes free after a stage check, an integration task's rework reaches its lane, and a lane's report after the hand-in no longer refuses its merge.

Fixed:
- **A feature's integration task was never reviewed after a member's stage check** (Lawrence M2: T-96 waited 20 minutes while review-3, F-1's reviewer, sat idle): a stage check whose member was accepted at hand-in left no review verdict, so its seat counted as busy. A stage check ends with its marker (`done`).
- **A rejected integration task was handed in again instead of reworked** (Lawrence M2: T-97 attempts 2 and 3 went back to review on unchanged code; the reviewer's own commit had moved the feature branch, and web never got the rework). Once an integration task has an attempt, its next step is the lane's rework, unless a member merged into the feature branch after that attempt (the captain's way to fix it: a new member such as T-103), and then the engine hands the branch in. Dispatch and the hand-in read the same rule, and the rework waits for unmerged members.
- **A lane's report committed after the hand-in refused the accepted merge** (GEAR M6.3: T-604, "a change after hand-in needs a new attempt"). A commit that writes only the voyage's records merges with the reviewed work.

## Upgrading

From 0.6.91: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.92`, then any `gear` call, and restart the engine — the binary changed.
