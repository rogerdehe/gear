# GEAR v0.6.109

Tasks of a voyage that has not departed wait for departure, and the board no longer renames a captain's tab.

Fixed:
- **Lanes picked up tasks of a voyage that had not departed.** A plan applied without `depart: now` still let the engine dispatch its ready tasks. The dispatcher now skips a task whose milestone has no departure; tasks with no milestone are unchanged.
- **Captains' own tabs were renamed "<project> board".** `gear board` renamed the tab it ran in, so a captain that started the board in its own pane lost its tab name. The board renames no tab now; the skill opens it with `herdr tab create --no-focus --label "<project> board"`.

## Upgrading

From 0.6.108: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.109`, then any `gear` call, and restart the engine — the binary changed. A captain whose tab was renamed renames it back with `herdr tab rename`.
