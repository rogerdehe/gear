# GEAR v0.6.76

An issue split into several tasks closes when its last task lands.

Fixed:
- **An issue closed on its first task's merge:** the forge closed a task's issue as soon as that task landed, so an issue split into several tasks (Carthage #359: seven) closed after the first. It now closes when the last of its tasks that is not cancelled has landed; every landing is still commented.

## Upgrading

From 0.6.75: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.76`, then any `gear` call, and restart the engine — the binary changed.
