# v0.7.55

## Fixed

- `integrated-by=` accepts a squash landing. Under `merge_method = "squash"`
  the task that lands another task's work merges a new commit, so the
  carried candidate is never an ancestor of the integration branch and the
  pass was refused (alfred M1, 2026-11-19: T-34 had landed with T-57, and
  T-18 with T-61). A candidate inside the integrator's accepted candidate,
  the lane's commit before the squash, now counts as landed with it. One
  that is not inside it is still refused: T-17's accepted rework was not
  inside T-61's candidate, and its fix was indeed missing from the branch.
