# GEAR v0.7.22

A landed voyage no longer shows as sailing because of work that reached the release branch outside GEAR.

## Fixed

- **Work of a finished voyage that is on the integration or release branch is marked merged.** The board and the landing count a voyage as open while a Done task's accepted work has no merge record. The lost-merge scan, which records work that landed another way, skipped every task of a voyage whose tasks were all done or cancelled. A task whose GEAR merge had failed and whose work was then merged by hand never got its record, and its voyage showed as sailing for good: one voyage, landed days before, still read as sailing with three such tasks. The scan now checks such a task's candidate against the integration and release branches and marks it merged when it is on either; its merge-failed item then closes.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.22`) and restart the engine. Nothing to configure; an old voyage that shows as sailing for this reason turns landed within one scan.
