# GEAR v0.6.52

Added:
- **The batch merge (`[conventions] merge_batch`, default 1):** with a value above 1, up to N passed merges of a project are merged together onto the integration branch, gated once, and land together. A red batch fails only the task whose changes match the paths the gate wrote to the file `$GEAR_GATE_FAILED` names; the others merge again. With no such match the batch is halved: it is gated again in smaller batches until the culprit is alone. `merge_batch` above 1 together with `merge_parallel` above 1 is refused — a batch is gated once and cannot also be a train. With the default 1 nothing changes: each merge is gated alone.
- **The gate contract for `GEAR_GATE_FAILED`:** every gate run gets `GEAR_GATE_FAILED`, the path of a file. A gate that can tell which tests failed writes the repo-relative files or directories they cover there, one per line; a gate that writes nothing is fine. A batch merge uses this to name the one task whose changes broke the gate, instead of failing all of them.

Fixed:
- **A project with no unfinished task releases its standby reviewers at once,** without waiting for `reviewer_release_idle_min`: once every task is done or cancelled the project's idle standby seats are let go, instead of staying up until a task or a configured idle time comes.
- **An item addressed to a retired seat closes with it:** when a lane or reviewer retires, the items still open for it are resolved ("closed: its seat retired"). Lawrence M1 landed with eight instructions to its retired seats that nobody could close.
- **`gear admin init` no longer moves a Herdr session to another store without a word:** an init with a different store for a session whose registered store exists is refused, naming both paths; `--move-store` allows the move.
- **`gear captain take` keeps the agent's name** on a pane that already holds another project's captain seat (reported as kept). The Prometheus captain took the landed Lawrence seat and its agent was renamed `lawrence-captain`, so messages by name could not reach it.

Why: the SelyraAI merge queue held 22 passed tasks (about two hours) because every merge ran a full CI round by itself (scope 9), and Lawrence M1 landed with two standby reviewers left up because `reviewer_release_idle_min` was unset (scope 10).

## Upgrading

From 0.6.51: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.52`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use. To use the batch merge, set `merge_batch` in the project's `[conventions]` and re-apply the config.
