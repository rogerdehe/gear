# GEAR v0.6.37

Added:
- **`state: hold` sets a running task aside for more urgent work:** its open attempt closes so the lane's seat takes its next task, and the lane is told to push what it has to the task's branch and end its turn. The task keeps its branch and comes back with `state: ready`. Before, a running task could only be cancelled and re-created to make room for urgent work.

Fixed:
- **A carried task's branches are left alone until its carrier lands:** the branch sweep named a done `carried-by` task's branches as "done but holding commits nothing will merge" and asked the captain to merge or delete them, although the carrier's merge will land them.

## Upgrading

From 0.6.36: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.37`, then any `gear` call, restart the engine, and install the skill again (`gear admin install-skill --agent <cli>`): it changed.
