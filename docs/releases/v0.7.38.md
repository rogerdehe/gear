# GEAR v0.7.38

A delivery to a seat whose agent is starting waits for it instead of ringing "lane is stuck".

## Fixed

- **A restart rang a false "lane is stuck".** A restart opens the seat's new binding and types the agent's command in one tick; a delivery aimed in that same tick found only a shell in the pane, failed as agent-gone, and the engine raised an urgent "lane is stuck" item while the agent was still starting (MissHerAI T-26, 2026-11-17, right after `- restart room`). A delivery to a pane without an agent now waits while the seat's binding is less than 60 seconds old; after that it fails as before.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.38`); the engine restarts on it by itself. Nothing to configure.
