# GEAR v0.6.24

Fixed:
- **`/new` on an OpenCode lane is confirmed:** Herdr reports no session for an OpenCode pane, so after `/new` GEAR never saw the new session, recorded `new-unconfirmed`, raised a false alarm to the captain, and kept the old session on the binding and the attempt. GEAR now asks OpenCode for the newest session in the lane's worktree created since `/new`, and records it.
- **A chartered lane's packet keeps its charter:** the packet footer said "You implement; you never design" to every lane, even one whose config charter makes it the technical owner of its task. A lane with a charter is now told its charter says how it works; a lane without one keeps the default line.

## Upgrading

From 0.6.23: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.24`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
