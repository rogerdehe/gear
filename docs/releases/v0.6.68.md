# GEAR v0.6.68

A second project on a repository gets `<project>/dev` by default.

Changed:
- **Default integration branch for a shared repository:** a project whose repository another project already integrates into on the default branch, and whose config names no integration branch, gets `integration = "<project>/dev"`. Registration writes the line into its config file and, when the remote has no such branch, cuts it from the release branch. A branch the captain pushed beforehand (from a commit the user chose) is kept. `--check` says what registration will set. A config that names the other project's branch is still refused; any other name is the team's.

## Upgrading

From 0.6.67: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.68`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
