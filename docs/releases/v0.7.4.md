# GEAR v0.7.4

GEAR opens the board itself.

## Added

- **`gear board --open`**: run from the captain's pane, it opens the Herdr tab `<project> board` in that workspace, in the project's repository, running the board, and replaces an earlier board tab there (never the caller's own tab). It returns once the board has drawn its first frame; when it does not draw within 20 s it fails and prints what the tab shows. Captains opened the board by hand before, and a tab whose command never ran stayed an empty shell that nobody noticed.

## Changed

- **The captain's guide opens the board with `gear board --open`**, not with hand-typed Herdr commands.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.4`) and reinstall the skill copies (`gear admin install-skill --agent <agent>` for each agent you use). A running engine restarts itself on the new binary.
