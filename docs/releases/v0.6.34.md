# GEAR v0.6.34

Fixed:
- **A merge-failed item closes once its work has landed:** when a task's candidate reached the integration branch another way (integrated by a later task, or a later merge), its old merge-failed item stayed open and rang the captain again and again, and a remerge was refused because the candidate was already in. The engine's periodic scan now closes such an item once the attempt it names has merged.

## Upgrading

From 0.6.33: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.34`, then any `gear` call, and restart the engine. The skill did not change.
