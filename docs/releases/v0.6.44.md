# GEAR v0.6.44

Fixed:
- **A finished task's leftover wait no longer shows its lane as waiting:** a task that finished with its declared wait still written (here: done with `external`) made `gear queue` and the board report the lane "waiting for external (-)" with no working task, while the lane in fact worked on its next task. The view now follows the engine's rule: a wait counts only while its task has an unfinished attempt. Dispatch was never affected.

## Upgrading

From 0.6.43: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.44`, then any `gear` call, and restart the engine. The skill did not change.
