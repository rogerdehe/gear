# GEAR v0.6.59

Fixed:
- **The engine never closes a pane another seat holds, nor a captain's pane:** every pane the engine closes (a released reviewer, a dead seat's shell, a retired seat whose agent still runs) is checked first: when another seat's current binding is active on that pane, the close is refused (`pane_in_use`). The retired-seat sweep never touches a captain seat.
- **A pane that holds two seats keeps one agent name** (T-570): the name restore no longer flips the agent between the seats' names.
- **A newer station or branch report replaces the older one** (T-568): one open item per station thread and one per branch sweep, not a pile.

Why: Prometheus, 2026-11-05: the live Prometheus captain's pane carried a released Lawrence captain seat's agent name, and the retired-seat sweep of v0.6.56 closed the pane by that name, killing the captain.

## Upgrading

From 0.6.58: `gear admin stop`, install v0.6.59, then any `gear` call, and restart the engine. The skill did not change.
