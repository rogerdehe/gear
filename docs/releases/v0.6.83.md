# GEAR v0.6.83

A failed reviewer start no longer stops the project.

Fixed:
- **Every tick of a project failed with `BAD_TRANSITION: seat: active -> unknown`:** when a reviewer seat that was already working (a feature's reviewer kept for its next light check) failed to start a job, GEAR tried to park it as Unknown, a step an active seat may not take; the whole project's tick failed from then on and its merges stood still. The seat now goes to NeedsCheck, and a seat that can take neither stays as it is.
- **One name for a task's branch:** every place that names a task's branch (packets, review prompts, merges, the parallel scan, handover, the forge) reads the feature override, so a feature's reviewer is told the feature branch.
- **Feature integration, stage 3 is in:** before a feature's full review its branch takes the integration branch in (a conflict is one rework of the owner lane), and a red full gate on a feature is bisected beside the merge train to name the member that turned it red.

## Upgrading

From 0.6.82: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.83`, then any `gear` call, and restart the engine — the binary changed.
