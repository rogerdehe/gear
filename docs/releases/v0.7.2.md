# GEAR v0.7.2

A landing no longer sweeps away the next voyage's design.

## Fixed

- **The landing reclaim keeps the next voyage's seat branch** (Lawrence M3 → M3.1). The captain's seat branch of a voyage that has not departed (`<project>/captain/M3.1` by default), its worktree and that worktree's Herdr workspace are kept and no longer named as leftovers. Before, the sweep removed the clean, pushed worktree within minutes and asked the captain to delete the branch.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.2`) and reinstall the skill copies (`gear admin install-skill --agent <agent>` for each agent you use). A running engine restarts itself on the new binary.
