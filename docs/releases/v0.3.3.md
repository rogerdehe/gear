# GEAR v0.3.3

A captain cannot be lost any more.

- **`gear captain take`: start your CLI, run one command, you are the captain.** In any pane, start plain `claude` or `codex` (no flags, no environment variables), go to the project's root and run `gear captain take` (or tell the agent "take over the captain"). Outside the project, it takes the only registered project, or lists them so the agent asks you which: `gear captain take <project>`. GEAR asks the project's own Herdr session, so a Codex whose tools run in its shared daemon (started from another pane or session) is found too. The captain seat moves to that pane at a new generation; the old captain's pane may be gone or still open. One urgent item says which pane took it and which it left. A pane bound to a lane or a reviewer cannot take it.
- **No `GEAR_CTX` needed.** A `gear` call without `GEAR_CTX` finds its seat from the pane it runs in (or, for a CLI whose tools run in a daemon outside the pane, from the one unbound pane of that kind). `GEAR_CTX` still works as an override.
- **A lane registered again reuses its home worktree** instead of failing on "already exists".
- **`scripts/test.sh`** runs the whole suite in parallel, prints the build time, every test's time and a warning for each test over 10 s (`scripts/slow-tests.allow` lists the exceptions; it is empty).

## Upgrading

From 0.3.x: stop the engine (`gear admin stop` in your own terminal), `herdr plugin install rogerdehe/gear --ref v0.3.3`, start the engine with any `gear` call. No store change. Do not restart a working captain for the upgrade.

A dead captain (its pane gone, or every `gear` call refused on identity): start `codex` or `claude` in a new pane, `cd` into the project, run `gear captain take`, then `gear` must show `captain · generation <n>`.

Nothing sent to the dead captain is lost: messages are addressed to the captain seat, not to its pane, and stay open. After `gear captain take`, `gear` lists every open thread (the ones that came in while no captain was there included); `git status` shows a plan file the old captain never applied; its own reasoning can be recovered with `codex resume` or `claude --resume`.
