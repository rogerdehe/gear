# GEAR v0.6.22

Fixed:
- **A captain's pass by full sha is merged:** a captain verdict that named the candidate by its full sha, while the attempt stored a short one, was accepted but never queued for a merge, because the merge queue compared the two strings exactly. The task sat done and unmerged, and `remerge` refused it ("has no merge to retry"). Both are now the same commit wherever a verdict is matched to its attempt, and a new verdict keeps the attempt's own spelling. Tasks stuck this way are queued at the engine's next tick, with nothing to run by hand.
- **build-slot:** the ssh wrapper hook under Herdr is removed.

## Upgrading

From 0.6.21: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.22`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
