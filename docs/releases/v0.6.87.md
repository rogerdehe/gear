# GEAR v0.6.87

Nothing lets a voyage stop before it lands.

Changed:
- **The captain's skill and GEAR's reminder state the rule:** GEAR asks the captain to finish the voyage, and nothing in it waits for the user to provide anything; a station is a mark, never a stop, and what only the user can test is listed for the landing. The only reasons to stop are force majeure: the machine or GEAR is down, the captain's own tokens are gone, or every lane is out of tokens or cannot start.

## Upgrading

From 0.6.86: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.87`, then any `gear` call, and restart the engine — the binary changed.
