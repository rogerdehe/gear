# GEAR v0.6.1

M6, station S2: the Cost tab prices tokens at the model maker's official price, peak and off-peak included, and shows a cost it cannot know as unknown, never as $0.00; reviewer seats scale elastically with a user-confirmed raise; dialogs never block a seat; the Tasks tab draws the dependencies; and the engine's multi-step operations no longer wait a whole tick between their steps.

Changed:
- **T-467 — reviewer seats scale elastically:** the configured counts still start and release seats by themselves, but a seat is released only after its role's idle time (default 30 minutes), so a re-review finds its reviewer warm; a count may be raised above the configured one only by a user-confirmed plan line that carries its reason and end condition, and when no hand-in waits the extra seats are released down to the configured count.
- **T-468 — dialogs never block a seat:** a lane's or a reviewer's blocking screen is closed in the same tick and the seat is told what to do instead, a captain's dialog nobody answers is cancelled after ten minutes and the work goes on, and every agent GEAR starts carries the three editor variables, so no git command waits in an editor.
- **T-470 — GEAR near idle: multi-step operations no longer wait a whole tick between their steps:** from the M5 probe lines, the steps the tick already knows run in the same call, adding only a few Herdr calls and a 300 ms terminal settle per session submission and no busy loop.
- **T-484 — the Cost tab prices tokens at the model maker's official price, peak and off-peak included, and shows a cost it cannot know as unknown, never as $0.00:** a pi record whose `cost.total` is 0 while it has tokens carries no cost and is priced from a built-in table of official prices (DeepSeek's flash and pro models, off-peak and peak, Mon-Fri 01:00-04:00 and 06:00-10:00 UTC); a project's `[prices]` entries override it per model id, case-insensitively and without the provider prefix; a record with no price is unknown, and a real nonzero CLI cost is kept.
- **T-494 — the Tasks tab draws the dependencies:** a deps column right of the lanes puts a line from every task not yet merged to each direct dependency it waits for that is shown and not merged, the stage says `waits for N` as a count, the selected row's lines are lit, and a frame too narrow for the lines caps them and shows the rest as `+N`.
- **T-473 — plan tools:** `state: hold` keeps a task out of delivery until it is set ready; a milestone departs only on a `depart: now` line (or at `[schedule] depart_at`); `- drop <milestone>` removes a milestone with no task and no history; a plan apply warns when two Ready tasks on different lanes name one file.
- **T-482 — a reviewer's agent is named after its seat** (`<project>-review-<k>`) and keeps the name across tasks.

Fixed by the captain:
- The no-push alarm counts the lane's answer window from when the ask reached it, so a lane busy in a task no longer raises a false "no word to the captain" item.
- A reviewer seat is free once the attempt of its last packet has a verdict, whoever wrote it; a seat whose last job was a direction check no longer waits forever.
- A new engine closes the "binary changed" items the engine before it left, so a restart no longer leaves a stale item.

## Upgrading

From 0.6.0: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.1`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
