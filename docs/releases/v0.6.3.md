# GEAR v0.6.3

M6, station S4: an omp seat's tokens, model and cost are read from omp's own session log, the way pi's are.

Changed:
- **T-496 — an omp seat's tokens, model and cost are read from omp's session log:** omp (oh-my-pi 18.12.6, a pi fork) writes the same `message`/`usage` session records pi does, under `~/.omp/agent/sessions/<path>/*.jsonl`; the built-in omp profile names the pi-jsonl reader, so GEAR reads an omp session's tokens, model and cost instead of showing them as unknown, and a fixture of a real omp session proves it.

## Upgrading

From 0.6.2: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.3`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
