# GEAR v0.6.32

Changed:
- **Idle reviewers stay up by default:** a standby reviewer is no longer released for being idle. The project's `[quota] temps` are the reviewers it keeps, and a kept agent takes its next job with `/new` or resumes its task's conversation. Set `[quota] reviewer_release_idle_min` to give idle slots back after that many minutes.
- **The board folds a long goal:** the folded header shows the first three lines of the voyage goal, ending in `…`, so the task list keeps its room; `d` shows the whole goal.

Fixed:
- **A model switch no longer waits for ever behind a provider retry:** OpenCode retries a provider error (a 429, "resource exhausted") for ever, so a switch that waited for the turn to end never ran. The OpenCode profile now knows the retry line, and a pending switch stops such a turn through the session API, then switches.

Skill:
- A fault in the merge gate itself is the captain's first hand fix: run the fixed gate once by hand, push it to the integration branch, tell the captains who land there.
- The captain text no longer asks the captain to release idle reviewers.

## Upgrading

From 0.6.31: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.32`, then any `gear` call, and restart the engine — the binary changed. Install the skill again (`gear admin install-skill --agent <cli>`): it changed. A project that wants the old reviewer release sets `reviewer_release_idle_min = 30` under `[quota]`.
