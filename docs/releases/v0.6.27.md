# GEAR v0.6.27

Fixed:
- **Nothing tells a captain to stop its lanes for a merge backlog:** the branch-limit item said "finish the reworks before new work", and the captain guide said to hold the lanes to clear a review backlog. A captain read both as an order and stopped every lane. Both lines are removed.

## Upgrading

From 0.6.26: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.27`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
