# GEAR v0.4.7

A running seat follows the project's current config, and a seat that produces nothing reaches the captain.

- **A restart takes the current config.** When a lane's or reviewer's agent has exited from its pane and the engine starts it again, the model, the CLI and the arguments come from the project's current config version, not from what was recorded when the round began. After a re-init that fixes a model id or changes a lane's kind, stop the agent and it comes back on the new config. This also ends the case where a reviewer started on a wrong model could only be cleared by settling its task by hand.
- **Silent seats are reported.** A lane or reviewer that holds work, whose agent is not working, and whose round has produced no model output for 10 minutes raises one urgent captain item on thread `silent:<seat>`: "… has produced nothing for <m> min on T-n … look at the pane, fix the config, then stop the agent so it restarts on the current config". One alert per round, and no second generic stall alert for the same seat.

## Upgrading

From 0.4.6: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.4.7`, then any `gear` call. No store or config change.
