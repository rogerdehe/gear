# GEAR v0.7.24

The idle reminder counts only the tasks left, and a captain working alone no longer gets an hourly station.

## Fixed

- **The idle reminder names the tasks left.** "Voyage M5 is not finished (10 tasks left)" counted the voyage's done tasks too; it now counts only unfinished ones (Prometheus M5: 2 left).
- **No hourly course station for a captain alone.** The course station checks on the lanes every hour; a project with no lanes got one each hour to answer for nothing. Its eta stations, the every-three-done stations and the land order still ring.

## Working alone

The skill's "Working alone" paragraph now says to pull the integration branch by merge or rebase, as the project's rules say, when a push is refused, and where the header's `base=` comes from.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.24`); the engine restarts on it by itself. Nothing to configure.
