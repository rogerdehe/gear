# GEAR v0.6.67

Deps hold a task's first start and its merge, never a rework.

Changed:
- **A dependency holds only the merge once work has started:** `deps` keeps a task from starting until its deps have merged, and since v0.6.64 its merge waits for them too. A task the lane has already worked on (a rework, or one given deps while it runs) is no longer held back from its lane: only its merge waits. A captain can now order two tasks' merges without idling a lane: let the task start, then add `deps: T-<n>`; it merges after T-<n> lands.

## Upgrading

From 0.6.66: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.67`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
