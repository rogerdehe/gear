# GEAR v0.5.6

M5.2, the blank board another project saw after a voyage landed: a milestone no plan describes no longer becomes a voyage the board shows, and plan apply refuses a task whose milestone no plan describes.

Changed:
- **T-441 — after a voyage lands, the board shows that voyage, not a plan-less milestone that departed later:** with no voyage sailing, the board's fallback keeps only the departures whose done sentence the plan described and shows the latest of those, falling back to the latest departure when none is described — so the stories a fleet's plan told stay on the board after the last voyage lands, instead of a voyage with no time, 0/0 tasks and no words.
- **T-442 — plan apply refuses a task whose milestone no plan describes:** a `NEW` block, or an existing task's block that moves it, naming a milestone with neither a `# Milestone <id>` block in the plan file nor a stored voyage with a done sentence is refused before anything is written, with the milestone named and what to add — so a typo or a made-up id never creates a voyage row, and tasks already in such a milestone are left alone.

## Skill

Nothing outside the tasks above.

## Upgrading

From 0.5.5: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.5.6`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
