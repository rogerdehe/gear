# GEAR v0.6.45

Fixed:
- **`- remerge T-n` queues the first merge of a task that is no longer carried:** a task accepted while it was `carried-by` another never got a merge of its own. After its `carried-by` was cleared, `remerge` refused it ("no merge to retry"), so the accepted work had no supported way to land alone. Now remerge queues its first merge; while the task is still carried, remerge refuses and names the carrier.
- **The refusal for a caller outside every pane names the command to run:** an OpenCode or Codex lane whose tools run in a shared daemon must name its pane (`gear --session <s> --pane <p> ...`, since v0.6.19). The refusal said the pane's agent was "not one GEAR knows to do that", which was wrong and gave no way forward. It now spells out the exact command.

## Upgrading

From 0.6.44: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.45`, then any `gear` call, and restart the engine. The skill did not change.
