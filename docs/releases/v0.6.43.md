# GEAR v0.6.43

Fixed:
- **An OpenCode `/new` no longer raises a false "check the profile" item, and the lane's new session is recorded:** OpenCode opens the new session only when the first prompt arrives, not on `/new`. GEAR waited 30 s for a new session id that could not exist yet, told the captain "/new did not change the session id", delivered, and kept the old id on the lane (so a later compaction or resume read the old session). The `/new` is now done once the composer is back. The session OpenCode opens in the lane's worktree afterwards is adopted as the lane's session; only one that has not appeared within 10 minutes tells the captain.

## Upgrading

From 0.6.42: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.43`, then any `gear` call, and restart the engine. The skill did not change.
