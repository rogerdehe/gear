# GEAR v0.6.13

M6.1, bug fixes that reach the users: a station item that can wait for the
user without ringing the captain.

Changed:
- **T-542 — a station item can wait for the user quietly:** a station item answered with `--wait <who> --until <t>` goes to `Waiting` like every captain item — no doorbell until its time, back in the captain's list after it — and a plan `station <id>: land` (or keep course, time-box, cut, move) still settles it from `Waiting`; `--resolve` stays refused on a station item, with the plan-line message.

## Upgrading

From 0.6.12: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.13`, then any `gear` call, and restart the engine — the binary changed. The skill did not change: no `gear admin install-skill` is needed.
