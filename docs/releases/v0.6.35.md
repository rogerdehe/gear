# GEAR v0.6.35

Fixed:
- **A changed review chain argument reaches warm reviewers:** a reviewer kept up between reviews was released for a new model or CLI in the review chain, but not for new arguments alone (a lower reasoning effort, say), so it ran every next review with the arguments it was started with. It is now released before its next review and started again with the chain's current arguments.

Changed:
- **A task no longer repeats the routine check:** a lane tests what it changed with the project's own capped check, named once in the project's instructions (its AGENTS.md or equivalent), plus any command the task's acceptance names. A task names a command only when the proof is its own.

## Upgrading

From 0.6.34: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.35`, then any `gear` call, restart the engine, and install the skill again (`gear admin install-skill --agent <cli>`): it changed.
