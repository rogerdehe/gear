# GEAR v0.7.3

A landing's leftover item stops ringing once the next voyage departs.

## Fixed

- **The reclaim item closes when its landing is over** (Lawrence M-2179). Once the next voyage departs, or the landing is a day old, the open "The voyage landed … left" item is resolved. Before, the sweep stopped but the item stayed open and kept ringing, naming the integration branch the new voyage was using.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.3`). The skill did not change. A running engine restarts itself on the new binary.
