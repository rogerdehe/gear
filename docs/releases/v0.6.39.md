# GEAR v0.6.39

Added:
- **A gate behind a wrapper can ask for a retry:** every gate run gets `GEAR_GATE_TEMPFAIL`, the path of a file. A gate that could not judge this time (a CI service refused a request) creates that file and fails; the merge is then retried instead of failed. This is the way for a gate run through `make`, which turns a recipe's exit 75 into its own exit 2. Exit 75 straight from the gate still works as well.

## Upgrading

From 0.6.38: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.39`, then any `gear` call, restart the engine, and install the skill again (`gear admin install-skill --agent <cli>`): it changed.
