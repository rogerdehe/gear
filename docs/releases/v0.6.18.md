# GEAR v0.6.18

A follow-up to v0.6.17 for two captains of the same CLI in one Herdr session.

Changed:
- **A Codex or OpenCode captain keeps its own session:** Herdr reports no session for some Codex panes, so two Codex captains in one session could not be told apart. `gear captain take` run from a CLI whose tools run in a daemon now records the caller's own session (`CODEX_THREAD_ID`, `OPENCODE_SESSION_ID`) on the captain's binding, and the first `gear` that finds a captain's pane with no known session records it there. After that each captain is found by its own session.

## Upgrading

From 0.6.17: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.18`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
