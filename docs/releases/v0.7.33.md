# GEAR v0.7.33

A captain that takes over another fleet carries that fleet's name.

## Fixed

- **A captain that took over another fleet kept its old fleet's name.** One pane may hold the captain seats of several projects, and its one agent carries one Herdr name. The take and the engine's name pass kept whatever name the agent already had (T-552, T-570), so a captain that took over a second fleet went on showing `<old project>-captain`. Now the agent carries the captain name of the project the pane took last: `gear captain take` (and a handover) renames it and records the take in the store, and the name pass of every project picks that same seat, so the name never flips. Without a recorded take, the seat that came to the pane last wins; a rebind of the same pane (a new session) is not an arrival. Deliveries to the other seats on the pane go to the agent's live name, as before.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.33`); the engine restarts on it by itself. A pane that already holds two captain seats is renamed after the seat that came to it last on the engine's next pass; anyone who prompts that captain by name uses the new name.
