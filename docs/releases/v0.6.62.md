# GEAR v0.6.62

Fixed:
- **Holding a task that was just delivered no longer stops the project:** `state: hold` on a ready task whose attempt was delivered but not yet confirmed closes that attempt, as it does for a running task, and the lane is told to save its work. The engine also leaves alone a delivery whose task can no longer start, instead of failing the project's whole tick.

Why: Prometheus, 2026-11-05. T-759 was held four minutes after its delivery. From then on, every tick failed with `BAD_TRANSITION: task: draft -> running` and was rolled back, so nothing merged, rang or was delivered for 25 minutes.

## Upgrading

From 0.6.61: `gear admin stop`, install v0.6.62, then any `gear` call, and restart the engine. The skill did not change.
