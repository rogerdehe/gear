# GEAR v0.6.14

M6.1, bug fixes that reach the users: a rework delivery says it is a rework.

Changed:
- **T-544 — a rework delivery says it is a rework:** the delivery of attempt n ≥ 2 used to open "New task", the same words as a first delivery, so a lane could take it for a repeat, skip its packet and guess the fix. It now reads "Rework T-n attempt k (contract vX): the review failed your last attempt; what to fix is the Rework section at the top of your task packet", followed by the branch and packet lines as before.

## Upgrading

From 0.6.13: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.14`, then any `gear` call, and restart the engine — the binary changed. The skill did not change: no `gear admin install-skill` is needed.
