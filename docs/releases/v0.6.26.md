# GEAR v0.6.26

Fixed:
- **The skill's guard no longer stops a bound captain:** it read "no `GEAR_CTX` and no seat bound to your pane → run no write command". A Codex captain checks its environment from outside its pane, finds no `GEAR_CTX`, and stopped replying. The guard now says to run `gear --session <session> --pane <your pane>`: a seat it names is yours, with or without `GEAR_CTX`.

## Upgrading

From 0.6.25: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.26`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
