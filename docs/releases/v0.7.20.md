# GEAR v0.7.20

A lane whose task waits on another of its own tasks no longer stops while a rebind is pending.

## Fixed

- **A parked attempt no longer holds back a rebind that keeps the repo.** A lane rebind waits until the lane has no open attempt, and while it is pending no new task is assigned to that lane. An attempt whose task declared a wait (`gear send --kind blocked --on T-<n>`) still counted as open, but it can only go on after the lane has done other work. When the awaited task was the same lane's, the lane stopped: the rebind never applied and the awaited task was never delivered. Now a parked attempt does not hold back a rebind that only changes the lane's paths. A rebind that moves the lane to another repo still waits for it, since that moves the worktree.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.20`) and restart the engine. Nothing to configure.
