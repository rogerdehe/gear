# GEAR v0.6.113

A voyage whose land order waits is not finished: the captain sees that order again; a long item typed into the prompt keeps its text.

Fixed:
- **The captain's home page was empty while the doorbell rang the land order** (Lawrence M2, M-1846). With every task merged, the page took the voyage for finished and hid its voyage lines, snapshot and engine items, the ready-to-land order among them. A voyage whose land order is still open is not finished; the handover between voyages follows the same rule.
- **A long item typed into the prompt kept only its header** (Lawrence M-1846, from v0.6.111). The cut fell on the last line break before the limit; a captain item that starts with the goal line has none, so only the ring's header was typed. A cut that keeps less than half the limit now falls mid-line.

## Upgrading

From 0.6.111 or later: install the new binary (`herdr plugin install rogerdehe/gear --ref v0.6.113`); a running engine restarts itself on it once its merges finish.
