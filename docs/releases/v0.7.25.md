# GEAR v0.7.25

A task can wait for a date, and a captain working alone can set its own task aside.

## New

- **`state: hold until=YYYY-MM-DD`.** A task that cannot start before a date (a bill that settles tomorrow, a reading a week out) is held until that date, read in UTC. Such a hold is no voyage stop and needs no confirmation; the idle bell skips the task until the date, and rings again from that day so the captain sets it `ready`. While only such tasks are left, the bell stays quiet (Prometheus M5: it rang every 10 minutes with only two date-bound tasks left).

## Fixed

- **A captain alone can hold its own task.** Holding a task in a project with no lanes read as the fleet standing still and asked for the user's confirmation; a captain alone has no fleet to stop, and the idle bell still counts an undated hold as a task left.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.25`); the engine restarts on it by itself. Nothing to configure.
