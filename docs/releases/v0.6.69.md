# GEAR v0.6.69

Accepted work that a stale `carried-by` mark kept off the integration branch is refused at plan time and named when it happens.

Fixed:
- **`carried-by` naming a task that has already merged is refused:** such a carrier lands nothing more, so the mark would keep the task's work unmerged for good (Prometheus T-779 sat accepted for 20 minutes). A mark the task already has is left alone; `carried-by: -` clears it, and leaving the field out keeps it.
- **The last task of a voyage is checked for lost work:** the lost-merge scan counted a voyage as finished as soon as every task was terminal, so the voyage's last accepted task, the one that holds the final candidate, was never named. A voyage now counts as finished once its last task settled two hours ago.

## Upgrading

From 0.6.68: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.69`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
