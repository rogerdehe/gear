# GEAR v0.7.18

A landed voyage's merged tasks are no longer reported as parallel changes.

## Fixed

- **The parallel-changes check skips the done tasks of a finished voyage.** It counted every done task as a change and told a merged one from an open one by its candidate being on the integration branch. After a landing that branch may be deleted (its tip is on the release branch), and every merged task of the voyage then read as unmerged: the captain was sent an item for each pair of them. A done task of a voyage with no open task left is now not compared at all.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.18`) and restart the engine. Nothing to configure.
