# GEAR v0.6.21

A voyage's clock under the user's hand.

Added:
- **A pause does not count:** `gear admin resume <project>` moves the departure of each voyage still sailing forward by the time the project spent paused, so the paused hours never show as elapsed time, against the eta or at a station.
- **`gear admin redepart <project> <milestone>`:** the voyage departs again now. Its elapsed time and time stations (the hourly course, the eta quarters) start from zero; its tasks, done work and completion count stay; its scope at departure is what it has today. It needs `GEAR_ADMIN=1`: a departure is still never moved on a captain's own call. Run it while the project is paused and the clock starts at the resume.

## Upgrading

From 0.6.20: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.21`, then any `gear` call, and restart the engine — the binary changed. The skill changed (one line in the captain reference): reinstall it with `gear admin install-skill --agent <cli>` for each agent CLI you use.
