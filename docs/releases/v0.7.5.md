# GEAR v0.7.5

A carried task's failed merge stops ringing.

## Fixed

- **The merge-failed item of a carried task waits for its carrier** (Lawrence M-2092, M-2223). While the task named in `carried-by:` has not merged, the item moves to waiting on that task, with the reason, for at most a day. It closes when the work lands with the carrier. A failure of the carrier rings on the carrier's own item. Before, the item rang as urgent every few minutes and offered a remerge that could only fail again.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.5`). The skill did not change. A running engine restarts itself on the new binary.
