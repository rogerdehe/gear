# GEAR v0.6.9

M6, station S5's speed work, continued: an ended round's usage is counted a bounded number of times, not forever.

Changed:
- **T-525 — an ended round's usage is counted a bounded number of times:** an ended round whose usage was still unknown was counted again every 60 s for as long as the reader could not find its session — 542 such rounds on a running store meant about nine counts a second, each parsing the project's config and walking `~/.codex/sessions` (about 1100 files). A round is now counted again only on a back-off (1, 5 and 30 minutes after it ended) and never again while its usage stays unknown — it stays unknown, never 0 — and the config is parsed once per tick instead of once per round. A round whose usage is found gives the same result as before.

## Skill

Nothing outside the tasks above.

## Upgrading

From 0.6.8: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.9`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change; a round already left unknown is not counted again.
