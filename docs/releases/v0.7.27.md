# GEAR v0.7.27

GEAR never deletes a top-level branch.

## Fixed

- **A floor under every branch deletion.** v0.7.26 stopped the landing's reclaim from deleting a shared integration branch. This release adds one rule to every place GEAR deletes a branch on a remote (the reclaim, the records merge, a merged task's branch, a seat branch rename): GEAR deletes only a branch under a prefix (`<project>/...`, as every branch it names is). A top-level name such as `dev`, `main` or `staging` is never deleted, whatever the configuration says.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.27`); the engine restarts on it by itself. Nothing to configure.
