# GEAR v0.6.89

A landing's reclaim never names the project's release or staging branch.

Fixed:
- **The reclaim named every branch under `<project>/`**, the project's own release and staging branches included, as leftovers of the landed voyage for the captain to delete. They outlive every voyage and are now left out. The integration branch is still named: it belongs to the voyage (M6.3 T-622 cuts it again from the release branch at the next departure).

## Upgrading

From 0.6.88: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.89`, then any `gear` call, and restart the engine — the binary changed.
