# GEAR v0.7.17

A landing cleans up after itself: the captain handles only what GEAR could not remove.

## Fixed

- **A landing no longer names workspaces whose agents are on their way out.** `station <id>: land` retires every lane and releases every reviewer, but their agents take a few ticks to exit. The reclaim ran in the same tick and named each of their workspaces as "holding an agent", so captains stopped agents and closed workspaces by hand that GEAR closed itself minutes later. For 15 minutes after the landing, a workspace still holding an agent is not named; one still there after that is.
- **The captain is no longer told to clean up by hand.** The landing guide and the land order told the captain to remove every worktree and close every workspace after landing. GEAR does that for everything clean and pushed; the captain now acts only on what GEAR names as left, each with its reason.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.17`), reinstall the skill copies (`gear admin install-skill --agent <agent>`): the landing guide changed. Restart the engine. Nothing to configure.
