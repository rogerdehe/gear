# GEAR v0.6.58

Fixed:
- **A captain pane that holds two projects' seats hands over the one it names:** a pane's GEAR context names one project, while one pane may hold the captain seats of several. A handover without `--project` from such a pane is refused, naming the seats it holds, instead of silently moving the context's project; `--project <project>` moves that project's seat when this pane holds it.

Why: Prometheus, 2026-11-05: a handover from a pane holding both Prometheus's and Lawrence's seats moved Lawrence's, and `--project prometheus` was refused.

## Upgrading

From 0.6.57: `gear admin stop`, install v0.6.58, then any `gear` call, and restart the engine. The skill did not change.
