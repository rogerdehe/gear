# GEAR v0.6.105

The ready-to-land item waits until every task of the voyage is merged, and names the done clauses still open.

Fixed:
- **"Ready to land" rang while accepted work had not merged** (Lawrence M2: M-1425 rang while T-119 and T-122 were accepted and unmerged; M-1439 rang the moment T-123 was accepted, while T-124's merge was still to run and then failed). The item now uses the landing's own rule: every done task of the voyage has its merge time. It rings on the tick after the last merge.
- **Every task merged was read as the goal met.** The item now lists the done clauses not yet met (for example a staging reading or a release the captain does itself), to meet before the landing or confirm with the user.

## Upgrading

From 0.6.104: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.105`, then any `gear` call, and restart the engine — the binary changed.
