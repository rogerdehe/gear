# v0.7.51

## Fixed

- A gate the config changes reaches the tasks already planned. Every task kept
  the gate it was planned with, so after a project moved `[conventions].gate`
  to its CI runners every task's merge still ran the old command on this
  machine (alfred M1, 2026-11-19). A task that lands on its repository's
  integration branch now runs that repository's current gate. A feature
  member keeps its feature's check, and a task of a repository the config no
  longer names keeps the gate it was planned with.
