# GEAR v0.6.28

Fixed:
- **Two merges no longer wait for each other:** a candidate that carries another task's work waits for that task to land first (T-62). When that task had passed review but its own merge failed, and the carrying candidate held the fix, each waited for the other forever. A reviewed task whose own merge failed is no longer waited for: the candidate that carries it lands both, after its gate passes on both.

## Upgrading

From 0.6.27: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.28`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
