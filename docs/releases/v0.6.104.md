# GEAR v0.6.104

A landing is reclaimed even when an old voyage holds accepted work with no merge time.

Fixed:
- **A landed voyage was never reclaimed while an old voyage of the project held accepted work with no merge time** (GEAR M6.3: 34 tasks of M1-M3, accepted before merges were timed, kept every worktree, the merge workspace and the feature branch after the landing). Only a voyage with a task in progress holds the reclaim; the landing itself still refuses while its own voyage has unmerged work, and the reclaim deletes only branches on the integration branch and worktrees that are clean and pushed.

## Upgrading

From 0.6.103: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.104`, then any `gear` call, and restart the engine — the binary changed.
