# GEAR v0.6.99

A feature's conflict item closes once the conflict is gone.

Fixed:
- **A `feature-refresh:<feature>` item stayed open after its feature branch took the integration branch, or after the feature landed** (Lawrence M2: M-1079 for F-1 and M-1165 for F-4; a reply cannot settle them). The item is resolved when the next refresh merges cleanly or the branch already holds the integration branch, and when the feature's integration task is done.

## Upgrading

From 0.6.98: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.99`, then any `gear` call, and restart the engine — the binary changed.
