# GEAR v0.6.40

Changed:
- **A `now` task's merge goes first:** accepted merges ran in the order they were queued, whatever the plan said, so a task the captain marked `now` waited behind older ordinary merges on a busy merge line. Merges of `now` tasks now run before the others; within each group the queue order holds, and a merge that waits for another task still goes last.

## Upgrading

From 0.6.39: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.40`, then any `gear` call, restart the engine, and install the skill again (`gear admin install-skill --agent <cli>`): it changed.
