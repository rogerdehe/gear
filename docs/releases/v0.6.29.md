# GEAR v0.6.29

Changed:
- **Stopping a voyage is the user's:** a plan apply that leaves no lane any work (every lane held, parked, in the tail or with nothing to start) while the departed voyage still holds work back (tasks on hold, or ready for a held or parked lane) is refused, like a change of the voyage's goal: the captain asks the user in its dialog, and applies again with `--confirmed` and a `confirmed:` line. An unanswered dialog is cancelled after ten minutes, so the voyage goes on. Holding one lane while another works needs nothing.

## Upgrading

From 0.6.28: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.29`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
