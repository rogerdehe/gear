# GEAR v0.4.6

The board in colour, as its prototype. `gear board` now draws the prototype's colours in all five views: the time bar green within the eta and red past it, each lane in its own colour, task stages (queued dim, working yellow, review cyan, merged green), over-estimate bars yellow, quota green, yellow and red, starred decisions yellow, and the time ratio from green to red. A lane name longer than four letters no longer runs into the task text: the lane column is as wide as the longest name. `NO_COLOR` turns colour off; `--json` and output that is not a terminal carry no escape codes.

## Upgrading

From 0.4.5: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.4.6`, then any `gear` call. No store or config change.
