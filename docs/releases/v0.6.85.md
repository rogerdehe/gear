# GEAR v0.6.85

A voyage never stops on its own.

Fixed:
- **A captain stopped at a station to wait for the user:** a station is a mark to measure against, never a stop. Every station report now ends with "A station never stops the voyage: keep every lane working; what only the user can do waits for the landing", the captain's skill says the same in its daily loop, and the engine sends one urgent item to a captain whose agent has been idle for 15 minutes while its voyage still has open tasks (again every 30 minutes while it stays idle).

## Upgrading

From 0.6.84: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.85`, then any `gear` call, and restart the engine — the binary changed.
