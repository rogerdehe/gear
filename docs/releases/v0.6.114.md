# GEAR v0.6.114

The board no longer names a cancelled task as a lane's next task.

Fixed:
- **A lane's board line read "next T-x is ready but not delivered" for a cancelled task** (Lawrence M2, T-69). The board kept cancelled tasks in the lane's list with the stage of a task never started, so its next-task line could pick one. The engine never dispatched it; only the board line was wrong. A cancelled task is now skipped, as the engine's rule skips it.

## Upgrading

From 0.6.111 or later: install the new binary (`herdr plugin install rogerdehe/gear --ref v0.6.114`); a running engine restarts itself on it once its merges finish.
