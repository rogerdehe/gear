# GEAR v0.5.3

Station S4 of M5, the voyage's last release: every M5 task is on dev, and a broken review worktree stops its seat instead of stranding the hand-ins behind it.

Changed:
- **T-425 — a broken review worktree stops its seat, never the task:** the checkout failures are counted per seat instead of per task, so a seat whose worktree fails three times is retired (with the worktree path and the git error, and a once-only notice to the captain) and its hand-in goes to another seat on the next tick; a hand-in is marked stuck only when its candidate fails to check out on two different seats; and a warm worktree left mid-merge is reset before its next checkout, so a bad reviewer no longer strands 24 hand-ins.

Every M5 task is in this release: T-332 and T-396 were cancelled, and nothing is deferred to a later version.

## Skill

Nothing outside the tasks above. The release review found the lessons since v0.5.2
(check every name a contract gives against merged code, run the whole crate when a
rule changes, release notes stop at the hand-in) already covered by the skill
(decompose §4, Reachability and Old tests) or not recurring.

## Upgrading

From 0.5.2: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.5.3`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
