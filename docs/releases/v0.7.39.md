# GEAR v0.7.39

A lane that runs out of other work during an external wait goes back to the waiting task.

## Fixed

- **A lane sat idle for over an hour behind an external wait.** An external wait (`gear send --kind blocked --on external`) ended only when the lane wrote again on the task or after 120 minutes. MissHerAI's media lane waited on T-30 for a merge that had landed before it declared the wait, worked T-35 meanwhile, handed it in, and then sat idle with nothing to wake it (2026-11-17). Now, once the lane has handed in another task since the wait began and has nothing in flight, the wait ends and the lane gets an urgent instruction naming what it waited for: continue the task if that is there, or declare the wait again with what is still missing.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.39`); the engine restarts on it by itself. Nothing to configure.
