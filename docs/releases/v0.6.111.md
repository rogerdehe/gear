# GEAR v0.6.111

An idle seat reads its messages in the prompt; a new binary restarts the engine by itself; engine items and the plan store stay small; four merge frictions are gone.

Changed:
- **An idle seat gets its messages as text** (M7 T-631). A seat that is idle, holds no delivery and has no item needing an ack gets the waiting messages themselves in one prompt: a header per message (id, sender, urgent), the body, and how to reply. Such a prompt counts as shown once Herdr took it. Over about 4000 characters it is cut and names `gear` for the rest. A working seat, or a ring with an item needing an ack, keeps the one-line doorbell.
- **A replaced binary restarts the engine by itself** (M7 T-632, T-647). When the `gear` binary on disk changes, the engine starts no new merge, lets the running ones finish, then runs the new binary in its own process under the same lock: no pause, no cut merge. A SIGTERM stop also waits for the running merges. `gear admin restart` asks every engine on the machine to do the same at once.
- **Engine branch items stay short** (M7 T-633; Prometheus M-8671 was 60k characters). Each section lists at most 10 branches, a done branch names its commit count and newest commit, and a last line names the command that lists the rest.
- **The store keeps the last 20 plan versions per project** (M7 T-646). Older ones are deleted at the next apply; git keeps the plan's history.

Fixed:
- **The idle-voyage item rang every few minutes while a land waited for the user** (M7 T-634): with every task done and a land order open, it rings once per land order.
- **The lost-work scan missed a carried task whose carrier landed without it** (M7 T-635): such a task gets the merge-lost item naming the carrier and the way out (`carried-by: -`, then `- remerge T-n`).
- **A member added to fix a red feature carrier minted a new carrier** (M7 T-644; Lawrence M2 T-96/T-107): a carrier that is done but not merged is kept, its deps get the new member, and the captain remerges it.
- docs/design/07-mail.md says how a message reaches an idle seat (M7 T-650).

## Upgrading

From 0.6.110: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.111`, then any `gear` call, and restart the engine — the binary changed. An engine older than 0.6.111 does not restart itself; stop and start it once by hand. From 0.6.111 on, installing a new binary is enough. The first apply after the upgrade prunes old plan versions; back the store up first if you want them (`sqlite3 <store> ".backup <file>"`).
