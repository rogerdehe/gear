# GEAR v0.6.46

Added:
- **`gear admin remap-commits <map>`** (GEAR_ADMIN=1, with the session's engine held by `gear admin stop --hold`): after a project's git history is rewritten (`git filter-repo`), every commit id the session's store names — attempt and verdict candidates, merge payloads, items, meta — becomes the new id from the filter-repo commit-map, at the same length. A full id or a unique prefix of at least 7 hex digits is rewritten; an ambiguous prefix, a dropped commit or an unknown id stays. Accepted work keeps its identity across the rewrite.

## Upgrading

From 0.6.45: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.46`, then any `gear` call, and restart the engine. The skill did not change.
