# GEAR v0.7.10

A rework whose task gained an unfinished dependency is delivered, and the engine round no longer fails on it.

## Fixed

- **A rework never waits on a dependency, and never stops the engine.** Dispatch holds a task behind its dependencies only for its first start: once the lane has worked on it, its rework is delivered and the dependencies hold only its merge. The step that creates the attempt still required every dependency to be done, so a rework whose task depended on a task still verifying was refused. That refusal failed the project's whole engine round, each round (a client saw 35 failed rounds in a row, `task T-246 depends on T-245, which is verifying and not done`). The attempt step now checks dependencies only for a task's first attempt, as dispatch does.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.10`). A running engine restarts itself on the new binary. Nothing to configure, and the skill did not change.
