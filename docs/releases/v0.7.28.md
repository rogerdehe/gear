# GEAR v0.7.28

`state: hold until=D` holds a task through day D.

## Changed

- **A dated hold covers its date.** `until=D` used to free the task at the start of day D (UTC), so the idle bell rang at 00:00 on the very date the captain wrote; both captains who used it read it as "held through D" (Lawrence T-354, Prometheus T-805). The task now stays held all of day D and counts again from the next day.
- The skill says a dated hold is also the way to record a block outside the team (a spent CI budget the user is asked to raise): hold to a date, and hold it to a later one if it is still blocked.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.28`); the engine restarts on it by itself. A hold already set keeps its date and is now held one day longer.
