# GEAR v0.6.100

A feature counts as landed for its conflict item only once its integration task merged.

Fixed:
- **v0.6.99 closed a feature's conflict item when its integration task was done but not merged** (Lawrence M2: M-1079 closed as "the feature landed" while T-107 was done and unmerged). The item now closes for a landed feature only when the integration task has a merge time; a clean refresh still closes it at once.

## Upgrading

From 0.6.99: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.100`, then any `gear` call, and restart the engine — the binary changed.
