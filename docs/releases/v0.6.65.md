# GEAR v0.6.65

Only a CLI that runs its commands outside its pane names its seat.

Changed:
- **Plain `gear` for Claude, pi and Grok seats:** since v0.6.19 every text GEAR sent a seat spelled `gear --session <s> --pane <p>`, and the skill told every seat to put those arguments on every `gear` command. Only OpenCode and Codex need them: they run commands in a shared background process outside the agent's pane. Every other CLI runs in its own pane, where GEAR finds it by its process. Doorbells, task, rework and review packets and continue notices now spell plain `gear` for those seats. The skill runs the guard once at start and says no other command (git, grep, builds, tests) takes these arguments or a `gear` call in front of it.
- **The board forecast leaves out cancelled tasks:** a cancelled task no longer blocks the tasks that depended on it in the forecast.

## Upgrading

From 0.6.64: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.65`, then any `gear` call, and restart the engine — the binary changed. The skill changed: run `gear admin install-skill --agent <cli>` for each agent CLI you use.
