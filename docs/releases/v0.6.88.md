# GEAR v0.6.88

A landing order answered `keep course` still lands the voyage, and reviewers stay up until the landing.

Fixed:
- **`station <id>: land` on a landing order already answered `keep course`** was skipped as a past decision: the voyage never counted as landed, so the captain's records branch was never merged and the reclaim never ran, with no item to say so (Carthage M1). The landing order is the only way to land a voyage, so a `land` line on it now takes the landing (its checks run as for an open order) and retires the lanes; a re-apply changes nothing.
- **Reviewers stay up until the voyage lands.** With every task done they were released at once, before the landing, so a late task, a rework or a feature check cold-started new reviewers. Idle reviewers are now released when the voyage has landed (or with `[quota] reviewer_release_idle_min`, as before).

## Upgrading

From 0.6.87: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.88`, then any `gear` call, and restart the engine — the binary changed.
