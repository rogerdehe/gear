# GEAR v0.6.75

A take between voyages never names the finished voyage's handover.

Fixed:
- **A take named a handover from a voyage that had landed:** `gear captain take` looked for the previous captain's handover in the last voyage's folder even when that voyage had finished, so Lawrence's new captain was pointed at an M1 document from before M1 landed. Between voyages, a take reads and asks for the handover in the project's `between-voyages` folder (`<voyage_dir>` with `between-voyages` for the milestone) until the next kickoff.

## Upgrading

From 0.6.74: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.75`, then any `gear` call, and restart the engine — the binary changed.
