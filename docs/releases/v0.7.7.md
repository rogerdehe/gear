# GEAR v0.7.7

Claude seats start without the advisor.

## Changed

- **Every seat GEAR starts runs Claude Code without its advisor tool.** Lanes, reviewers, temporary reviewers and restarted seats are covered. The seat's start line exports `CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` next to the editor variables. A simple review spent many tokens on the advisor's stronger model. Other CLIs do not read the variable. A Claude Code session you start yourself, a captain for example, keeps its own settings.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.7`). The skill did not change. A running engine restarts itself on the new binary. Seats already running keep their advisor until their next start.
