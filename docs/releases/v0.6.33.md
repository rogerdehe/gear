# GEAR v0.6.33

Fixed:
- **The Codex skill reaches agents that run with `CODEX_HOME`:** Codex reads its skills from `$CODEX_HOME/skills` when `CODEX_HOME` is set, but `gear admin install-skill --agent codex` always wrote `~/.codex/skills`, so such agents kept an old copy. It now writes where Codex reads.

## Upgrading

From 0.6.32: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.33`, then any `gear` call, restart the engine, and run `gear admin install-skill --agent codex` again in the shell that sets `CODEX_HOME`.
