# GEAR v0.6.84

A landed feature asks for no more light checks.

Fixed:
- **Reviewers started again and again after a feature landed:** the light checks of stage 2 walked every accepted member of every feature, including features whose integration task had already merged; a reviewer was started, failed and started again every few minutes, even after the voyage landed. A feature whose integration task is finished gets no light check.

## Upgrading

From 0.6.83: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.84`, then any `gear` call, and restart the engine — the binary changed.
