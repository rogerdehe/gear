# GEAR v0.6.23

A follow-up to v0.6.22 found in its first live use.

Fixed:
- **The queued merge of a full-sha pass runs:** v0.6.22 queued the merge, but the check just before the merge still compared the op's full sha with the attempt's short one exactly and voided it as "the task may not be merged". It now matches the same commit.
- **`remerge` retries a voided merge:** a voided merge merged nothing, so `- remerge T-<n>` queues the accepted attempt again (it refused with "already void, not failed").

## Upgrading

From 0.6.22: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.23`, then any `gear` call, and restart the engine — the binary changed. The skill did not change.
