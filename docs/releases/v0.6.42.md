# GEAR v0.6.42

Fixed:
- **A new failure of the same merge rings the captain again:** when a task's merge failed while its earlier "merge of T-n failed" item was still open, GEAR only rewrote that item. A captain who had already seen it got no doorbell, so a third failure could sit unnoticed. A new failure now closes the old item ("a newer failure of this merge replaced it") and opens a fresh one, which the doorbell names. The same failure repeated still changes nothing.

## Upgrading

From 0.6.41: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.42`, then any `gear` call, and restart the engine. The skill did not change.
