# v0.7.42

## Added

- A `correction` decision line: `- <date> correction: <what> -> <the check or
  change that prevents it now | judgment only: why>` in `# Decisions` is
  structured, not a note. The date may carry a time. `gear report voyage`
  lists every correction in its own part, and marks one with nothing after
  `->` (or a bare `judgment only:`) with ⚠ and counts it in the part's
  heading, so the landing walk shows what still needs an answer.
