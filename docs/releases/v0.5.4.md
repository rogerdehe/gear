# GEAR v0.5.4

The first batch of M5.1, the fixes another project's fleet reports: a restart that stalls, a command typed but never sent, an overlap check that re-diffs what it has already diffed, and a mechanical packet that told the lane to run the gate itself.

Changed:
- **T-433 — a restart finishes even when onboarding already made the seat Active, and one failed restart no longer stops the project:** the finish phase accepts a seat that onboarding has set Active on the plan's generation, so the restart completes, the pending plan is cleared, the plan's model is applied and the open attempt gets its Deliver op; and a restart step that fails for one seat is reported as "<seat>: restart step failed" without aborting the rest of that tick.
- **T-434 — a session step types its command and presses Enter in the same step:** `/new` and a resume's `/quit` no longer sit in the box unsent when the tick runs long or the agent looks busy right after the text, which used to leave lanes idle with a half-finished switch until someone pressed Enter by hand.
- **T-435 — the overlap check keeps the diff of each commit pair:** `git diff` runs once per pair of commits instead of twice per open task every ten minutes and at every hand-in, so a long parallel check no longer holds up that tick's session steps.
- **T-437 — a mechanical task's packet no longer tells the lane to run the merge gate:** such a packet now says the engine runs the gate at the merge and that it is the only check, so mechanical lanes stop running the whole gate twice.

## Skill

Nothing outside the tasks above.

## Upgrading

From 0.5.3: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.5.4`, then any `gear` call. The engine changed, so the restart matters. Nothing in an existing config has to change.
