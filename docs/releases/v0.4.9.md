# GEAR v0.4.9

The captain keeps the destination in view.

- **Every captain doorbell repeats the voyage's goal.** After the item ids, the doorbell adds one line: `Your goal, voyage <M>: done: <the done sentence> · bar: <the bar>. Judge every decision against it.` It is taken from the voyage that departed last, as applied from its `# Milestone` block. Lanes and reviewers get no such line; they already carry the done sentence and the bar in every packet.
- **Station reports and the landing are judged against the goal (skill).** A station starts from the distance to the `done:` sentence, then pace and the eta. The voyage report opens by quoting `done:` and judging each of its clauses with measured evidence (the number the sentence names, never the count of tasks merged).

## Upgrading

From 0.4.8: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.4.9`, then any `gear` call. No store or config change. Keep the `# Milestone` block with `done:` and `bar:` in the voyage file, so the line the captain sees is the goal the user agreed.
