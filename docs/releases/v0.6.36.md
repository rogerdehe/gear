# GEAR v0.6.36

Added:
- **`carried-by: T-<m>` on a task:** the task's work lands with T-m's merge. Its review passes as usual, but the pass queues no merge of its own, T-m's merge does not wait for it, and the engine marks it merged (as `integrated-by` would) once T-m's merge has landed its candidate on the integration branch. Before, a reviewer had to withhold its verdict to keep a standalone merge from starting, and GEAR kept reminding it as an idle hand-in.

## Upgrading

From 0.6.35: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.36`, then any `gear` call, restart the engine, and install the skill again (`gear admin install-skill --agent <cli>`): it changed.
