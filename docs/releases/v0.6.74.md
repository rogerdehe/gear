# GEAR v0.6.74

The home page of a finished voyage shows what the doorbell rings for.

Fixed:
- **The doorbell rang for an item the page hid:** a captain whose voyage finished saw no engine item at all, so a seat take (Lawrence M-875) rang the doorbell again and again while `gear` showed nothing. The page now leaves out only the finished voyage's own items (its tasks, stations, merges, branch sweeps, overruns, stall), the same ones the doorbell leaves out.

## Upgrading

From 0.6.73: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.74`, then any `gear` call, and restart the engine — the binary changed.
