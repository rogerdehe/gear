# GEAR v0.6.106

A task moved to another lane keeps the branch its first attempt was told.

Fixed:
- **A rework after a lane move named a branch that never existed** (Lawrence M2 F-71: T-126 moved from web to the align lane, added mid-voyage; its rework said `lawrence/align/t126` and that the review was committed on it, so the lane cut a new branch from the integration branch). Once a task has an attempt, its branch is the one its first attempt's lane used, for the delivery, the hand-in check, the review and the merge alike. A task that names its own branch (a feature member, an integration task) keeps it as before.

## Upgrading

From 0.6.105: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.106`, then any `gear` call, and restart the engine — the binary changed.
