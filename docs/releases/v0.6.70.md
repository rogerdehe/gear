# GEAR v0.6.70

A voyage with a task in progress is not stopped.

Fixed:
- **The "voyage is stopped" item rang while lanes worked:** it counted only the tasks that wait, so a task waiting for a running one by design (Prometheus T-792 on T-788) rang the captain every few minutes while three lanes worked. A task in progress now moves the voyage, and the item closes.

## Upgrading

From 0.6.69: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.70`, then any `gear` call, and restart the engine — the binary changed.
