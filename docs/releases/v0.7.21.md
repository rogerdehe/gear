# GEAR v0.7.21

Past the rework cap the captain settles the task; another plain rework is refused.

## Changed

- **The rework cap holds for the captain's own verdicts.** `[conventions].review_max_rounds` (3 by default) stopped only a review that settled itself. A captain who copied each failed review into a `fail rework="…"` line could send a task back without end: one task went back seven times. A task sent back that many times is the captain's to settle, since neither the lane nor the reviewer owns the project. Past the cap, a plain `fail rework="…"` is refused with what to do instead: pass the task with `why=`, rewrite or split its contract, cancel it, or send one last round with a ruling.
- **New verdict field: `fail ruling="<why the rounds failed> <the exact fix>"`.** A ruling is the captain's last word on the task. Its text becomes the rework note under a header saying that it replaces every earlier rework note and the review's open findings, so the lane works to it and the reviewer judges that round against it alone. It may be used before the cap too. The captain's item names `ruling=` in its verdict line once the cap is passed.

## Upgrading

Install the new binary (`herdr plugin install rogerdehe/gear --ref v0.7.21`), reinstall the skill and restart the engine. Nothing to configure. A task already past the cap needs a ruling (or another way to settle it) for its next fail.
