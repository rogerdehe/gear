# GEAR v0.6.86

GEAR rings the captain when the whole fleet stands still.

Changed:
- **The reminder watches the fleet, not the captain alone:** an idle captain is no problem while its lanes and reviewers work. When the captain and every lane and reviewer have been idle for 5 minutes, no merge is running, and the voyage is not finished (it has open tasks, or every task is done and its landing order waits), the captain gets one urgent item; again every 10 minutes while the fleet stays still. A paused project is left alone.

## Upgrading

From 0.6.85: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.6.86`, then any `gear` call, and restart the engine — the binary changed.
