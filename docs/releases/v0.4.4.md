# GEAR v0.4.4

The captain registers its project. A first `gear admin init` is no longer refused because it runs in an agent's pane: the whole setup is the captain's, with `GEAR_ADMIN=1` as the consent the user gave at kickoff. A seat of a project (a lane or a reviewer, which carries `GEAR_CTX`) still never registers another project, and a config re-applied to a registered project is still proven to come from its captain's pane.

The captain's guide says the same: after the kickoff sheet is confirmed, the captain runs `GEAR_ADMIN=1 gear admin init gear/gear.toml` itself.

## Upgrading

From 0.4.3: `gear admin stop`, `herdr plugin install rogerdehe/gear --ref v0.4.4`, then any `gear` call starts the engine. No store change.
